TITLE: Errors (GNU Coding Standards) — 4.4 Formatting Error Messages
ACCESSED: 2026-10-28 (reader extraction; method native text)
EXTRACT (verbatim, the section's rule for noninteractive programs):
  "Error messages from other noninteractive programs should look like this:
   program:sourcefile:lineno: message
   when there is an appropriate source file, or like this:
   program: message
   when there is no relevant source file."
  "The string message should not begin with a capital letter when it follows a
   program name and/or file name, because that isn't the beginning of a sentence."
