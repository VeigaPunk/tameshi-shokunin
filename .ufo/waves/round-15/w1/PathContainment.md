These complement other seats' fixtures. Each arm runs as a public-CLI subprocess on a copied tool inside a temp lane, and asserts literal exits.
1. `lane-anchor-ok`: the copied tool in `scratch/lane/tools/`, on a good fixture → exit 0. Assert that the receipt exists **only** at `scratch/lane/.ufo/evidence/round-15/context-receipt.json`, and that no `round-14` path was created.
2. `receipt-exists-refused` (if PC-6 is adopted): pre-create the output → exit 2, kind `receipt_exists`, bytes unchanged.
3. `check-doctored-env`: run the check on synthetic bytes shaped like `context-missing-env.json` → exit 1, ID `missing_injected_environment`.
4. `check-digest-mismatch`: one byte flipped against the pinned digest → exit 1 (or 2, per GateClassification's map), with a stable digest ID.
5. `check-path-redirect`: `sources.probe.path = "../outside/x"` → rejected as a mismatch without opening the path. Place a sentinel file at the target and assert its atime/absence of access only if the check can observe that cheaply. Otherwise assert the stable ID alone.
6. `check-symlink-receipt`: receipt argv is a symlink → exit 2 (`receipt_symlink`) through `O_NOFOLLOW`.
7. `probe-leg-not-object`: the stub probe emits `legs:[1,2,3,4,5,6]` → exit 2 `probe_baseline_unusable` (not a traceback, and not 1).
8. `usage`: unknown argument → exit 64, no receipt written (round-14 routed: declare 64 explicitly).
