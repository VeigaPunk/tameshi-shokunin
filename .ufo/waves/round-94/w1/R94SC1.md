## Behavior — what each block says

**Block 1 (note status block).** Drafted as a **replacement** for the committed
`## Certification attempt (appended round 94) — the self-anchored gate identity` section
(note line 297 at `6b19eb92`), keeping that section's three fixes and adding the three
things the item asks for and the committed section lacks: an explicit statement of what
the reader certifies (the twelve cells), an explicit statement of what it does **not**
certify (how the cells were obtained; fenced presentations; a table whose header row
carries no `verdict` header), and S320/S321/S322 cited **with their located quotes**
(the committed sections name S320/S321/S322 but quote no span and give no file:line).
It ends by deferring admission to the non-author closure; it makes no admission claim.

**Block 2 (QUALITY criterion).** QUALITY 160 already carries 158's operational half and
QUALITY 166 carries the reason test. Neither covers the **binding** this round's own
wave found, so the draft adds a third criterion rather than editing either. It states
that a disposition checker must be bound to *the manifest of the round it audits* and
that its receipt must name that manifest — because the audited path is a constant in
the checker's own bytes, and round 94's checker revisions 1 and 2 named the **round-93**
manifest, so the round-94 manifest's `canary` and `unstable0` reasons were never
audited while the run printed `findings=0`. Drafted as criterion **168**; the L1 owns
the number and the placement.

**Block 3 (Mistakes row).** The class the item names is **already recorded** — round-93
lesson `M2` (line 38) and QUALITY 159. The draft is therefore not a restatement of it
but the **evidence-pointer correction** the committed row needs: its pointer names a
`D01.out` receipt reading `exit=1` / `C1_R93_PASS=false`, and **no such receipt exists
anywhere in the lane's history** (every committed `D01.out` reads `exit=0` /
`C1_R93_PASS=true`). The defect itself is confirmed from committed bytes: the pre-A3
counter `b34c929e` carried the stray-verdict rule **twice** (lines 260 and 266) and the
A3 counter `855f0c1c` carried it **once** (line 262), and the driver's D01 anchor matched
only the block-line copy. The draft replaces `M2` in place, keeping its id, and points
at the wave seat's committed re-derivation plus the two instrument revisions — the only
place the `exit=1` witness actually lives.

exist.** Block 3 is the correction. The class is not in doubt; the pointer is. The
witness that does exist — the wave seat's re-derivation — carries a `counter_sha` that
is the **mutated rev-C counter**, reproduced here byte for byte, so it is a mutation
study over a scratch copy rather than a battery receipt, and that is the honest way to
cite it.

**F3 — The C2 receipt does not name the manifest it audited, and at rev 1 it could not.**
This is the substance of block 2. Note the interaction with the plan's amendment A1,
which records the rev-1 → rev-3 repair; **the operative checker (rev 3) still prints a
receipt that never names the manifest**, so the "receipt names the audited manifest"
half of block 2 is a rule for a future revision, not a description of the instrument as
it stands. Block 2 says so explicitly rather than implying the gap is closed.

**F4 — `claims.json` still names rev 1 as the C2 `instrument_sha256`** while the
operative instrument is rev 3 (`6d4d2706…`). The plan's amendment A1 records this
substitution and reads kill rule (d) with it. Noted here because block 2's witness
depends on the rev-1 bytes being identifiable as rev 1.

**F5 — The frozen plan's C2 predicate (`DISPOSITION_SELFTEST: 8/8 pass`) does not
match the operative checker**, which prints `9/9 pass` (the extra case is
`a4-prose-state-word-cheat`). The plan's line 165 reads `8/8`; `claims.json`'s
`battery_predicate` likewise says `8/8`; the committed receipt
`.ufo/evidence/round-94/pre-freeze/c2-selftest.out` says `9/9`. Both the plan and
`claims.json` are frozen, so this is for the L1 to reconcile in the records commit, not
for this seat to edit.
