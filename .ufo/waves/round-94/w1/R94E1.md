## Method

Driver: `.ufo/waves/round-94/w1/R94E1-repro.sh` (this seat's saved driver). It

1. materializes a pristine copy exactly as the seat spec mandates:
   `git -C /home/vgpnk/Projects/shokunin archive --format=tar f47ad6ba8d306f8125597401cb2ce45c1297a593 scripts/fixtures/sources-census | tar -x -C "$D"`,
   plus `git … show f47ad6ba…:scripts/sources-census.sh > "$D/scripts/sources-census.sh"`, `chmod 755`;
2. runs `bash "$D/scripts/sources-census.sh" selftest` on the pristine copy —
   exit 0 and `selftest ok` on the final line (pristine rc=0, `_` arm set of 134 lines, all `killed`);
3. for each mutant C01–C12 in `.ufo/evidence/round-94/c1/census-mutants.json`, copies the pristine tree to a
   scratch case dir, applies the mutant's exact `old`→`new` string with its own short Python program
   (the frozen counter is never imported for execution; the edit script asserts `old` occurs exactly once —
   all 12 applied cleanly, `edit applied exactly once`), then runs `bash …/scripts/sources-census.sh selftest`
   **twice in the ordinary shell environment (no `env -i`)**, recording rc of both runs;
4. derives verdict: rc 0 = SURVIVED, rc ≠ 0 = KILLED (unstable if the two runs disagree — none did), and
   diffs each run's output against the pristine output to name the selftest arm(s) that differ;
5. runs the frozen counter once at the instrument revision into a fresh empty work dir and pastes its stdout below.

Everything ran under scratch `/fast/scratch/hyaku/tameshi-r94/R94E1/` (removed before yield).
