## 4. UFO-FSD Connector Synthesis & Bounded Proposal

### Title
**Indented-Literal Block Immunity & Self-Pin Single-Match Sealing**

### Evidence & Synthesis Across Round Seats
1. **Indented-Code Literal Refusal (Critic R94C1 Attack A8/A8b, Proven Kill Rule (a)):**  
   In `measure-v94.py:78,226-248,275-280`, `block_lines(text)` strips fenced code blocks via `FENCE_RE = re.compile(r"^ {0,3}(`{3,}|~{3,})(.*)$")` per CommonMark/S322, but does not exempt 4-space-indented code blocks (`^ {4,}`). Consequently, if an honest note includes a 4-space-indented literal example containing a markdown table or stray verdict tokens (e.g., `| C01 | KILLED |`), the reader evaluates it as structural markdown, triggering `stray-verdict` or `verdict_tables=2` (exit 1).  
   Crucially, this contradicts the fleet gate's own maintained parser lineage (`scripts/sources-census.sh:40`), which explicitly specifies:
   `# Maintained parser accepts 0–3 leading ASCII spaces before Markdown rows/headings; 4 or more spaces are indented code and ignored.`
2. **Self-Pin Re-Binding Vulnerability (Reviewer R94R1 Finding F1):**  
   In `measure-v94.py:62,91-92`, `SELF_PIN_RE = rb'^SELF_SHA256 = "[0-9a-f]{64}"\n'` uses `re.sub(SELF_PIN_RE, b"", b, flags=re.M)`. This strips *all* occurrences of the pattern. Inserting a second `SELF_SHA256 = "<H>"` line before `main()` executes during import and binds `SELF_SHA256` to the tampered hash `H`, while both lines are stripped during normalization, reporting `selfpin=true` on modified logic.
3. **Double-Backslash Escaping Nuance (Reviewer R94R1 Finding F2):**  
   In `measure-v94.py:171-192`, `split_cells` absorbs `\|` into a cell without recognizing that in CommonMark/GFM (§6.2), `\\|` is an escaped backslash (`\\` → `\`) followed by an unescaped table pipe separator (`|`). While pristine note rows contain no backslashes, a future note table employing backslashes could diverge in cell count.
4. **Independent Verifications (Reviewer R94R2, Scout R94S1, Executor R94E1):**  
   - R94R2 confirmed that the 19 conjunct keys, the 17 falsifiable receipts, and the 2 sealed unfalsifiable proofs match the plan and manifest row-for-row.
   - R94S1 confirmed live byte-exact identity of S321 (GFM) and S322 (CommonMark 0.31.2) with committed snapshots.
   - R94E1 independently confirmed 12/12 mutant reproduction outside the counter (5 KILLED, 7 SURVIVED).

### Affected Axes
- **Coverage (Axis: Verification-Fixture Craft, R94-C1):** Closes the honest-note refusal vector on 4-space indented code blocks (CommonMark S322 §4.4) and eliminates the `\\|` cell-splitting divergence (S321 / S322 §6.2), aligning the reader's structural parser with both external specs and the fleet gate's own 0–3 space standard (`scripts/sources-census.sh:40`).
- **Calibration (Axis: Verification-Fixture Craft, R94-C2):** Hardens `selfpin` verification by enforcing single-match integrity (`len(matches) == 1`), eliminating the multi-pin defeat vector and guaranteeing that the executing counter is bit-exact to its pinned digest.

### Proposed Move
Incorporate a 3-point craft hardening into the verdict-content reader:
1. **Indented-Code Block Immunity (`^ {4,}`):**  
   In `block_lines()`, ignore lines with 4 or more leading spaces (`^ {4,}` outside list continuations), or in `tables()` / stray-verdict scans ignore lines matching `^ {4,}`. This ensures literal code blocks in documentation notes cannot trigger stray-verdict or table-count refusals, matching CommonMark §4.4 and `scripts/sources-census.sh:40`. Add a committed positive control state `pos-indented-literal` to `controls-v94.py`.
2. **Single-Pin Match Enforcement in `self_pin_ok()`:**  
   In `self_pin_ok()`, assert `len(re.findall(SELF_PIN_RE, b, flags=re.M)) == 1` before stripping. If zero or multiple pin lines exist, immediately return `False`, refusing setup (`C1_SETUP self-pin-mismatch`).
3. **Escaped Backslash Resolution in `split_cells()`:**  
   Update `split_cells()` to process double backslashes (`\\`) before pipe escaping, ensuring `\\|` yields an escaped backslash followed by a cell delimiter.

### Risks & Invariance Analysis
- **Zero Regression on Honest Note:** The committed note `corpus/knowledge/mutation-case-fleet-sources-census.md` uses 0-space indented tables and zero backslash characters. It continues to pass cleanly (`C1_R94_PASS=true`).
- **Zero Regression on Battery Receipts:** None of the 45 pre-registered controls use multiple `SELF_SHA256` lines or 4-space indented tables (except the newly added `pos-indented-literal` control).
- **Predicate & Conjunct Invariance:** The 19 conjunct keys, `C1_CONJUNCT_KEYS`, and the disposition manifest `tools/conjunct-disposition.json` remain completely invariant.
