## Verdict

**KILLED** (mutant detected; no survivor). The invariant is real on pristine bytes — the
fixture's `case.expected` is `b'old\n'` after the no-flag call and `b'new\n'` only after
`update=True` — and the selftest's own byte read plus the C2 counter's FLAG_GATE replay both
fail the mutant (`rc=1`, `fixture_wrote=0`, `noflag_unchanged=0`, `mutant_killed=1`).
Baseline pristine passed, so the kill is not a baseline artifact.

Coverage note (not a contract change): the kill relies on the detector checking both the
return value and the file bytes (`if wrote or not unchanged`, line 100). Either check alone
would also catch this mutant; a defect that returned `True` while leaving bytes unchanged
would be caught only by `wrote`.

sha256 `bc8c660c56f871f85dad8912be28446293fd63f62b4fd1c16eb153f7a27edc62`, `--selftest` rc=0;
lane file hash unchanged before/after (`bc8c660c...a27edc62`), lane `git status` for `tools`
and `.ufo/evidence/round-39` empty.
