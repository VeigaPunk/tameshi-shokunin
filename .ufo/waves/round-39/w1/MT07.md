  every recorded pin would satisfy a pure hash spot-check; the actual barrier is the
  round-38 contract frozen before the deciding run plus git history, both intact here.

  knowledge-entry edit elsewhere could later make the entry leg fail without touching the

  three now hash to the pin because mutants were restored. That is evidence, not a second
