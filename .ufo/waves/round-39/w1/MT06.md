## Depth finding

1. On live REV bytes the classifier has **no positive instance**: 0 of 99 write-site lines match
   `EXPECTED_RE`; 0 of 21 gate files contain any `FLAG_RE` token. So
   `unflagged = |WRITE ∩ EXPECTED ∩ ¬SCRATCH ∩ ¬FLAG|` collapses to the constant 0 on the live
   corpus — the value is produced by the heuristic matching nothing, not by flags being present.
   The only positive instance that exists anywhere is `PLANTED['unflagged']` (`:58`).
2. The only expected-value writes in the pinned gates are selftest fixtures inside temp dirs:
   `tools/golden-verdict.py:48,52` (`golden = os.path.join(tmp, 'expected.txt')` under
   `tempfile.TemporaryDirectory`, then `with open(golden, 'w', ...)`) and
   `tools/context-capture.py:1662,1682,1685` (`expected_path = os.path.join(directory,
   "expected.json")`, directory under `tempfile.mkdtemp` at `:1624`, then `open(expected_path,
   "w"/"wb")`). Neither file carries any update flag. A *semantic* classifier would call these
   scratch writes; the census excludes them only accidentally — neither the expected token nor
   the scratch token is on the `open()` line — so its `unflagged=0` is right for the wrong
   reason and proves no discrimination on live code. Mutant 3 shows the same line-local rule
   silently under-reports the identical form on a non-scratch path. The live corpus realizes no
   non-scratch expected-value write at all, so `live_unflagged` has no informative instance in
   either direction. (The tool docstring at `:7-9` declares non-same-line paths out of scope;
   the point is that `live_unflagged=0` cannot be read as "no unflagged expected writes".)
3. Behavioral coverage of the live path is nil: Mutant 2 proved `--selftest` and `mutant_killed`
   stay green while `--census` output changes. The sha256 pin is the only thing that kills a
   classifier defect; the pin freezes bytes, it does not validate the classifier. This matches
   the contract's own carve-out (`:29`) but is the depth boundary of the claim: the reported
   depth number is unauthenticated beyond the hash, and the frozen planted controls exercise only
   `classify_text` on one-line strings, never `census()` aggregation.
