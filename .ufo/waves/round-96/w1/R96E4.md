## Mismatches (6) — all systematic, none random

- **D01–D05 (all `exit=2 C1_SETUP rev-not-a-commit-id`, expected `__pass` exit 0):**
  Driver (`controls-v96.py:576,608`) invokes the mutant counter with `--rev HEAD`, but the v96 counter (`measure-v96.py:418`) refuses any rev that is not a 40-hex oid (`rev-not-a-commit-id`). The mutants therefore never execute. Proven by hand-running the D01 mutant counter against the `renamed-result` clone with its resolved HEAD oid `e316da57…`: exit 0, `C1_R96_PASS=true` — exactly the expected `__pass`. Root cause is the driver's `HEAD` literal combined with the round-96 counter's new rev guard.
- **`replace-honest` (`exit=2 C1_SETUP rev-not-a-commit-id`, expected setup token `replace-refs-present`):**
  Same `--rev HEAD` root cause — the counter dies on the rev guard before reaching the replace-ref check. Additionally the frozen `EXPECT_EXTRA` token `replace-refs-present` does not match the counter's printed token `replace-refs-present:lane` (`measure-v96.py:435`), so even with the rev resolved the grader's substring check would still fail.
