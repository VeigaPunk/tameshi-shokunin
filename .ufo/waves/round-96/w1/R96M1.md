## 2. Method

1. Extract `measure-v96.py` from the freeze object store (`git cat-file blob`); assert its sha256 equals the lane work tree bytes.
2. Apply each defect as **one edit** (D05 and the S02/S03 seal rows are the declared named multi-rule removals), asserting the anchor occurs exactly once. `prep=pin` recomputes `SELF_SHA256` for the edited bytes; `prep=nopin` (E01 alone) leaves the pin stale by design so the self-pin assert is exercised.
3. Build each battery state as a `git clone -q --shared` of the freeze, assert `git rev-parse --show-toplevel` equals the clone before every commit, materialise `states()[name]`, commit inside the clone. `rev-branch` adds a `master` ref; `rev-empty` stages an uncommitted pseudo verdict row; `rev-unresolvable` runs a 40-hex nonexistent id.
4. Run the pristine baseline, the mutant, and the restored pristine bytes on the same state clone; grade each against the state's expectation. KILLED = the mutant no longer satisfies it; SURVIVED = it still does; INCONCLUSIVE = the honest baseline itself does not.
