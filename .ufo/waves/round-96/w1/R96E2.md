## Defect F3 — rank fix (fresh receipt wins over a planted rerun)

v96 `controls-v96.py` grading loop, lines 625–630:

    found = None
    for cand in [n + ".out"] + ["%s.rerun-%d.out" % (n, i) for i in range(1, 50)]:
        p = os.path.join(a.outdir, cand)
        if os.path.lexists(p):
            found = p
            break

Candidate order is ascending (`<name>.out`, then `.rerun-1.out` … `.rerun-49.out`) and the loop `break`s on the first existing candidate, so the writer's fresh `<name>.out` always outranks any planted higher-index rerun.

v95 grading loop (at 0685c358) iterates the same ascending candidate list but with no `break` — `found` keeps being overwritten, so the highest planted rerun wins. Evidence (`R96E2-rerun-plant.out`): v96 prints `coverage-absent MATCH exit=1`, exit 0; v95 prints `coverage-absent MISMATCH exit=1 (read coverage-absent.rerun-9.out)`, exit 1.

## Defect F4 — O_NOFOLLOW read fix (symlinked receipt refused)

v96 grading loop, lines 635–652:

    try:
        _fd = os.open(found, os.O_RDONLY | getattr(os, "O_NOFOLLOW", 0))
    except OSError:
        ...
        lines.append("%s SYMLINK-REFUSED" % n)
        continue
    try:
        import stat as _stat
        if not _stat.S_ISREG(os.fstat(_fd).st_mode):
            raise OSError("non-regular")
        with os.fdopen(_fd, "r", encoding="utf-8", errors="replace") as _f:
            body = _f.read()
    except OSError:
        ...
        lines.append("%s NONREGULAR-REFUSED" % n)
        continue

The read opens the receipt with `os.O_RDONLY | os.O_NOFOLLOW` and additionally requires a regular file (`S_ISREG` on the opened fd); a symlink fails `O_NOFOLLOW` and is counted missing (`SYMLINK-REFUSED`, never a MATCH). The write side already used `os.O_NOFOLLOW` (line 372); the fix closes the read side too. Evidence (`R96E2-receipt-symlink.out`): v96 prints `coverage-absent SYMLINK-REFUSED`, exit 1; v95 (plain `open()`) follows the link and prints `coverage-absent MATCH exit=1`, exit 0.
