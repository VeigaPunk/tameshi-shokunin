## Mutant

Smallest behavior-bearing point: drop the two cases whose asserted count is 0 —
`bytes_flagged` and `replace_flagged` — from a scratch `fixtures.json`
(keys after mutation: `bytes_unflagged`, `replace_unflagged`, `scratch_replace`).

## Verdict

**KILLED — the selftest fails closed.** Deleting both flagged fixtures exits 1 and names both cases;
the absence is detected per key, not in aggregate. Mechanism: `selftest()` iterates a hardcoded `expect`
dict (`tools/write-path-census-v2.py:54`), reads `planted.get(name)` (`:63`), records `-1` plus
`FAIL missing fixture` for a non-string/absent body (`:65`), and returns `0 if not failed else 1` (`:84`).

The counter layer fails closed twice over on the same mutation: `measure.py:159` builds `got` from the
*remaining* keys only, so the `got['bytes_flagged'][1]` / `got['replace_flagged'][1]` accesses at
`measure.py:213-214` raise `KeyError` (observed by reproducing exactly those statements against the
mutated fixture — the counter was **not** run in default mode), and `measure.py:218` independently
requires `rc.returncode == 0`, which the selftest no longer returns.

## Coverage finding (adjacent mutant class, survives — reported, contract untouched)

Neutralizing the flagged fixtures instead of deleting them (`bytes_flagged: "x = 1"`,
`replace_flagged: "y = 2"`, i.e. no flag marker, no write site) gives
`bytes_flagged=0 replace_flagged=0`, `rc=0`. The selftest asserts only `unflagged == 0` for the flagged
cases, so a flag-free body is indistinguishable from a properly flagged one: the discriminator that the
flagged fixtures are supposed to exercise is not itself asserted. This is a coverage limit of the
selftest, not a pass/fail change to the frozen predicate (the counter's own `v1_misses` / live-site
checks are unaffected by it).
