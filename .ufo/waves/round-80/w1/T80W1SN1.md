## Findings: severity, exploit path, evidence, impact, minimal fix

### F1 HIGH — CRLF silently removes receipts

`receipt-bytes-bind.py:139–145,151–160` discovers receipts using regexes whose end anchors reject CRLF. A measured or design CRLF header alone yields `zero-receipts` (2). Alongside one valid LF control, each yields **exit 0, receipts=1 bound=1 corrected=0 design=0 unbound=0**: the CRLF file vanishes. A newline conversion can therefore hide an unbound declaration in an otherwise green sweep. Normalize CRLF before discovery/parsing, or refuse raw recognized prefixes rather than excluding the file; add mixed-newline population arms. **Must fix.**

### F2 MEDIUM — malformed conflicting declarations accepted as design

`receipt-bytes-bind.py:158–178` derives block presence from successfully parsed values, then validates raw prefixes only for the selected block's three fields. A valid design block plus malformed `# measured_rev: invalid`, `# tool: bad path`, `# tool_sha256: invalid` returns **design, exit 0**, despite mixed declarations. A valid marker plus a second `# measured_bytes: wrong` also returns **design, exit 0**. A reader sees contradictions that the counter ignores. Inventory all raw header prefixes first, validate counts/values across both blocks and the marker, then classify; add both refusal arms. **Must fix.**

### F3 MEDIUM — ambiguous live figure contradicts frozen exact-once contract

Plan C1 lines 63–65 requires exactly one live figure. `registry-figure-bind.py:210–213` selects `matches[-1]`. Toy stdout `TOY: 0/1 pass` then `TOY: 1/1 pass`, with a declaration of `TOY: 1/1 pass`, returns **match, exit 0**. A later token masks a contradictory measurement. Require `len(matches)==1` and add a two-live-token refusal arm. **Must fix.** This is a contract disagreement, not a judgment on the seven actual frozen rows.

### F4 MEDIUM — registry paths select external surfaces

`registry-figure-bind.py:135–144,151–153,173–175` accepts doc/registry fields with `..` or absolute paths. All four scratch probes report **match, exit 0**, reading surfaces outside their supplied fixture repo. A modified manifest can substitute an external registry home and produce a green measurement. Require repo-relative paths and resolved containment, including symlinks. **Must fix for custom-manifest confinement**, but unreachable through the current frozen manifest's `SKILL.md` / `tools/registry.json` paths. An externally supplied manifest file itself can remain an intentional CLI feature.

### F5 LOW / portability — Windows-style design paths accepted

`design_tool: ..\outside.py` and `C:\outside.py` both return **design, exit 0**; POSIX parent/absolute forms refuse (2). The guard at `receipt-bytes-bind.py:180` recognizes only slash separators. On Linux backslashes are literal filename characters, and design measurement never opens the tool: **no host traversal demonstrated**. This permits ambiguous/nonportable provenance. If the schema means POSIX git paths, reject backslashes and drive-qualified forms; add design-path arms. Not in the minimal Linux correctness must-fix set; absent from current design arms 11–13.
