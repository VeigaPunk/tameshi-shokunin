### 3.2 The residual dependence: locale **availability**, not locale value

Direct mechanism probes (`rc 0`):

```
$ python3 -I -X utf8 -c 'import sys;print("Xutf8",sys.flags.utf8_mode)'
Xutf8 1                                              # the flag forces the mode
$ env -i LC_ALL=en_US.UTF-8 PATH=/usr/bin:/bin python3 -I -c \
    'import sys;print("enUS -I",sys.flags.utf8_mode, sys.getfilesystemencoding())'
enUS -I 0 utf-8                                      # arm17's premise: a real UTF-8 locale
$ env -i LC_ALL=C PATH=/usr/bin:/bin python3 -I -c \
    'import sys;print("C -I",sys.flags.utf8_mode, sys.getfilesystemencoding())'
C -I 1 utf-8                                         # POSIX locale ENABLES UTF-8 mode
$ env -i LC_ALL=xx_YY.UTF-8 PATH=/usr/bin:/bin python3 -I -c \
    'import sys;print("bogus -I",sys.flags.utf8_mode, sys.getfilesystemencoding())'
bogus -I 1 utf-8                                     # unresolvable locale ⇒ C ⇒ mode 1
$ locale -a | grep -i en_US
en_US.utf8                                           # present on this host
```

So `python3 -I` (no `-X utf8`) yields `utf8_mode=0` **only** when the effective
LC_CTYPE resolves to a real UTF-8 locale. Battery E pins arm17 to an
uninstalled locale (`xx_YY.UTF-8` in the arm copy; `rc 0`):

```
CONTROL: GREEN (pristine 17/17 — the flag still forces 1)
DEFECT python-utf8-dropped: SURVIVED (exit=0)   ARM17: PASS
MUTATE: DONE (defects=1 killed=0 survived=1 kill-rate=0%)
```

**The kill is silent-green-fragile**: on a host without `en_US.UTF-8` (or with
`LOCALE_ARCHIVE`/`LANG` overrides that make it unresolvable inside the pinned
env) arm17 passes on the pristine bytes *and* on the mutant. This host has
`en_US.utf8`, so the landed arm kills today — measured natively and under
`LC_ALL=C`. Recommended hardening for the L1 (one arm, no new fixture): before
spawning, have arm17 assert its premise, e.g. run
`python3 -I -c 'import sys; assert sys.flags.utf8_mode == 0'` under `env6` and
report a named failure (`arm17-locale-unavailable`) when the pin does not
resolve, or pin `C.UTF-8` **and** assert. Either way the blind spot becomes
loud instead of green.
