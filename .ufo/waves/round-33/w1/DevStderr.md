# DevStderr — round 33 wave 1: output-channel tricks against the frozen tally audit v2

Seat: `DevStderr` (mutation tester, dev sweep). Scratch: `/fast/scratch/hyaku/tameshi-r33-seats/DevStderr`.
Lane bytes were never edited; every mutant is a separate copy of the frozen runner.

## Verdict

20 single-edit mutants. 13 are must-kill (11 by the tally block's exit code + first stdout line, 2 by the
runner's own selftest harness), 7 are behaviourally equivalent under the frozen oracle (exit code + first
stdout line). The tool **killed 12 of 13 must-kill copies and accepted all 7 equivalents**: no false
rejects, and the stdout-only rule is enforced in the direction that matters (all three verdict lines moved
to stderr are killed).

**One survivor — `M19-cr-fake-record`.** The copy is behaviourally different (witness vector
`0 0 0 0 0 0 0 0 0` gives `(0, 'junk')` against pristine's `(0, 'REGRESSION: PASS …')`), yet the tool answers
`TALLY_AUDIT: SETUP` (exit 2), not `TALLY_AUDIT: FAIL` (exit 1). The frozen C1 predicate requires exit 1 +
FAIL on every valid sealed must-kill copy (`contract.json:18`), and the counter's `score_tool` counts a kill
only when `rc == 1 and last.startswith('TALLY_AUDIT: FAIL')` (`c1-measure.py:198`). A SETUP is neither a kill
nor an accept, so a sealed kill copy of this shape scores a miss.

No stderr-channel survivor was found: stderr-junk copies are accepted (correct, stdout-only) and
stderr-verdict copies are killed (correct). The survivor is a **record-parsing** escape, not a comparison-
channel one.

## Survivor detail — `M19-cr-fake-record`

Exact edit (one insertion, old-string occurs once, at `tools/mutate-and-run.sh:1432`):

```diff
   local nlegs=9 npass=0 nfail=0 nsetup=0 st
+  printf 'junk\rR\t0\tfake\n'
   for st in "$st_js" … "$st_citecheck"; do
```

Witness vector `0 0 0 0 0 0 0 0 0` (the witness rule in `contract.json:18`: "a status vector on which the
mutated tally block's exit+first line differ from pristine"):

```
pristine block -> (0, 'REGRESSION: PASS (cases=9 passed=9; ledger legs exact: killed-delta<=0 flips<=0)')
M19      block -> (0, 'junk')
```

Tool, exact command and observed output:

```
$ timeout 300 python3 tool.py --runner mutants/M19-cr-fake-record.sh; echo $?
TALLY_AUDIT: SETUP (tally driver failed (exit 0, 4754/2377 results): )
2
```

Mechanism: the audit's driver emits one record per vector as `printf "R\t%s\t%s\n" …` (`tool.py:227`) and
parses with `out.splitlines()` (`tool.py:230`). `str.splitlines()` also splits on `\r`, so the carriage
return in the block's output cuts the record in two and the `R\t0\tfake` tail becomes a *second* record for
the same vector: 2377 vectors produce 4754 records. `len(got) != len(vectors)` raises `CannotAudit`
(`tool.py:231`), `main` prints `TALLY_AUDIT: SETUP` and returns 2 (`tool.py:600`). The audit never compares
anything; it declines to audit a copy that is plainly wrong.

Scoring impact: `verdict = (rc == 1 and last.startswith('TALLY_AUDIT: FAIL'))` (`c1-measure.py:198`) is false,
`kill_hit` stays 0 while `kill_total` increments, and C1 requires `ho_k == ho_kt` (`c1-measure.py:347`).
The same SETUP escape is reachable without the CR: any copy that makes the driver emit a different number of
records (for instance `kill -TERM $PPID` inside the block, since `$$`/`$PPID` inside the command substitution
name the driver shell) also lands on exit 2. The CR form is the purest instance because it needs output bytes
only.

## Notes that are not scoring defects under the frozen rule

1. **First-line-only comparison.** M12 (extra stdout line after the verdict) and M13 (a second, contradictory
   `REGRESSION: FAIL` line after a PASS) are accepted. Their blocks differ from pristine but not in
   exit + first line, so `ho_witness_ok` (`c1-measure.py:171-183`) cannot validate either as a kill copy —
   they are outside the sealed kill space by construction. The residual risk is for consumers, not the
   counter: a reader that takes the *last* `REGRESSION:` line would misread such a copy.
2. **stderr is unconstrained.** M03/M04 pass the audit yet break the runner's own `--selftest`, whose harness
   compares `out=$(bash "$root/tally.sh" 2>&1)` (`tools/mutate-and-run.sh:2004`). Measured on vector
   `2 0 0 0 0 0 0 0 0`: pristine first line = the SETUP verdict (exact match true); M03 first line =
   `tally: counting legs`; M04 first line = `.REGRESSION: SETUP …` — both exact-match false under `2>&1` and
   exact-match true under `2>/dev/null`. This is the price of the stdout-only rule, not a violation of it.

## Adjacent observation (not my verdict, not a counter run)

The frozen counter's `block_run` (`c1-measure.py:157-159`) sandboxes with
`--ro-bind script /x.sh --bind d /w --dev /dev --proc /proc` and then execs `timeout 60 bash /x.sh`, but binds
no system tree, so `/usr/bin/timeout` and `/usr/bin/bash` are not in the sandbox root. Reproduced here:

```
$ bwrap --unshare-all --die-with-parent --new-session --clearenv --ro-bind "$d/run.sh" /x.sh \
    --bind "$d" /w --chdir /w --dev /dev --proc /proc timeout 60 bash /x.sh; echo $?
bwrap: execvp timeout: No such file or directory
1
$ bwrap ... --ro-bind /usr /usr --ro-bind /bin /bin --ro-bind /lib /lib --ro-bind /lib64 /lib64 ... ; echo $?
hello
0
```

Every invocation returned `rc=1, first=''` for pristine and mutants alike, so on this host the counter's
vector-witness path (`ho_witness_ok` → `block_run`) cannot distinguish anything and would mark every vector
witness invalid. I ran no counter; this is a raw reproduction of its argv, flagged because it is cheap to
check before wave 2 and would otherwise look like a tool defect.

## Smallest safe correction

Do **not** change the frozen tool: the predicate pins its bytes (`9dbbce62…33a4`) and the counter refuses any
other bytes at REV. For a future versioned v3 only:

1. index the driver records (`printf "R%d\t%s\t%s\n" <i> …`) and compare per index; treat a duplicate,
   out-of-range or extra record as a **mismatch (FAIL)**, not as an audit error. Reserve `CannotAudit`
   (exit 2) for a driver that produced no record for an index at all.
2. independent of (1): make the runner's own harness compare stdout only (`2>/dev/null`), which also removes
   its acceptance of stderr-verdict blocks.

Until then this is a coverage note for the round lesson: one kill class (a copy that injects a record
boundary) escapes as SETUP.
