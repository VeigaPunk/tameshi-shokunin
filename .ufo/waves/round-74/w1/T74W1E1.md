## 5. Fixture-craft findings the L1 needs (C1 is not safe without these)

**(a) The base fixture's `seat_reports` listing never matches its own prefix.**
`fixture_rows()` keys the listing `(REV, 'wave')` but emits entries
`x/T1W1S00.md … x/T1W1S11.md, x/swarm-registry.json`. Every `seat_reports` row
carries `dir='wave'`, so `prefix='wave/'` matches no entry and every such row
measures `files=0`. Measured: base arm3 on pristine is
`drift[printed=11 files=0]` — its `drift` comes from an empty match set, not
from 11 vs 12. Consequence: **an arm15 built by merely appending
`x/nested/deep.md` to the existing listing reads `drift[printed=12 files=0]` on
pristine and on all three mutants** (column `arm15-dirwave` above), i.e. it kills
nothing and would trip kill rule (v). The arm must key its listing to the row's
own `dir` (`{(REV,'x'): SEAT_FILES + ['x/nested/deep.md']}` with `dir='x'`, or
normalise the entries to `wave/...`). Both proven keyings are in
`probe_matrix.py`; the working one is `arm15-dirx`.

**(b) Normalising the fixture does not change any arm 1–12 outcome.** With
entries rewritten to `wave/...`, base arm3 reads `drift[printed=11 files=12]`
(was `drift[printed=11 files=0]`): same `got='drift'`, same `ok`, for pristine
and all three mutants. So kill rule (iii) survives the fixture repair; only the
`detail` string changes. Measured for all four modules.

**(c) `SELFTEST_ARMS` is load-bearing.** Line 69 `SELFTEST_ARMS = 12`; line 475
`return 0 if passed == len(results) == SELFTEST_ARMS else 1`. Adding three arms
without bumping the constant prints `WAVE_RECONCILE_SELFTEST: 15/15 pass` and
returns **1**. The plan's after-state names both the line *and* exit 0, so the
constant must move to 15. [INFERENCE from the quoted line, not run.]

**(d) The module docstring becomes false on landing.** Lines 26–30 currently say
the delimited-token rule and the span-substring rule "are enforced on every row
but carried by NO arm of this suite … so the arm for it is a named next-round
carry". After arms 13/14 land that paragraph must be rewritten, or the file
ships a statement its own suite contradicts.

**(e) The L1's current `tools/wave-reconcile-mutants.spec` applies cleanly.**
Parsed with the runner's documented escapes (`\n \t \r \\`, fail-closed):
all three defects `old_count=1`, `noop=False`, `SPEC-ARGS: defects=3
