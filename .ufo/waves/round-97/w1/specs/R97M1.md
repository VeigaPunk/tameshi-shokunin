# R97M1 — mutation-tester — mutate the two instruments

## Target
The round's own tools (not the round-96 checker): `.ufo/evidence/round-97/c1/battery-bind.py` and `.ufo/evidence/round-97/c2/guard-inertia.py` at the freeze rev.

## Steps
1. Build a mutation table of 8-12 single-edit defect injections over the two tools (exact-string anchors from the committed bytes; use your own copies in scratch, never edit the lane). At least one per class: a check dropped, a comparison inverted, a count not incremented, a path/constant changed, an early `sys.exit(0)`, a silent exception swallow.
2. For each defect run: the tool's `--selftest`, and the tool's main command at the freeze rev (`battery-bind` with the driver pin; `guard-inertia` with the checker pin). Pre-register `expect: killed|survived` per defect before running, and record the observed line/exit.
3. Classify: killed = the tool's own selftest or main run goes red (nonzero exit or a different predicate line) AND the tool still runs (enumeration not lost). Survived = green with the same line. Report the survivors as gaps with the exact site.
4. Specifically test: `classify()` always returning `killed`; `run_matrix` printing the summary without the loop; `bind()` returning matched=len(expectations) without reading receipts.
