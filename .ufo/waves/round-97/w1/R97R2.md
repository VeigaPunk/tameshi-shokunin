## 2. Attack A (step 2) — a text difference that is not a verdict difference

Fixture checker (`c.py`): `print("VERDICT GOOD alpha-detail"); sys.exit(0)`. One row, edit

Receipts: `atk2-text-diff-expect-killed.out`, `atk2-text-diff-expect-limit.out`.

**Classification: no over-count.** `differs` (`G:194`) is `(mutant exit != pristine exit)` OR
`(declared token not in mutant text)`; it is not a text diff. A mutant whose only change is
unrelated text is `survived` under `expect=killed` and `limit` under `expect=limit`; it is
never counted `killed`.

The mirror case is real and is the wording's own limit surface: a mutant that **prints an
extra finding** while keeping exit 0 and the declared token is classified `limit`:

```

```

Here the manifest edit inserts `print("EXTRA FINDING: a finding the declared token omits")`
into the mutant before `sys.exit(0)`; the declared token and exit are unchanged, so the tool
calls it `limit`. The mutant's extra finding is outside the declared token, which is the whole
verdict surface.
