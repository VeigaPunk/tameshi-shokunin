## Disclosures / caveats

1. `K_GLOB` is KILLED by an uncaught `IndexError` inside the selftest's own print statement
   (`res['detail'][0]` on an empty list; the narrowed glob matches no governed ledger),
   not by a clean failed assertion. Exit status is 1, so the exit-status oracle records
   KILLED exactly as predicted; its traceback embeds the mutant's absolute path, which is
   why the merged `K_GLOB.out` is the one file that differs across workdirs. The counter
   and the runner both use exit status only, so the table is unaffected.
2. The host arm inherits the full host environment; only `TMPDIR` was redirected to scratch
   to honour the scratch-write rule. The selftest itself always runs `git` with an explicit
   identity and `-q`, so host git config produced no output difference.
3. The split-stream probe rebuilds the suite's sandbox (`$WORKDIR/sandbox-<id>` → its own
   dir) and runs the same `env -i` command; `$WORKDIR`/`$DEFECT_ID` are not read by the
   Python gate, only by the shell prelude.
4. Durations differ between sweeps (wall-clock); they are not part of the claim. The
   verdict/exit/id/sha columns are identical.
5. Frozen artifacts were only read. Nothing in the lane was written except this seat's
   files under `.ufo/waves/round-88/w1/`. Scratch
   `/fast/scratch/hyaku/tameshi-r88/T88L1` was removed by the driver's `trap`.
