## Findings

1. **K_GLOB is a genuine witness kill, not an accidental red.** Both checks are
   false before the crash (`gate:78,106,111`); the `detail[0]` print (`gate:115`)
   replaces the `0/2` tally with a traceback. The draft records the verdict as
   KILLED and names the traceback as an output artifact, so a later reader does
   not mistake it for a harness accident.
2. **The `fixture non-prefix` word is the fixture's outcome, not the check's.**
   `gate:114` prints `failed` when `red` is true (the guard rejected the edit) and
   `passed` when the guard accepted it. The draft states this before the table;
   without it the receipt lines read backwards.
3. **S_RED_FILES is gate-equivalent.** `red` is selftest-local and never read by
   the gate's exit path (`gate:111` vs `gate:149`); only a meta-fixture asserting
   `red` stays False when `files != 1` can kill it. The draft records this the way
   case 7 recorded CKIND.
4. **S_OFFSET_EQ is not merely a suite-net gap.** It corrupts the reported
   `first_divergence` (a real output field in the tree JSON/detail), so the draft
   treats the offset assert as a genuine behavioural test; the `--root --json`
   path is outside the current suite.
5. **The single-ledger fixture explains three of five survivors** (S_VACUOUS,
   S_OK_ALL, S_RED_FILES); the other two are the unasserted offset and the
   one-byte head slack. The gate's `--base-file` branch and the CLI `--root` path
   are wholly outside the suite (`gate:52-56,123-126`; the selftest calls
   `check_tree(repo, rev)` at `gate:105,110`).
6. **Receipt chain is consistent.** Pin sha = sweep target sha = landing pin sha;
   spec sha unchanged; the landing replay reproduces 10/10 with 0 flips, so the
   "sweep predates the leg" gap is closed by execution at the candidate revision.
7. **Bookkeeping is the L1's.** The S312 registry row is a working-tree edit (not
   in `28ec588`); S001's `used-by` cell does not yet list
   `corpus/knowledge/mutation-case-kake-ledger-guard.md`, while S312's does. The
   draft cites S312/S001/S006; landing must commit the row and extend `used-by`
   as the lane's convention requires (S006 only if the L1 keeps the
   witness-vs-accidental caveat).
8. **The L1 has already copied the draft into the corpus while this seat was
   finishing.** `corpus/knowledge/mutation-case-kake-ledger-guard.md` is an
   untracked working-tree file (16608 B, sha256 `8b13b180…42650`, mtime
   16:14:36) that matches the draft body but (a) removes the S006 clause from
