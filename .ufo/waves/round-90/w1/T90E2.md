## Disclosures and residual risks

- **D1 — fixture-head shape, not content.** The first fix-clone run (commit `9b01dd5e`, detached,
  no ref containing it) made two pre-existing active rows exit 2:
  `evidence-disposition-round18` and `evidence-disposition-round18-before`
  (`historical_input_unavailable: "detached HEAD 9b01dd5e… is on no branch or remote-tracking
  branch"`), summary `held=72/78`. The same bytes with HEAD reachable from a branch give `held`
  for both rows, and with the live lane's own anchor binding (`lane.branch=master`, `master` at
  the commit) both rows also hold. So the two rows are sensitive to the *landing topology*: the fix
  commit must be reachable from a local/remote-tracking ref, or `lane.branch` must stay set (the
  live lane has `lane.branch=master`, read-only inspected; `refs/heads/master` exists). This is a
  precondition for the C2 landing, not a content regression of the fixes.
- **D2 — `registry-check.py --root .` is live mode and writes into its root.** Each run left
  untracked `.ufo/evidence/round-15/attempt-N/` and `verification-N.json` in its clone (the tool
  documents this). That is why the fix state was re-run from a fresh clone: the repeat produced the
  same summaries and row set, so the writes do not steer the comparison. Nothing was written to the
  live lane.
- **D3 — `measure-c2.sh` fourth argument is a revision in LANE, not a path.** Passing a directory
  path as `MANIFEST_SRC` prints `C2_SETUP manifest-unreadable` and `C2_R90_PASS=false`, exit 2.
  The PASS receipt above uses the default (`MANIFEST_SRC=REV`), which is the correct form. Reported so
  no seat repeats the misuse.
- **D4 — base `measure-c2` uses the freeze manifest.** `tools/defect-bind-r90.json` does not exist at
  `4e1c10e0`, so the base run reads the manifest from `3485ceb0` (`manifest=pinned`, `rows=fail`,
  `registry=fail`) — the meaningful "before" state, matching the plan's
  `pre-freeze/controls/C2-nowork-base.out`.
- **D5 — scope.** This seat measures only the standing sweeps' state. It does not re-audit the C2
  predicate contents, the C1 counter, or whether the fixes actually repair items 1-4; another seat
  owns those. A green no-harm table cannot certify the repairs, only that they break no sweep.
- **D6 — frozen bytes verified before use.** `fixes.py` sha256 `3f1e0352…293e` and
  `measure-c2.sh` sha256 `6b0a7070…8ba6` match
  `.ufo/evidence/round-90/pre-freeze/instrument-sha256-v2.txt`; the manifest read by the counter hashes
