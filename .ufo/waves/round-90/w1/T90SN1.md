## Evidence per finding

### F1 — `fixes.py --target` is an unguarded write primitive (High)

`fixes.py` contains **no git call at all** (`grep -n git` → none), so it neither asserts a
toplevel nor can it be tricked into `git -C ""`; it simply appends to
`<target>/corpus/README.md`, `<target>/corpus/knowledge/kernel-witnessed-ledger.md`,
`<target>/corpus/lessons/round-89.md`, `<target>/SKILL.md`, rewrites
`<target>/tools/registry.json`, and writes `<target>/.ufo/evidence/round-90/c2/*.txt`.
Its own docstring (line 4) says the real lane is an intended target.

Measured, in scratch:

- **D3** — `--target ""` from a lane-shaped cwd: all five tracked files **and** both receipts
  written; `rc=0`; the target is not a git repository at all
  (`git rev-parse --show-toplevel` → `rc=128`). Output: `fixes written variant=pos
  registry_exit=2 selftest_exit=2`, `rc=0`.
- **D4** — sibling-lane shape (`corpus/README.md`, `corpus/knowledge/`, `corpus/lessons/round-89.md`,
  `SKILL.md`, no `tools/registry.json`): four appends, then `FileNotFoundError` at the registry
  read, `rc=1`, **no rollback**. Exactly `kaidoku-shokunin`'s on-disk shape (verified by `stat`:
  it has README, `corpus/knowledge/`, `corpus/lessons/round-89.md`, `SKILL.md`, no
  `tools/registry.json`); `kagi-shokunin` matches three of the four and receives a phantom
  `corpus/knowledge/kernel-witnessed-ledger.md` (append mode creates).
- **D5** — fleet-root shape: `FileNotFoundError` on `corpus/README.md`, **zero files created**.
  The real fleet root survives only because it has no `corpus/` directory (verified: `/home/vgpnk/Projects/shokunin/corpus`,
  `/home/vgpnk/Projects/shokunin/SKILL.md`, `/home/vgpnk/Projects/shokunin/tools/registry.json`
  all absent). That is luck, not a guard.

Exploit path for the wave: any seat that runs the landing generator with a mistyped or
copy-pasted path (`--target /home/vgpnk/Projects/shokunin/kaidoku-shokunin`) dirties another
lane's tracked corpus files; nothing in the round would notice, and the C2 counter would still
be measuring the clone rather than that lane. Anti-exploit in failure mode: the append-only text
is recoverable with `git checkout --` in that lane, but only if someone looks.

Smallest remediation: require `git -C <target> rev-parse --show-toplevel` to equal
`realpath(target)`, require a lane marker (presence of `tools/registry.json` and the pinned
`c1/measure.py` sha), refuse `--target ""`, and stage the edits in a temp worktree instead of
the caller's directory (the controls already pass a clone, so only the landing call needs the
escape hatch).

### F2 — re-running the committed drivers truncates the frozen receipts (High)

`controls.py:140-141` computes `outdir = <lane>/.ufo/evidence/round-90/pre-freeze/controls`
with no argument and `makedirs(..., exist_ok=True)`; `114`/`125` write each receipt with
`open(..., "w")`. `controls-c2.sh:12,16` is the same (`> "$OUT/$1.out"`). Neither checks
existence, neither has `--out`, neither has `--force`. The receipts are not reproducible:
each control's commit carries a fresh committer timestamp, so `clone_rev` in the first line
changes per run (frozen receipts show `CTL2-flip … clone_rev=04eb5116…`,
`C2-pos … clone_rev=b04b0680…`), i.e. a re-run rewrites the bytes *and* the recorded SHAs the
plan and lesson cite.

Worse, the combined path with F3: `controls.py:138` realpaths `--lane`, so `--lane ""` from the
lane itself resolves to the lane, and the driver then re-runs all 16 controls against the live
lane and overwrites all 16 receipts (+5 from `controls-c2.sh`). Same for the frozen `23` entries:
16 C1 receipts + 5 C2 receipts + summary + superseded dir.

Smallest remediation: make `--out` a required argument outside the lane, and refuse to run if
any expected `.out` already exists (or gate on `--force`). A `chmod a-w` on the frozen control
directory plus a `[ -w ]` refusal at start-up is a two-line variant for the L1.

### F3 — empty path arguments become cwd in the Python drivers (Medium)

Fleet precedent re-confirmed in this session (`D0`): `git -C "" rev-parse --show-toplevel` from
the fleet root prints `/home/vgpnk/Projects/shokunin`, `rc=0`; and
`python3 -c 'os.path.realpath("")'` prints the cwd.

- **D1** `measure.py --repo "" --rev HEAD --work <empty>` → the counter does not refuse; it runs
  `git -C <cwd> rev-parse` (`C1_SETUP git-failed:rev-parse --verify HEAD^{commit}`), i.e. an
  unset `$REPO` silently aims the counter at whatever directory the shell was in.
- **D2** `measure.py --repo <lane> --rev <bogus> --work ""` from an empty cwd → the **work check
  passes** (`work-not-empty-dir` is not hit); the run then dies only on the deliberately bogus
  rev. With `--rev` valid, `materialize()` would extract the fleet fixtures and write pristine/
  canary/mutant trees into the cwd.
- **D6** contrast: `measure-c2.sh ""` → `rc=1`, `line 18: 2: rev`; empty `WORK` → `line 18: 3: work`;
  `controls-c2.sh <lane> ""` → `rc=1`, `line 7: 2: scratch`. All three refuse **before any
  `mkdir`**, so no write precedes the refusal.

Smallest remediation: in both Python drivers, `die("empty-path-arg")` when the value is empty or
when `realpath(value) == os.getcwd()`, and require `--work` to lie under an explicit
`--scratch-root` (cheap: `os.path.commonpath`).

### F4 — the unpinned spec is executed before it is judged (Medium)

`measure.py:129` computes `spec_pinned`, then `131` parses it, `132-133` take `fleet`/`commit`/
`path` from it, `136` compares the gate to `g["sha256"]` (a value from the same spec — circular),
and `142` materializes. The `spec` conjunct only appears at `251`.

Empirical proof from the frozen controls, not from my probe: `CTL5-spec.out` (spec edited) still
prints **12 `C1_ROW` lines** and `C1_CONJUNCTS pin=true spec=false green=true canary=true …` with
`exit=1` — i.e. the entire 12-mutant sweep ran under an unaccepted spec, and the `pin` conjunct
reported `true` because the edited spec supplied the matching hash. `CTL12-pin.out` shows the same
shape (`pin=false spec=false`, all measurement conjuncts true).

Impact is bounded today: `C1_R90_PASS` is still false, so a forged spec cannot yield PASS. What it
does permit is spec-driven filesystem writes and subprocess execution from a committed state the
counter has already decided not to trust (the round's own threat model is a counterfeit committed
state). Together with F8 those writes can land outside `--work`.

Smallest remediation: refuse immediately after line 129 (`die("spec-mismatch")`) before parsing.
Note the receipt shape changes (`C1_SETUP spec-mismatch`, exit 2, instead of `spec=false`, exit 1),
so `CTL5-spec` and `CTL12-pin` would need re-baselining — a future-round change, not a wave edit.

### F5 — timeout kills one process, not the pipeline (Medium-Low)

`measure.py:86-90` uses `subprocess.run(argv, ..., timeout=timeout)` and maps `TimeoutExpired` to
`INCONCLUSIVE` (fail-closed for the verdict), but CPython kills only the direct child (`bash`).
The gate spawns `gawk`/`find`/`sort`; on a hang those grandchildren survive the kill and keep
running while `shutil.rmtree(md)` (196) deletes their cwd, for the remaining mutants of the sweep.
The probe did not trigger this (it would need a deliberately hanging gate); the claim is
code-level and matches documented `subprocess` semantics.

Smallest remediation: `start_new_session=True` on the `Popen`, and in the handler
`os.killpg(os.getpgid(p.pid), signal.SIGKILL)` then `communicate()`.

### F6 — C2 executes REV-supplied code with the operator's environment (Medium-Low)

`measure-c2.sh:31-35` exports only `TMPDIR` and inherits everything else; `32`, `34` run REV's
tools with it. `registry-check.py:148-170` (`git_env`/`row_env`) strips `GIT_*` and pins
`GIT_CONFIG_GLOBAL=/dev/null`, `GIT_TERMINAL_PROMPT=0`, `PYTHONDONTWRITEBYTECODE=1` — good — but
`HOME`, `SSH_AUTH_SOCK`, `AWS_*`/`GOOGLE_*`/`GITHUB_TOKEN`, proxy variables pass through to the
row's argv. `fixes.py:102-104` passes `dict(os.environ)` to the same two tools. The C1 counter,
whose job is to run code it has deliberately mutated, replaces the environment wholesale
(`measure.py:64-69`: PATH/HOME/TMPDIR/LANG/LC_ALL only, `HOME=work`, `TMPDIR=work/tmp`).

No leak was demonstrated. The point is asymmetry: the C2 counter certifies arbitrary committed
bytes (any seat's clone, any future fixture) and hands them the operator's identity material.
Smallest remediation: build the C2 conjunct environment the way `env_for()` does — `HOME="$WORK"`,
scrubbed `GIT_*`, no `SSH_AUTH_SOCK`, keep `PATH` — and let the lane tools opt in to anything else.

### F7 — the fix generator and its caller both ignore its exit status (Low)

`fixes.py:116` prints the two receipt exits and returns; there is no `sys.exit`. `D3` shows
`rc=0` with `registry_exit=2 selftest_exit=2`. `controls-c2.sh:25`
(`(cd "$r" && TMPDIR="$d" python3 -I "$FX" --target . --variant "$2") > "$d/fixes.log" 2>&1`)
has no `|| exit 3`, and line 26 commits whatever state exists. A fixture whose generator died
half-way is committed and measured as the positive control.

Backstop today: the defect-bind `receipt-tokens` row (`tools/defect-bind-r90.json:57`, receipt
`ledger-witness-selftest.txt`) fails when the receipt is missing or wrong, so a partial positive
control surfaces as `rows=fail` in `C2_SUMMARY`. That is a second-order catch, not the generator's
contract.

Smallest remediation: `sys.exit(0 if p.returncode == 0 and q.returncode == 0 else 1)` and
`( ... ) || { echo "fixes failed"; exit 3; }`.

### F8 — spec-derived path joins have no containment check (Low)

`measure.py:73` `sd = os.path.join(dest, os.path.dirname(gate_path))`, `78`
`gp = os.path.join(dest, gate_path)`, `104-110` witness `corpus/SOURCES.md`, `dirs`, `files`.
`os.path.join("dest", "/abs")` yields `/abs`; `..` walks out. The spec is hash-pinned, so this is
only reachable with F4 (an unpinned spec is used before the `spec` conjunct refuses). The same
applies to the `git archive` positional at 74.

Smallest remediation: reject spec paths that are absolute or contain `..`, and assert
`os.path.commonpath([realpath(dest), realpath(target)]) == realpath(dest)` before every write.

### F9 — `--only` typo is silently a no-op (Low)

`controls.py:145-153`: the submission loop is `if not a.only or name in a.only`. An unknown name
matches nothing; zero futures; `j.result()` loop is empty; exit 0, empty stdout. A re-verifier
would read that as "no failing controls". Smallest remediation: after the loop,
`if not jobs: raise SystemExit("no control matched: %r" % (a.only,))`, and assert the set of
printed names equals the requested set.

### F10 — bytecode written into the frozen tree (Info)

`c1/__pycache__/measure.cpython-314.pyc` (23201 B, 18:24) and `c2/__pycache__/fixes.cpython-314.pyc`
(9048 B, 18:28) exist inside `.ufo/evidence/round-90/`, ignored by `.gitignore:4` and absent from
`git ls-files`. Import-based re-use of a frozen driver mutates the frozen directory (Python writes
the cache next to a writable source). Smallest remediation: any importer uses `-B` /
`PYTHONDONTWRITEBYTECODE=1`, and the frozen tree is mounted/chmodded read-only while the round runs.

### F11 — dead control branch (Info)

`controls.py:103-104` `if name == "CTL15-coverage": pass`. The variant is already produced by
`controls.py:74` (README key dropped). No behaviour; delete on the next edit so a reader does not
assume the branch builds the coverage variant.

## Holds (verified, no finding)

- **Mutating git is always bracketed.** Every `clone`/`checkout`/`add`/`commit` is preceded by a
  toplevel assertion and never receives an empty or unchecked variable: `controls.py:92-107`
  (assert 95-97, `realpath` compared), `controls-c2.sh:21-26` (assert 23, `realpath -- "$r"`
  compared, `|| exit 3`), `measure-c2.sh:21-24` (assert 23, `|| exit` 2). `--lane`/`--scratch`/
  `LANE`/`REV`/`WORK` are `${n:?}`-guarded or built from a `mkdir`'d scratch path. The
  2026-11-06 `git -C ""` shape is **not** reachable in the two shell counters.
- **No shell injection surface.** No `shell=True`, no `os.system`, no `eval`; every subprocess
  argv is a list (`measure.py:53,86`; `fixes.py:103,110`; `controls.py:25,94`), and the shell
  drivers quote every expansion (`"$LANE"`, `"$M"`, `"$r"`, `"$d"`).
- **No hardcoded `/tmp`.** The only `/tmp` string is `measure.py:66`'s `os.path.join(work,"tmp")`;
  `TMPDIR` is exported into `$WORK/tmp` by `measure-c2.sh:30-31`.
- **Untrusted archives are extracted safely.** `measure.py:76` uses
  `tarfile.extractall(dest, filter="data")`.
- **Work directories cannot be clobbered.** `measure.py:123-124` and `measure-c2.sh:19` refuse a
  non-empty `--work`; the C2 checkout is `--shared`, so the lane's object store is only read.
- **Verdicts fail closed.** timeout → `INCONCLUSIVE`, differing runs → `UNSTABLE`, both are
  conjuncts; `trivial` treats a timed-out `validate` as trivial (rejects the mutant rather than
  passing it).
- **The C1 sandbox is sound for code it intentionally mutates.** `env_for` (`measure.py:64-69`)
  drops the inherited environment, pins `HOME`/`TMPDIR` inside `work`, `stdin=DEVNULL`, and the
  gate cwd is the mutant directory — no variable points back at the lane.
- **Nothing reads credentials, the network, or a URL.** Grep for `HOME|TOKEN|SSH|GIT_|netrc|curl|
  wget|http` across the five drivers finds only `HOME=work` (measure.py:67) and the shell
  counters' path handling. `fixes.py` makes no git call at all.

## Design note for the L1 (not a finding; needs a decision before landing)

The C2 landing is defined to add files **inside** the frozen tree: `fixes.py:105-114` writes
`<target>/.ufo/evidence/round-90/c2/registry-check-ledger-witness.txt` and
`ledger-witness-selftest.txt`, and the frozen manifest binds row `R89-4b`'s receipt to the second
of them (`tools/defect-bind-r90.json:57`). "Everything under `.ufo/evidence/round-90/` is frozen"
and "the landing generator must write two receipts there" cannot both hold literally. Either the
freeze language needs an explicit carve-out naming those two paths, or the generator takes an
`--evidence-dir` pointing outside the frozen tree and the manifest is re-pointed — which changes
the pinned manifest sha and therefore the C2 population. Today the files are absent at HEAD
(verified), so the carve-out is still free to state.
