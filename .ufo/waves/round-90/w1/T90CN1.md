## Method (what makes the numbers checks, not greps)

1. **Pin**: the gate blob is read from git objects and its sha256 compared with the spec before
   anything runs.
2. **Mutants**: each survivor is a single-edit scratch copy; `old` occurs exactly once, `new != old`,
   `bash -n` clean; all copies live under `/fast/scratch/hyaku/tameshi-r90/T90CN1` and are deleted
   on exit (mutate only scratch, never the fleet gate).
3. **Copy control**: a byte-identical pristine copy reproduces the original's `(rc, stdout, stderr)`
   on all 21 registries × 4 modes (84 runs) — the copy mechanism itself is not the variable.
4. **Differential**: original vs each survivor on all 21 registries in `census|validate|overdue|shared`,
   `--today 2026-11-06` (7 × 21 × 4 = 588 mutant runs). A lane is "hit" only if the gate's output
   tuple changes.
5. **Shape scan with the gate's own rules**: one gawk pass per registry that embeds the pinned gate's
   primitives (`trim`, `symbolic`, `separator_row`, `url_of`, 0–3 leading spaces, `## Registry`
   section only) — 25/25 copied fragments are asserted byte-present in the blob before use — and
   emits every in-section record with its line number. Class predicates run row by row, and C03/C09
   additionally replay the gate's E04/W04 duplicate-URL state machine in file order (old vs mutant
   URL/exemption), so "effective" means the row's verdict actually flips, not merely that the row
   looks like the class.
6. **Independent zero-checks**: C02 and C06, reported as 0, were re-counted with a second, separately
   written gawk parser; both returned 0 again.

Every class number below is consistent with the differential to the line (finding-code sums in
§ Cross-check), so the shape counts are not standing alone.

## Risks and limits

* **Units.** Rows ≠ findings (C12 1146 vs 1695). The table gives both so the case note can pick.
* **Shape vs behaviour.** C03 (415 vs 97) and C09 (2 same-scope vs 96 cross-scope) prove shape counts
  cannot be quoted as impact; only the `effective` column is impact.
* **Copy-fidelity.** The shape parser is a copy; it is guarded by the 25/25 verbatim-fragment check,
  the pristine-copy control, and the differential agreement to the finding, but it is not the gate
  itself. Any divergence would appear as a shape-vs-diff lane mismatch, which is printed.
* **Date pinning.** `--today 2026-11-06` fixes date-dependent checks; none of the measured surfaces
  (E11, E04, E09, W04, separator parsing) depends on the date, but reruns on other days should keep
  the same `--today` for comparability.
* **Moving target.** The fleet is live; row counts are pinned to the bytes seen at this run. The
  script re-derives them from the pinned gate and the current registries in ~22 s.
* **Scope.** I did not judge, admit, edit, or integrate anything; the gate, the fixtures, the plan
  and every `.ufo/evidence/round-90/` byte are untouched. My scratch dir
  `/fast/scratch/hyaku/tameshi-r90/T90CN1` is removed.
