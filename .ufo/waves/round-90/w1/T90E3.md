## Method (as executed)

1. Materialize a pristine copy from the fleet's object store, assert its blob sha256 equals the
   spec's pinned `3fb72615…4e30`.
2. Apply `T90E3-arms.patch` with `patch --batch --forward -p1`. The arms use only the gate's own
   `check` / `checkx` / `checkline` helpers and create their fixtures at runtime under the
   selftest's existing `$test_root`, exactly like the surrounding arms (no new checked-in
   fixtures).
3. Pristine + arms: `selftest` exit 0, `selftest ok`, all seven new arms `killed`.
4. For each mutant C01–C12: fresh pristine copy, apply the spec's `old`→`new` once (asserting
   `old` occurs exactly once and `new != old`), then apply the arms patch, `bash -n`, run the
   suite. For each of the seven survivors the suite must exit 3 **and** the arm drafted for
   that mutant must print `SURVIVED`; the other six arms must stay `killed`. For each of the
   five pre-registered KILLED mutants the suite must exit 3 and all seven arms stay `killed`
   (so the arms add no false kills elsewhere).
5. Scratch: `/fast/scratch/hyaku/tameshi-r90/T90E3` (trap `rm -rf` on EXIT); the directory is
   gone after the run. Nothing was written outside `.ufo/waves/round-90/w1/`.
