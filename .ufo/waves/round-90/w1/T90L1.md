# T90L1 — environment-invariance probe of the 12 C1 mutant verdicts

Target hypothesis H: *the 12 verdicts derived by the C1 counter are invariant to the host
environment knobs the counter pins (TZ, LANG/LC_ALL, PATH order, TMPDIR location).*
Falsification route: re-execute the pinned gate's own `selftest` on each of the 12 spec
mutants under a matrix of environments, independent of `measure.py`.

Result: **the probe did not falsify H.** All 12 verdicts are identical in all six
environments, twice each, with identical surviving-arm signatures; the derived table is
5 KILLED / 7 SURVIVED as pre-registered and as derived by the frozen counter at `33dd6e47`.

  lane is read-only for this seat)
- Raw output: `.ufo/waves/round-90/w1/T90L1-probe.out` (156 selftest executions)

## Method and pins

1. Materialized `scripts/sources-census.sh` + `scripts/fixtures/sources-census` at fleet
   commit `f47ad6ba8d306f8125597401cb2ce45c1297a593` from the fleet object store only
   (`git archive` / `git show`), into a scratch tree. The blob sha256 was verified equal to
   the spec pin `3fb7261569f46423dd80ecc23e0a23789a7926f667c7a3fc559d2439d4a64e30`; the
   spec sha256 was verified equal to `ce8983d577b1fa71afd1760b80304cba87c56ca339384df06eb2705a5bfde290`.
2. Applied each of the 12 spec single edits verbatim to its own scratch copy
   (`old` occurs exactly once — all 12 `occurrences=1`; `new != old`; no other byte
   changed). An earlier probe iteration that silently lost the fixtures was caught by the
   arm-count guard below, so no verdict rests on an early-exit; the emitted `MUTANT` /
   `VALID` lines record the application.
3. `bash -n` on all 12 mutated copies: ok.
4. Ran `bash <copy>/scripts/sources-census.sh selftest` **twice per (mutant, environment)**
   with cwd = the copy's `scripts/`, stdin `/dev/null`, `timeout 180`, under a fully
   rebuilt environment (`env -i`) so nothing leaks from the fleet shell. Verdict mapping is
   the counter's: `SURVIVED` iff every run exits 0, `KILLED` iff every run exits non-zero,
   `UNSTABLE`/`INCONCLUSIVE` otherwise.
5. Completeness guard: every run had to print 96 `killed`/`SURVIVED` arm lines and a final
   `selftest ok|FAILED` marker. All 156 runs: `arms=96,96`, 0 abnormal cells, 0 timeouts.
6. Pristine control (unmutated copy) run twice per environment: `rcs=0,0`,
   `selftest ok`, `arms=96,96` in every environment.

C05 — the most date-sensitive mutant — is instructive: its mutation (`>` → `>=` on
`opened_epoch>today_s`) makes the arm labelled `UTC-date-in-Sao-Paulo` fail under **every**
TZ, including Pacific/Kiritimati and the LANG-only E5, because that arm and every other
date-bearing arm calls the gate with an explicit `--today 2026-10-19`; the gate's defaults
use `date -u +%F` and gawk `mktime(..., 1)`/`strftime(..., 1)` with the UTC flag, so local
walls and local calendars do not enter. The one-day local-date shift in E2/E5 therefore
changes nothing, which is exactly what invariance of the C05 verdict requires.

## Limits (what this probe does not claim)

- It measures the pinned gate's `selftest` exit verdicts only. The counter's other
  conjuncts (note table, figure, source row, README coverage) are outside this probe.
- PATH *order* was exercised (E5 demotes `/usr/local/bin`); no shadowing binary with
  different behavior was introduced — that would test deliberate tool substitution, not an
  ordering knob. On this host `/bin` is `/usr/bin`.
- TMPDIR variation is path-level only, all on `/fast/scratch` (same filesystem) as the
  seat rules require; a different filesystem or world-writable `/tmp` was not tested.
- Wall-clock rollover was not crossed: UTC stayed 2026-11-06 through the 4 m 19 s pass, so
  the gate's `date -u +%F` default never changed between paired runs. Crossing UTC
  midnight mid-suite is a residual flake class, not one of the four knobs.
- Six environments, two runs per cell; not an exhaustive TZ × locale × PATH product.
  Within that matrix, 0 abnormal cells and 0 timeouts.
