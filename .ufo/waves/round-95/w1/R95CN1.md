## 3. UFO-FSD Connector Synthesis & Bounded Proposal

### Title
**Tab-Stop Expansion Normalization & Dual-Token Self-Pin Disposition Binding**

### Evidence & Synthesis Across Round Seats
1. **The Indented-Code Tab Trap (Scout R95S1 & Sibling Ground):**  
   In `measure-v95.py:91`, `INDENT_CODE_RE = re.compile(r"^ {4,}\S")` matches four or more literal ASCII spaces. However, CommonMark 0.31.2 §4.4 (S323, lines 2356–2364 opened by R95S1) explicitly specifies:  
   *"Tabs in lines are expanded to spaces, with a tab stop of 4 characters... An indented chunk is a sequence of non-blank lines, each preceded by four or more spaces of indentation."*  
   Sibling lane evidence in `tsukuroi-shokunin/tools/check-adjacency-overlap.py:250-251` demonstrates that robust Markdown parsing requires expanding tabs before measuring indentation:
   ```python
   expanded = source_line.expandtabs(4)
   indent = len(expanded) - len(expanded.lstrip(' '))
   ```
   Under `measure-v95.py`'s current regex, any documentation note using tab-indented code examples (`\t| C01 | KILLED |`) will fail `INDENT_CODE_RE`, causing the line to be evaluated as visible markup, triggering `stray-verdict` and falsely refusing an honest note.
2. **The Escaped-Pipe Column Discrimination (Executor R95E1 Finding):**  
   R95E1 demonstrated that the plan's frozen fixture for `escaped-backslash-pipe` (witness cell of row C01 ending in `C:\\`) does not discriminate under v94 vs v95 because trailing cell merges are tolerated by GFM S321 remainder rules. Shifting `\\|` left of the verdict column (into the arm or path column: `| C01 | fixture arm | C:\\|KILLED | differs |`) forces a cell-count divergence where v94 merges the arm and verdict cells (`width:cells=4`, `ids=false`), while v95 splits cleanly into 5 cells (`badrows=0`, `C01=KILLED`). R95E2 and R95E1 aligned on this row structure in `controls-v95.py:273-289`.
3. **The Unaudited Self-Pin Refusal Arm (Reviewer R95R1 & Executor R95E3 Gap):**  
   Round 95 C1 introduces two distinct refusal arms in `self_pin_state()`:
   - `self-pin-line-count` (refusal when `len(re.findall(SELF_PIN_RE, ...)) != 1`);
   - `self-pin-mismatch` (refusal when the normalized hash differs from `SELF_SHA256`).  
   In `controls-v95.py`, both arms have battery controls: `selfpin-edit` (`self-pin-mismatch`) and `double-pin` (`self-pin-line-count`).  
   However, in C2's disposition manifest (`conjunct-disposition.json:5-9`), the `selfpin` conjunct is mapped **only** to `selfpin-edit` with token `"self-pin-mismatch"`:
   ```json
   "selfpin": {
     "state": "selfpin-edit",
     "mode": "setup-refusal",
     "token": "self-pin-mismatch"
   }
   ```
   The C2 disposition audit is therefore completely blind to whether the newly added line-count refusal arm works. A regression or mutant that disabled the line-count check (reverting to round-94's multi-pin vulnerability) would pass C2 with `findings=0`.
4. **Replace-Ref Setup Refusal Precedent (Mado R67 & Souji R67/R68):**  
   In `mado-shokunin/corpus/knowledge/replace-ref-citation-boundaries-r67.md:54` (H06), the fleet documented that `GIT_NO_REPLACE_OBJECTS=1` bypasses replacements for reads but does not hide or delete them from the repository. Tameshi's C2 checker is the first to implement the logical conclusion of H06: an automated setup refusal on `git -C <lane> replace -l` (`replace-refs-present` exit 2).

### Affected Axes
- **Coverage (C1 - Verification-Fixture Craft):** Expands note reader presentation coverage to full CommonMark §4.4 compliance by honoring tab stops (`\t` expanding to 4-space stops), preventing spurious refusals on tab-formatted code blocks.
- **Calibration (C2 - Verification-Fixture Craft):** Closes the calibration gap between C1's added multi-pin protection and C2's disposition audit by requiring *both* self-pin refusal tokens to be certified against committed object-store receipts.

### Proposed Move
Incorporate a 2-point craft synthesis:
1. **Tab-Stop Expansion in `block_lines()` (`measure-v95.py`):**  
   In `block_lines()`, normalize line indentation using `.expandtabs(4)` before matching `LIST_RE` and `INDENT_CODE_RE` (matching `tsukuroi-shokunin/tools/check-adjacency-overlap.py:250` and CommonMark §4.4):
   ```python
   expanded = raw.expandtabs(4)
   if LIST_RE.match(expanded):
       list_open = True
       vis.append((idx, raw))
       continue
   if INDENT_CODE_RE.match(expanded):
       if list_open:
           vis.append((idx, raw))
       continue
   ```
   This ensures literal code blocks indented with tabs are correctly identified as literal text without affecting the raw line content returned in `vis`.
2. **Dual-Token Refusal Binding in `conjunct-disposition-v95.py` & Manifest:**  
   In `conjunct-disposition-v95.py`, extend `setup-refusal` mode so that `token` can accept either a single string or an array of `(state, token)` pairs:
   ```json
   "selfpin": {
     "mode": "setup-refusal",
     "refusals": [
       {"state": "selfpin-edit", "token": "self-pin-mismatch"},
       {"state": "double-pin", "token": "self-pin-line-count"}
     ]
   }
   ```
   The checker verifies that both receipts exist in the object store, both carry the matching `counter_sha=`, and each prints its respective `C1_SETUP` token.

- **Contract & Conjunct Invariance:** The 19 conjunct keys in `C1_CONJUNCT_KEYS` remain identical; the 17 falsifiable and 2 unfalsifiable counts are strictly preserved.

### Verification Protocol
1. **Tab-Expansion Test:** Run `measure-v95.py` against a fixture note containing a tab-indented table (`\t| C01 | KILLED |`); verify that with `.expandtabs(4)` it passes with `badrows=0` (exit 0), whereas without it fails with `stray-verdict` (exit 1).
2. **Dual-Refusal Selftest:** Run `conjunct-disposition-v95.py --selftest` with a case where `double-pin` is missing or fails to print `self-pin-line-count`; verify that it triggers `finding token-absent`.
