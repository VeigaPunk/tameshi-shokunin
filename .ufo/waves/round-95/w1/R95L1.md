## Boundary probe — "an indented line is literal unless it continues a list item"

The plan's declared limit is the boundary of A2. Three probe notes were built by
appending to the honest note and committing each in the scratch clone (plumbing only:
`hash-object`/`read-tree`/`update-index`/`write-tree`/`commit-tree`; receipts
`R95L1-runs/probe-fixtures.diff`, `R95L1-runs/note-*.md`, `R95L1-runs/revs.txt`).

| probe | appended bytes | counter | exit | `badrows` | `verdict_tables` | key line | reading |
|---|---|---|---|---|---|---|---|
| list-continuation | `- boundary probe list item` then `    \| C01 \| KILLED \|` | combined (v95 parser) | 1 | 1 | 1 | `stray-verdict:366` | **it keys it** — a verdict row that continues a list item is not literal |
| list-continuation | same | A2 fix alone | 1 | 1 | 1 | `stray-verdict:366` | attribution to A2 alone |
| list-continuation | same | real v95 snapshot | 1 | 1 | 1 | `stray-verdict:366` | the shipped reader agrees |
| indent-literal | `A paragraph line ends the list.` then the same 4-space row | combined | 0 | 0 | 1 | `C1_R94_PASS=true` | literal when it does not continue a list item |
| indent-literal | same | pristine v94 | 1 | 1 | 1 | `stray-verdict:366` | the exemption is new (before state) |
| no-local-continuation | the 4-space row at the note's end, no list before it | combined | 0 | 0 | 1 | `C1_R94_PASS=true` | `list_open` does not leak from the note's earlier lists |

The constructed rule, stated exactly as implemented: a line matching `^ {4,}\S` is not
visible unless a `list_open` flag is set; the flag is set by a visible non-blank line
matching `^ {0,3}(?:[-*+]|\d{1,9}[.)])\s`, survives blank lines, and closes on a
visible non-blank line at indent < 4 that is not itself a list item. The v95 snapshot
states the same closing rule in its `block_lines` docstring and implements it
identically (next section). The boundary answer requested by the seat: **yes — a
4-space-indented verdict row that continues a list item is keyed, and the note is
refused with `stray-verdict`.**

## Limits and honesty

- **What is verified.** Five built counters (four single fixes, one combination) and
  the pristine v94 counter each ran the full twelve-mutant battery plus the note reader
  against the honest note at `02ff6290`; all six exited 0 and printed byte-identical
  stdout. The combined variant's parser regions are semantically identical to the
  uncommitted v95 draft snapshot, which was also run on the honest note and on the
  list-continuation fixture.
- **What is inference.** The single fixes' inertness is also explained by the note's
  form (no indented-code lines; backslashes only inside fences and never beside `|`;
  three-hyphen delimiters; one pin line) — the explanation is derived from the note
  bytes and the parser text, but the measured identity is the run output, not the
  explanation.
- **Scope of the boundary probe.** The literal-vs-continuation answer depends on the
  `list_open` closing rule; the rule is stated above and matches the v95 snapshot's
  docstring and code. Probes use the note's own ending (a list item with an
  indent-2 continuation), so the `no-local-continuation` control also tests that the
  flag does not leak from earlier list items.
- **Not run here.** No check of the five C1 control states (R95R1/E2 own those), no
  C2 work, no mutation matrix. The v95-supplemental run is supplementary, not one of
  the five required runs; its exit 1 is the absent round-95 lesson (`source=false`),
  and its note-reader fields match pristine.
- **Repository hygiene.** No lane file was edited outside `.ufo/waves/round-95/w1/`;
  no commit, ref update, stash, checkout in the lane; no `git replace` entry; the only
  git writes were loose objects and synthetic commits inside the scratch clone. The
  fleet repo was read-only (`git cat-file`/`archive` by the counter's sealed env).
- **Tooling.** None installed or upgraded; no pacman transaction (paused host-wide).
  Python 3.14.8, git 2.56.0 were already present.
- Scratch `/fast/scratch/hyaku/tameshi-r95/R95L1` was deleted before this seat yielded;
  the fixture notes and their exact append diffs are preserved in the receipts so the
  probes can be rebuilt.
