## 1. Method

For each of the twelve rows the driver (`R95E4-driver.py`, in this directory)
runs the protocol round 94's mutation study used, with the frozen v95 instrument:

1. clone the lane at `3ca1981a` (`git clone --shared`, `rev-parse --show-toplevel`
   asserted equal to the clone before any commit);
2. materialize the battery state the round-94 driver paired with the rule
   (`controls-v95.py` `states()["<state>"]`), commit inside the clone under
   `ctl <ctl@fixture.invalid>`;
3. run the **pristine** counter extracted from the object store and grade it with
   the battery's own pre-registered expectation (baseline);
4. write the row's single edit into a scratch counter copy, recompute
   `SELF_SHA256` (all twelve rows had `prep=pin` in round 94), run it on the same
   state and grade it the same way;
5. restore the exact pristine bytes into the mutant path, verify the sha256, and
   re-run the restored bytes on the same state;
6. where the battery has no state that can expose the rule, build a purpose-made
   **isolation state** (P09/P10 share one; P13/P15/P16/P20/P26/P29/P30), or use
   one of the battery's own states as the construction attempt (`gate-foreign`
   for E05, `spec-shape` for E32). Run the pristine and mutant counters on it and
   record which conjuncts refuse. Isolation states are labelled
   `no-expectation`; they are not battery members and are not counted in the
   battery's 50-control tally.

Every state repo is a scratch clone; `rev-parse --show-toplevel` was asserted
after each commit. No `/tmp` path is cited; the driver's `TMPDIR` is inside the
scratch tree.

## 4. Why each classification

**E04 green — subsumed by `pins` (and `inconclusive0`/`figure`/`mismatched0`).**
`green` is false only on the battery's `timeout` state, whose spec edit
(`timeout_s=0.001`) also changes the spec bytes and therefore fails `pins`
(`spec_sha256` in `pins.json` no longer matches), and whose gate never finishes
in time so `figure`, `mismatched0` and `inconclusive0` also fail. The mutant's
`green=false→true` moves none of them: exit 1 both, battery MATCH. The only lever
that moves `green` without touching the pinned gate is a spec edit, which `pins`
refuses.

**E05 canary — invariant-pinned by `GATE_COMMIT`/`GATE_SHA256`.** The canary is
computed from the gate bytes anchored in the counter's self-pinned constants
(`GATE_COMMIT f47ad6ba…`, `GATE_SHA256 3fb72615…`). The construction attempt —
the battery's `gate-foreign` state, which repoints the spec at a foreign gate —
is refused at setup with `C1_SETUP gate-identity-mismatch` (exit 2) for both the
pristine and the mutant (`E05-gate-foreign.out`), so the rule never reaches a
foreign gate. On `pos-real` both print `C1_R95_PASS=true` (`E05.out`). See F1 for
the one observed `canary=false`, an intermittent timing artefact on `timeout`.

**E09 unstable0 — subsumed by `mismatched0`.** The battery's `timeout` state
derives INCONCLUSIVE twice, so `unstable` is 0 and removing `unstable0` moves
nothing. The isolation state P09P10 puts a deterministic alternating mutant in
the spec (selftest run 1 exits 0, run 2 exits 1): two runs derive UNSTABLE, so
the pristine fails `mismatched0` and `unstable0`; the mutant (`unstable0=True`)
still fails `mismatched0`, because the note's twelve cells can only be
KILLED/SURVIVED and an UNSTABLE row can never match a cell. Exit 1 both
(`E09-P09P10.out`).

**E10 two-run count — subsumed by `witnessed` (and `mismatched0`/`unstable0` on
the pristine side).** On the same P09P10 state, forcing `runs=1` makes C02 derive
the first run's SURVIVED, which matches the note (`mismatched0` true) and hides
UNSTABLE (`unstable0` true), but the mutant's validate-mode witness is unchanged
(`same`), so `witnessed` (6 != 7) refuses: exit 1 both. The two-run pristine
refuses via `mismatched0`+`unstable0`. Removing the second run changes the
refusing conjunct, never the verdict.

**E13 out-of-set — subsumed by the id-set-equality half of `ids`.** The committed
`hidden-c001` state is refused by `verdict_tables` (a second verdict table) and
by `ids` (bad rows). P13 puts an out-of-set id (C99) inside the single verdict
table: the pristine refuses with out-of-set (`ids=false`); the mutant keys C99,
and `set(note_rows) == spec_ids` still fails, so `ids=false` again — identical
conjunct set and exit 1 in both runs (`E13-P13.out`).

**E15 position — subsumed by `dup` in the committed state and by `mismatched0`
in isolation.** The committed `position` state carries the extra `C12` row, so
`dup` refuses first (pristine bad rows include `position:21:C12` and
`dup:21:C12`; the mutant's only `dup:21:C12`). P15 removes the duplicate and puts
every row's token in the witness column: the pristine refuses via `position`
(`ids=false`); the mutant keys `cells[vcol]="differs"` as the verdict, so no note
cell equals the derived verdict and `mismatched0=false`. Exit 1 both
(`E15-P15.out`).

**E16 width — subsumed by `position`.** The committed `sharp-width-lastrow` row
is a duplicate C12, refused by `dup`. P16 uses a non-duplicate over-wide last row
carrying two verdict tokens: the pristine refuses by `width`, the mutant by
`position` (`len(toks)!=1`); `ids=false` and exit 1 in both (`E16-P16.out`).

**E20 figure anchoring — ungraded (state-coverage gap).** No battery state
embeds `measured: K/N killed` in a longer line, so `pos-fixture` passes both.
P20 replaces the figure line with `The run recorded measured: 5/12 killed
overall`: the anchored pristine finds no figure (`figure=false`, exit 1) while
the unanchored mutant finds it (`figure=true`, exit 0, `C1_R95_PASS=true`). The
rule is load-bearing and no other check refuses that state, so the gap is the
battery's state set (round-94 B4's missing state).

**E26 coverage own-cell — ungraded (state-coverage gap).** No battery state names
a longer path containing the note path, so `pos-real` passes both. P26 appends a
LAST `corpus/README.md` row naming
`knowledge/mutation-case-fleet-sources-census.md.bak` with a denial: the own-cell
pristine ignores it (`coverage=true`, exit 0) while the substring mutant picks it
as the last naming row and reads the denial (`coverage=false`, exit 1). The
round-94 B4 state is still absent.

**E29 trivial detector (`rc is None` arm) — subsumed by `figure`/`mismatched0`/
`witnessed` (and `inconclusive0` for a global hang).** The battery's `timeout`
state moves nothing but the intermittent canary. P29 makes C01's `validate` hang
on the clean-lane path (70 s): the pristine marks it trivial (`trivial0=false`,
exit 1). Without the `rc is None` arm the mutant is measured, but a
selftest-green hang mutant derives SURVIVED against the note's KILLED cell, so
`figure`, `mismatched0` and `witnessed` still refuse (exit 1); a global hang
would derive INCONCLUSIVE and `inconclusive0` would refuse. No construction of
this arm lets the mutant pass its state (`E29-P29.out`).

**E30 one-verdict-column — ungraded (masked battery state, B2).** The committed
`sharp-two-verdict-cols` state builds a 5-cell header over `note_text()`'s fixed
4-cell delimiter, so the delimiter rule refuses first (pristine bad rows
`verdict-cols:7:2` + `delim:7:header=5,delimiter=4`; both runs `ids=false`). P30
builds a five-cell delimiter for the five-cell header, rows carrying one token in
the first verdict column: the pristine refuses via `verdict-cols` (`ids=false`,
exit 1) while the mutant keys all twelve rows and passes (exit 0,
`C1_R95_PASS=true`). No other check refuses that state: the rule remains
ungraded (the round-94 B2 state is still the masked defect).

**E32 spec-count half — subsumed by the unique-id half of `spec`.** On
`short-spec` (11 mutants) the mutant still fails `spec` because
`len(spec_ids)==N_MIN` fails; on `spec-shape` (12 entries, one duplicate id) both
pristine and mutant fail `spec` via the same unique-id half (plus `ids`,
`mismatched0`, `pins`). The removed count half is redundant.

## 6. Findings

**F1 — the `timeout` state's `canary` is not a constant under the matrix's mixed
load.** In the final matrix run, the E04/E09/E10 baselines and the E29 baseline print
`canary=false` while every other conjunct and all twelve `C1_ROW` lines are
identical to the runs that print `canary=true` (the mutant or restored arm of the
same state). 24 controlled reruns of the same state bytes — six sequential,
twelve concurrent, and eight `pos-real` + six `timeout` mixed — all printed
`canary=true` (`F1-canary-race.out`), so the flip is an intermittent
host-scheduling artefact of the 0.001 s `timeout_s` knob, not a deterministic
state property. No graded conjunct moved and all twelve battery rows still
matched. This does not falsify the C2 canary row (the pinned gate bytes are what
the canary reads); it does mean a pre-freeze battery run on `timeout` can print
`canary=false` and that the `timeout` state is not a dependable canary witness.

**F2 — the v95 battery kills none of the twelve.** The five states added over
round 94's forty-five are four PASS presentation fixtures
(`indent-code-row`, `indent-token`, `escaped-backslash-pipe`,
`two-hyphen-delimiter`) and one setup refusal (`double-pin`). A permissive
single-edit removal still satisfies a PASS fixture, and none of these states
names a verdict/reader rule, so the battery's 50 pre-registered controls (41 state
fixtures + 9 `EXPECT_EXTRA` controls) grade none of the twelve rules under test. This is a state-coverage fact, not a counter defect.

**F3 — three rules remain ungraded by every committed check.** E20 (figure
anchoring), E26 (coverage own-cell) and E30 (one-verdict-column) each have an
isolation state where the mutant passes where the pristine refuses (or the
reverse) and no other check catches it. These are the round-94 B2/B4 routed
states that round 95 did not add; `ungraded` names exactly that.

**F4 — the masking defects B1–B3 still hold.** `position` is masked by `dup`,
`width` by `position`, `one-verdict-column` by the delimiter rule. E13/E15/E16
are nevertheless genuinely subsumed (the isolating state is still refused by
another check); E30 is only masked: the isolating state passes the mutant.

## 7. Limits and risks

- Single-edit removals only, one state per rule; this says nothing about
  arbitrary weakenings or combinations.
- The isolation states are constructions in scratch, not battery members. Their
  receipts are labelled `no-expectation`; they are not counted in the battery's
  50-control tally and no receipt claims they are pre-registered.
- `ungraded` is not one of the plan's three names. It is used only where none of
  the three applies — no battery state and no other check refuses the rule — and
  the discriminating construction is shown so the gap is actionable.
- E04/E09/E10 restored arms: the restored bytes hash to the pristine sha
  `5f0d1770…` and reproduce every graded conjunct and every `C1_ROW` line; the
  only stdout delta is the intermittent `canary` of F1 (`restored_note` in the
  results JSON).
- The instrument is the committed freeze revision `3ca1981a` (the battery's own
  discipline: counter, lesson, spec, pins and sources read from the object
  store). After this matrix run the lane advanced to `f219fb0c` (lesson S323
  anchor edit) and `plans/round-95.plan.md` carries an uncommitted 25-line
  addition written by another seat; neither is this seat's write and neither
  changes these receipts, which read `3ca1981a`. The only tracked modification in
  the lane at yield is that `plans/round-95.plan.md` entry; this seat wrote only
  the `R95E4*` wave-dir files.
- No lane file was modified: `git status --porcelain` shows no tracked change and
  only untracked wave artifacts.
