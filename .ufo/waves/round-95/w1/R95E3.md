## Risks / open items

1. **The positive is against synthetic receipts.** The real E2 battery receipts are not
   in the lane yet. At integration the frozen counter must be re-run at the commit that
   contains `measure-v95.py`, the manifest and
   `.ufo/evidence/round-95/pre-freeze/controls/*.out`; each of the 17 state-row receipts
   must carry `counter_sha=<sha256 of the committed counter blob>`. If E2's receipts bind
   a different counter revision, the checker will (correctly) print
   `receipt-counter-sha-mismatch` for every row. This is the one integration dependency.
   E2's final `controls-v95.py` (sha256 `b1a94edd…f441699`, read after their note) has
   `COUNTER_PATH = ".ufo/evidence/round-95/c1/measure-v95.py"` at line 39, and its
   `run_ctl` writes the frozen counter digest into every state receipt; only the
   `D01`–`D05` receipts carry a mutant digest, and none of those is a manifest state.
2. The `counter_sha=` line binds a receipt to the counter bytes, not to the driver run
   that produced it (declared limit in plan §C2). A hand-written receipt that is committed
   at the audited revision with the correct digest passes; the forge only proves that
   *uncommitted* and *mis-bound* receipts do not.
3. `--receipts` is an audit parameter. A caller can point it at another in-repo receipts
   directory; the checker will audit whatever tree it is given (reviewer probe
   `R95R2-forge/seal/alt-receipts-v95.out` shows findings=0 on a valid alternate tree).
   Authenticity of the manifest and of the chosen tree is bound by the `claims.json` sha
   check (kill rule d), not by this checker.
4. The manifest row discrepancy in the seat-spec parenthetical (`green` vs `unstable0`) is
   documented above; no row was changed. If L1 intends `green` to be unfalsifiable, that is
   a new declaration that needs a state which flips `unstable0=false`, which no instrument
   in this round produces.
5. Nothing else is blocked. No pacman transaction was run; no tool was installed
   (Python 3.14.8, git 2.56.0 were already present). No `/tmp` path is hardcoded in either
   committed tool; the selftest uses `tempfile` under the caller's `TMPDIR`.
