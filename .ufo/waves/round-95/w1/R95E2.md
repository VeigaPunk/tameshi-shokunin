## Fixture precision: the spec's first `escaped-backslash-pipe` wording does not discriminate

Measured, not inferred (`R95E2-fixture-discriminate.out`):

- Literal first wording — four-column `note_text()` whose C01 witness cell ends
  `C:` + two backslashes + ` |` — gives **4 cells under both** readers; v94 prints
  `C1_R94_PASS=true`. Cell counts alone cannot make it a control (a trailing merge is
  tolerated by v94, and v95 yields the same width).
- Plan §Amendments A1 (binding, pre-data) pins a **five-column** note and the C01 row
  `| C01 | fixture arm | C:` + two backslashes + `|KILLED | differs |`. Measured:
  v94 `rows=11 bad=['width:9:cells=4'] C01=None` (exit 1, `ids=false`); v95 `rows=12
  bad=[] verdict_tables=1 C01=KILLED`. Delivered fixture is exactly this row; it also
  keeps the spec's `C:\\ |`-shaped cell end inside the path cell.
- Plan §Amendments A2: decoy pin line **before** the real line. Measured with
  `--conjuncts`: v94 exit 0 (`C1_CONJUNCT_KEYS …`), v95 exit 2
  `C1_SETUP self-pin-line-count`. A decoy inserted after the real line makes the decoy
  the executed constant and v94 dies `self-pin-mismatch` (non-discriminating); the
  delivered block inserts before.

vs 4 cells with verdict in column 4) in `R95E1-backslash-e2row.out`.

## Risks / caveats (for L1 and the reviewers)

- **Freeze-run preconditions.** The driver's fixtures are built from the lane work tree
  (`NOTE`, `LESSON`, `READY`, `SRC`). The freeze battery must run with the integrated
  `corpus/lessons/round-95.md` and the S320–S323 `SOURCES.md` rows present in the work
  tree, not only at `--rev`; otherwise `states()` raises on the missing lesson. My dry
  run used a provisional lesson because SC1's drafts had not landed — the 50/50 result is
  a wiring proof of the battery, not the freeze receipt.
- **`source-noquote` coupling.** That carried fixture removes lesson lines containing
  the round-94 S322 sentence “A fenced code block begins with a code fence, preceded by
  up to three spaces of indentation.”; it measured `source=false` only because the
  provisional lesson carries that exact sentence (as the round-94 lesson did). SC1's
  draft `.ufo/waves/round-95/w1/SC1-lesson.md` (landed after my runs) carries it once
  (`grep -c` = 1) on its S322 Gate line, so the state stays discriminating if L1
  integrates that draft; a lesson that drops the sentence would make it a no-op and
  MISMATCH at freeze, and it is a pre-registered state I may not re-key without L1.
- **Mutant `counter_sha`.** Per E2 spec item 2 the five D0x receipts declare their mutant
  file digest. A C2 check that compares *every* receipt's `counter_sha` to the counter
  blob would flag those five; E3's manifest state list excludes them, but the plan's C2
  sentence “the 50 committed battery receipts each carry the matching `counter_sha=`”
  should be read against the `mutant=` tag or amended.
- **Scratch rev, not instrument rev.** All receipts cite scratch commit `8ee48acf…`;
  the freeze must re-run at L1's instrument revision, where `pins.json`/`SOURCES.md`
  bytes may differ. Nothing here was committed by me.
- **Spec-internal conflict resolved by the plan amendments.** The E2 spec's original
  four-column `escaped-backslash-pipe` construction is non-discriminating (measured
  4/4 cells, v94 passes); the delivered fixture is plan §Amendments A1's five-column
  row, which reproduces the declared before-state (`width:9:cells=4`, exit 1).
