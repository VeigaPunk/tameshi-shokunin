## 2. Method

1. Extract `measure-v95.py` from the fixture rev with `git cat-file blob` (never a
   work tree); sha256 asserted equal to the lane's final bytes.
2. Apply each defect of `R94M1-defects.txt` as **one edit**, asserting the anchor
   occurs exactly once in the v95 text **before** any run. 37/38 anchors are the
   round-94 text verbatim; the only anchor that moved is E01, whose round-94
   `if not selfpin: die(...)` is now `self_pin_state()` + a token die, so the
   rule-equivalent v95 edit is:

   ```
   old:  selfpin_state = self_pin_state()
         selfpin = selfpin_state == "ok"
         if not selfpin:
             die(selfpin_state)
   new:  selfpin_state = self_pin_state()
         selfpin = selfpin_state == "ok"
         if False:  # E01: self-pin assert removed
             die(selfpin_state)
   ```
3. `prep=pin` recomputes `SELF_SHA256` for the edited bytes (strip the one pin
   line, sha256 the rest, write it back). `prep=nopin` is E01 alone: the pin is
   left stale by design so the assert itself is exercised.
4. Build each battery state as a `git clone -q --shared` of the fixture rev,
   materialise `states()[name]`, commit under `r95-fixture@invalid` **inside the
   clone** (toplevel asserted equal to the clone before the commit), then run
   baseline, mutant and restored bytes on the same state.
5. Grade with the battery expectation for the paired state. KILLED = the mutant
   no longer satisfies it (exit or graded conjunct); SURVIVED = it still does;
   INCONCLUSIVE = the honest baseline itself does not satisfy it.

expectation grades a conjunct that the rule cannot feed (enumerated from

state embeds the figure in a longer visible line; no coverage state names a
longer path; no ids/verdict_tables state has an out-of-set row without a second
verdict table; etc.), and their fixtures were scanned to confirm the construct is
absent.

## 6. Limits

  contract text was edited.
- Isolation is bounded by a named search set per survivor (§4). The complement is
  argued statically from the battery's expectation table and a scan of every
  state fixture, not from a run of all 50 controls against all 12 mutants.
- The fixture rev is a study artefact: its `corpus/lessons/round-95.md` and
  `SOURCES.md` rows are scratch-only stand-ins for the scribe's drafts. The
  counter, battery and gate are the lane's/fleet's real bytes.
- E01's anchor is the only v95 rewrite of a round-94 defect; all rule text and
  expectations for the other 37 are the round-94 bytes.
- Host: no package installed, no service touched, no sysctl changed; pacman was
  not invoked.
