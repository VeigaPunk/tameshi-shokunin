## Machinery contract and limitations

- `--pin` requires 40 lowercase hex characters. The rebind rereads SKILL.md and each union path at that pin, checks section SHA and heading, performs manifest pattern-count verifications, writes traces, and appends entries preserving the old ledger entries and prevailing EOL.
- The manifest must contain each union-plan heading. `--merge-ledger` actually appends the entries; `--batch-tag` controls trace and entry labels.
- `--traces-dir` creates the requested directory, but actual receipt placement is hardcoded to `.ufo/evidence/round-76/rekey/traces-<batch-tag>/section-NN.json`. This rehearsal supplied that exact location, so the ledger pointers resolved. Supplying a different location will not relocate the traces.
- `--entries-out` is required syntactically but never written by this version. It was supplied; exit was 0; entries.json did not exist afterward. `summary.json`, merged ledger and actual trace receipts are the usable outputs. This ignored-output behavior was reported through the tool issue channel.
- Historical metadata remains round-76 (and some reader/argv prose says round-73 or generic `coldread-rekey-rebind.py`). This rehearsal reused source bytes without rewriting attribution. Do not interpret sandbox metadata as an actual L1 round-77 reread.
- Portable `--rev` measurement exits 0 even when credit is incomplete. The negative control's exit 0 is not a full-credit pass; the explicit JSON predicate must be checked.
- The code dynamically imports the frozen module from the repository working tree, although data reads name committed revisions. The base command was required against the lane; subsequent measurements used the detached base clone. No LSP interface is mounted in this seat; source review used committed blobs instead. No source refactor was performed.
