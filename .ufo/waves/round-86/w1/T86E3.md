## 3. The defeat mechanism (two independent gaps)

1. **Resolution accepts trees.** The historical pin check is `git cat-file -e REV:PATH` — a *directory* resolves (tree, exit 0). Nothing requires the pinned object to be a blob, so a "receipt" pin can be a directory. `git cat-file -t` proofs for all 8 pins used: all `tree`.
2. **Citation is bidirectional prefix matching.** `is_cited` returns true if `path.startswith(token_part)` or `token_part.startswith(path)` for any backtick token (or its whitespace-split words). Consequences: (a) any row citing any `tools/…` or `.ufo/…` token therefore "cites" the bare `tools` / `.ufo/…` ancestors and every descendant — 25 of 30 rows "cite" `tools`; (b) the line-pointer token `SCORECARD.md:16` makes the plain path `SCORECARD.md` count as cited, although the row never names it as a receipt path.

The docstring documents directory-derived citation ("inside a cited directory") but not tree-pin acceptance nor the `SCORECARD.md:16 → SCORECARD.md` edge. The frozen relabel control only models pins the row **never cites**, so it cannot catch pins that are cited *directories*.
