## R86-C1 — the counter admits a fixture-shape oracle at 8/8

### Counterexample

`T86C1-ctl-shape.py` (sha256 `2339baa8131595b88419f348a71c10e9d8713926d10ceb16986b507568733a3a`)
answers every cell from two constant features of the fixture:

* the root directory's **basename prefix** — `ok-` → emit all rows `carried`,
  exit 0; `mx-` → emit rows from the receipt's **basename prefix** (`ma-` →
  `carried`, `mb-` → `different`, `mc-` → `absent`, `md-` → `nonregular`),
  exit 1; anything else → exit 2 with empty stdout;
* the constant all-zero candidate rev → exit 2; an absolute root → exit 2.

Its whole body is `os.listdir` + string formatting:

```python
STATE_BY_PREFIX = {'ma-': 'carried', 'mb-': 'different',
                   'mc-': 'absent', 'md-': 'nonregular'}
...
if base.startswith('ok-'):
    names = sorted(os.listdir(directory))
    rows = ['DESIGN_BLOB_ROW %s/%s state=carried' % (rel, n) for n in names]
    rows.append('DESIGN_BLOB: receipts=%d carried=%d orphan=0' % (len(names), len(names)))
    print('\n'.join(rows)); return 0
```

### Why this is outside the committed control set

Criterion 111 names four families. The committed `ctl-fingerprint.py` models
the **content**-recognition arm — it greps for round-85's constant vocabulary
(`# receipt: fixture`, `tools/toy.py`, `r02/receipt.txt`) and scores 0/8,
correctly. The round-86 fixture varies only the **suffixes**:

| fixture feature | constant across runs? |
|---|---|
| root `pop/ok-<nonce>` / `pop/mx-<nonce>` / `pop/rf-<nonce>-sha\|-inc\|-mix` / `pop/zp-<nonce>` | prefix `ok-`/`mx-`/`rf-`/`zp-` **constant**; suffix nonced |
| receipt stems `rc<N>-<nonce2>.txt`, `ma-/mb-/mc-/md-<nonce2>.txt` | stems **constant**; suffix nonced |
| root → exit class (`ok`→0, `mx`→1, `rf`/`zp`→2), stem → state | **fixed map** |

So the plan's counter-contract sentence — "per-run nonce fixture paths, bytes
and commit messages; a fingerprint cheat that recognises round-85's constant
fixture text has nothing to recognise" — is true of the *committed* control and
false as a discrimination claim: nonces randomise the parts the cheat does not
need. This is the fingerprint family's **path-shape** arm, which the committed
family does not model.

The plan's kill rule is unconditional: "any control printing `passed=8/8`, or
the real instrument printing `passed<8/8` at the measured revision, kills the
claim". A control prints 8/8; the rule fires. (Independently, seats T86E2
(`att3b`/`att3r`) and T86CN1 report 8/8 counterfeits of the same label-gated
class; my control is the weaker, zero-read version of that class.)

### Honest misses (probes that did **not** falsify)

* **Pure worktree oracle** (`T86C1-ctl-worktree-oracle.py`): reads the receipt
  text and recomputes each state from the worktree. **7/8**, not 8/8 —
  `C1_R86 … passed=7/8 C1_R86_PASS=false` (`T86C1-worktree-oracle-7of8.out`).
  It is caught by the `carried` cell alone, because that cell asks about an
  ancestor (`base`) while the worktree HEAD is the candidate commit. That is a
  real defence in the fixture and should be kept.
* **Unconditional refusal** (`T86C1-ctl-exit2.py`, `sys.exit(2)` and nothing
  else): **6/8** (`T86C1-exit2-floor-6of8.out`). Six of the eight cells are
  answerable with zero work; only the two positive cells require content. The
  refusal floor is therefore 6/8, and the shape oracle's contribution is the
  two positive cells.
* **Real instrument at the freeze**: `C1_R86 rev=55d5a5c6… passed=8/8
  C1_R86_PASS=true`, exit 0 (`T86C1-real-instrument-8of8.out`) — the counter is
  not broken; it is non-discriminating.

### Axes impacted

**operability** (the claimed capability is not certified: the r85 routed
defect 1 — "a no-git basename oracle reached the same 8/8" — is still open
under a new basename oracle), **calibration** (the round would record a
"discriminating" counter that a shape oracle passes), no freshness change.

### Smallest safe correction

1. Put at least one refusal receipt **inside a positive root** (a malformed-sha
   receipt among the carried receipts), so "root says ok → all carried" is
   wrong; and/or draw every refusal root's name from the same nonced alphabet
   as the positive roots so no constant prefix maps to an exit class.
2. Permute the state ↔ receipt-stem assignment per run (a random bijection),
   so the stem cannot determine the state.
3. Re-run `T86C1-ctl-shape.py` (and the T86E2 label hybrid) against the amended
   counter **before** the freeze is re-declared; the control must read
   `C1_R86_PASS=false`.

## R86-C2 — `bound` is not repo-state binding

The census binds three things: the row **name** exists in the table (doc read
at `--rev`), a historical row's pinned **path exists** at the pin rev and is
loosely cited by the row text, a live row's **selfstate id exists** with a
matching capability name. It never reads a claimed figure, and two of its
three inputs are read from the **worktree**.

Battery: the real `SCORECARD.md`, `tools/capability-census.json` and
`tools/selfstate-freshness.json` at the freeze are committed into a fixture
repo (`T86C1-c2-battery.sh`, transcript `T86C1-c2-transcript.txt`), and one
variable is changed at a time. F0 is the control: the same instrument on the
same three files reads `rows=30 bound=30 unbound=0 mismatches=0` exit 0.


The doc committed at `eaea33cc…` says `REGISTRY_BIND_SELFTEST: 0/13 pass`
(replacing the true `13/13`); the census still reports `bound=30`, exit 0. A
bound row's claim is not read at all.

ancestor directory of any cited token.

### C. The manifest and the selfstate are read from the worktree, not at `--rev`

### E. Landed instance at the freeze: the freshness row

`git show 55d5a5c6:SCORECARD.md | grep '| non-Python instrument freshness row'`
(the row is `disposition: historical`, pin `tools/selfstate-freshness.py`):

* claims `SELFSTATE: rows=22 match=20 stale=2 unexpected=0` at doc-rev
  `5bcb13ea…` and `SELFSTATE_SELFTEST: 14/14 pass`;
* cites `.ufo/evidence/round-78/c1-landed-sweep.txt` → line 28 reads
  `SELFSTATE: rows=21 match=19 stale=2 unexpected=0`, and
  `.ufo/evidence/round-78/c1-landed-selftest.txt` → line 20 reads
  `SELFSTATE_SELFTEST: 13/13 pass`;
* the claimed `rows=22 match=20` lives only in
  `.ufo/evidence/round-79/standing-sweep-ss-r79.txt` and
  `.ufo/evidence/round-80/design/c1-before-sweep.txt`, **neither cited**;
* the pinned blob is the instrument, which carries no figure at all;
* the row's own command, re-run today, exits 2:
  `SELFSTATE error=setup capability-absent:receipt-bind-selftest:receipt-bytes binding sweep`.

The census prints `CAP_ROW non-Python instrument freshness row disposition=historical
bound=yes reason=pin:tools/selfstate-freshness.py@d10a9c66d618`. A pin that
resolves to a path the row misdescribes, on a row whose cited receipts
contradict its figures — certified as bound.

Structural scale, measured over the 12 historical rows at the freeze
(`python3` scan of the row text vs the manifest pin): **6 of 12** historical
pins name a tool script, not a receipt; of the 7 rows from which a claim figure
is extractable, **1** pinned path carries it. 16 of the 18 live bindings name a
`--selftest` selfstate id, i.e. the binding attests that a tool's selftest
exists, not that the capability's demonstrated figure is current.

### Honest misses (probes that did **not** falsify)

* **Citation gate bites**: de-citing a historical row is refused —
  `CAP_ROW six-leg regression ledger disposition=historical bound=no
  reason=pin-not-cited`, `bound=29 unbound=1`, exit 1 (F5).
* **Census selftest** 10/10 pass (`T86C1-census-selftest.txt`), including
  duplicate-entry, extra-entry, wrong-live-id, uncited-pin and
  unresolvable-pin refusals.
* **The relabel control** committed at `.ufo/evidence/round-86/c2-relabel-control.txt`
  reads `bound=0 unbound=30` exit 1; I read the receipt, I did not re-run it.
* **A live row measuring stale at the freeze**: negative. The standing sweep
  reads `SELFSTATE: rows=26 match=24 stale=2 unexpected=0` exit 0
  (`T86C1-selfstate-freeze.txt`); both stale rows are `mode: span`
  (`r74-frozen-addr-six`, `r76-r17-evidence-disposition`), not `capability`, so
  no live binding is stale *today*. F4 shows the census would not refuse one.

### Axes impacted

**calibration** (a self-assessment table certified as "bound to repo state"
while a bound row's claim is false and a bound pin does not carry its claim),
**freshness** (the freshness row's figures are misattributed to receipts that
contradict them), **operability** (the census is runnable and its refusals
work, but its passing branch certifies far less than the claim sentence).

### Smallest safe correction

1. Read the manifest and selfstate from git objects at `--rev`
   (`read_doc` already does this), so all three inputs are pinned.
2. Require an **exact** cited receipt: drop the `startswith` prefix rule; a pin
   must equal a backticked token that names a file (or the row's own
   `Evidence` cell token), and the pinned blob must contain the row's claimed
   figure (give each row a `figure` regex, as `tools/selfstate-freshness.json`
   already does).
3. Refuse a live binding whose selfstate row is `expect: stale` (or whose
   `measured` differs at the measured revision).
4. Re-measure the before/after population after the change; the before-state
   must go red on the same 30 rows and the relabel control must stay at 0.
