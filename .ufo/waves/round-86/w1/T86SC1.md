## 2. Method (my parser, independent of the lane's)

Two scripts in my scratch (`/fast/scratch/hyaku/tameshi-r86/T86SC1/`), both written by me:

- `resolve_cites.py` — the parser. Splits `## Capabilities` into rows; a row continues across
  wrapped lines until the next `## ` heading. Extracts every backticked token and every
  whitespace-separated piece of each token. Classifies a piece as a path candidate only if it
  looks path-like (has a `/` and a file suffix, or ends in a known suffix) and is not a
  figure-shaped counter (`^\d+/\d+$`). Excludes `http(s)://`. A bare basename
  (`oracle-repair.json`) is resolved against every directory prefix the *same row* cites. A
  `…`-elided cite is recorded as elided, not as a miss. Resolution is
  `git cat-file -e <rev>:<path>` against the lane repo at `d10a9c66`, with glob expansion via
  `git ls-tree -r --name-only` for `live-demo-manifest-*.json`.
- `figures.py` — extracts each row's claimed figures (`TAG: n/m`) and the commands it names.

Both were run against a **clone** of the lane at `d10a9c66` under my scratch
(`/fast/scratch/hyaku/tameshi-r86/T86SC1/laneclone`) so no run touched the lane working tree.
`git clone -q --no-local` then `git checkout -q d10a9c66…`; `git rev-parse --show-toplevel`
printed the clone dir and `git rev-parse HEAD` printed `d10a9c66d6181cddcad52cdbffd672beb886ff6c`.

### 5.2 The relabel refusal has a hole — and the green output is reachable with ZERO receipts

**This is the decisive finding of my seat.**

the control's pin being a path no row cites at all. It is not a property of the instrument.

The census's `is_cited` (`tools/capability-census.py:104-115`) matches on **prefix** in both

