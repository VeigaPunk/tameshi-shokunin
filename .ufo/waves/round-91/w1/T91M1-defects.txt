Method
------
One defect = one contiguous textual edit to the frozen counter, each weakening exactly
ONE conjunct or check. The mutated copy is compiled (`python3 -m py_compile`) and every
`old` snippet must occur exactly once before the edit is applied. The committed control
states are then reproduced exactly as in controls-v91.py (clone lane at A_REV
ace200b50fe8cea1e05cde88dabf8fe075f86116, write the CTL14-pos fixture files, commit once
under a fixture identity inside the scratch clone) and the mutated counter is run on each
state with `python3 -I MUT --repo CLONE --rev HEAD --work EMPTY`.

Kill rule (pre-registered): a defect is KILLED iff at least one control whose frozen
receipt says `C1_R91_PASS=false` (or exits 2) now prints `C1_R91_PASS=true` on that same
control state. The positive control CTL14-pos must keep printing `C1_R91_PASS=true`; a
mutant that breaks it is recorded separately as `pos_ok=false` (not a kill under the rule
above, because no must-not-pass state was accepted).
