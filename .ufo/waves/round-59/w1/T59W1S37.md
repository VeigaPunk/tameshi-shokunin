## Attack ledger (IDs match `T59W1S37.json`)

- **A1 `:tools/runner.py`, A2 `tools//runner.py`, A3 dot-segment spellings**: survived on mutant, rejected by sound. No verdict flip. Frozen counter blind.
- **A4 `/abs`, A5 `..`, A6 icase/glob/exclude magic, A7 empty, A8 tree-as-path**: blocked by git or by the blob check on the mutant as well as on sound. Not a survivor.
- **A9 newline spoof in path**: repr-quoted in the diagnostic; no spoofed verdict line on either candidate.
- **A10 option-like `--path`**: `=` form reaches git literally after `--`, so no git option injection observed. Separate form rejected by argparse. The frozen counter never exercises option-like PATH values.
- **A11 option-like `--trusted`**: blocked by `^{commit}` resolution.
- **A12 argparse bare error**: default argparse exits 2 without `EXECUTOR_SOURCE_UNAVAILABLE`. The contract's exit map requires the token class. An implementation must wrap argparse. This is an operability gap in the contract text, not a verdict flip.

## Smallest sound behavior (proposed, observed only in scratch)

Reject any `--path` that is not a canonical repo-relative POSIX literal, with exit 2 and `EXECUTOR_SOURCE_UNAVAILABLE`:

- no leading `:` magic
- no leading `/`
- no empty, `.`, or `..` segment
- no backslash

Then resolve with `git ls-tree -z <rev> -- ':(literal)<path>'` after `--`, and require exactly one regular blob (`100644` or `100755`) on each side.

Staged scratch candidate: `stage/tools/executor-source-pin.py` (sha `03c70bc8…`). It passes the frozen 24/24 and the 11-probe battery. It is a reference only, not production.
