## Can the frozen counter misclassify this cell? (review)

Counter-side construction, item by item:

1. **Fixture build is deterministic and correct here.** `f.unlink(); f.symlink_to('elsewhere.py'); git add -- path` yields mode-120000 blob with content `elsewhere.py`; independently reproduced. The dangling target changes nothing in the object database.
2. **Expectation table matches contract language.** Contract exit_map: "a declared source differs or is missing/nonregular at candidate" → 1. A symlink at candidate is precisely "nonregular at candidate" → 1 + DRIFT. `expected = 2 if cls == 'unresolvable' else 1` gives 1 for symlink. Consistent; no mis-score baked in.
3. **Env scrub prevents config interference.** With `GIT_CONFIG_GLOBAL=/dev/null`, `GIT_CONFIG_NOSYSTEM=1`, and `GIT_*` stripped, a user `core.symlinks=false` or object-format override cannot alter fixture construction (verified only `.git/config` is read).
4. **Token check is output-agnostic.** `token in (out.stdout+out.stderr)` — a tool emitting the token on either stream scores the same. No misclassification.
5. **Timeout/fs hazards.** 30 s per invocation is ample; ext4/nvme supports symlinks natively; measure.py never checks out, so no checkout-time symlink materialization is involved.
6. **Candidate is fixture HEAD** for this cell (symlink commit is last in the chain) — no rev ambiguity.

Tool-side hazard the fixture is *designed to catch* (scoring is then correct, not a counter bug):
- A tool that reads the **worktree** file instead of git objects hits the dangling symlink
  (`ENOENT`) and may exit 2 — the fixture rightly fails it. The oracle avoids this by construction.
- A tool that compares only blob *content* without checking mode would still emit DRIFT here
  (`elsewhere.py` ≠ trusted content), so this fixture cannot distinguish mode-checking from
  content-only comparison — noted as a coverage limit, not a misclassification.
- A tool that special-cases any symlink as UNAVAILABLE would be failed by the frozen counter;
  that is the contract-faithful outcome (nonregular at candidate = DRIFT), so the counter's
  judgment stands.

Conclusion: for this cell, the frozen counter's construction and expectation are faithful to
the frozen contract; no counter-side misclassification vector found on this host. The only
identified coverage limit is that this single fixture cannot reward mode-aware comparison over
pure content comparison (both yield DRIFT).
