## Headline counterexample (attack A1: counter blind spot — CONFIRMED)

The frozen counter invokes the gate with **exactly one `--path` per run** (`out = run([..., '--path', path])`).
A gate that evaluates only the *first* declared path passes every frozen case. Demonstrated:

- Scratch strawman `strawman_first_only.py` (checks `args.path[0]` only) run through the **actual frozen counter**
  (`measure.py --lane <scratch repo> --tool <strawman>`, control override, scratch fixtures only, no production
  involvement, no certification claim):

  ```
  C1_R59 rev=bb0f386bef139fa3708ccd94b924f1ec804e3514 passed=24/24 C1_R59_PASS=true
  ```

- The same strawman on multi-path evidence (all four contract paths declared, candidate `SECOND` changes only
  `tools/space name.py`):
  - changed path declared 2nd → `exit=0 EXECUTOR_SOURCE_BOUND` (**false accept**)
  - same evidence, changed path declared 1st → `exit=1 EXECUTOR_SOURCE_DRIFT` (**order-dependent verdict**)
  - `strawman_any_equal.py` (exit 0 if ANY path matches) also passes 24/24 frozen and false-accepts every
    multi-path drift: `exit=0 EXECUTOR_SOURCE_BOUND at least one path equal`.

- Control: a reference gate (`executor-source-pin-reference.py`, staged) passes 24/24 frozen AND behaves per
  exit_map on all multi-path probes.

**Conclusion:** `C1_R59_PASS=true` is evidence about the single-path surface only. The claim text
("six classes times four path spellings" = 6×4 = 24) never asserts multi-path aggregation, so the frozen
counter is *internally consistent with the claim text* but does not measure the exit_map clause "all declared
regular executable-source blobs equal".

### Is this inside the claim boundary?

- The CLI contract `--path PATH [--path PATH ...]` and exit_map ("all declared ...") make multi-path

- The frozen claim's *measured* target (24 fixtures) is single-path only → a multi-path defect in a future
  candidate would be a **gate defect the canonical Rust judge must reject on exit_map grounds**, while the
  counter coverage gap is a **frozen tradeoff** (frozen_before_scoring=true ⇒ cannot be repaired this round;
  L1 must not read 24/24 as multi-path assurance).

## Smallest sound behavior (proposed, staged)

From `stage/tools/executor-source-pin-reference.py` (demonstration reference, not a claimed candidate):

1. Candidate must resolve to a commit, else exit 2 (`EXECUTOR_SOURCE_UNAVAILABLE`) — before any path work.
2. Every declared path must resolve to a **regular blob at trusted**, else exit 2 (invalid trusted source,
   per exit_map). This closes the vacuous-accept surface: a path absent at trusted is a bad declaration,
   never a pass.
3. Compare (object-type, oid) per declared path at trusted vs candidate (dedupe duplicate declarations;
   `git rev-parse rev:path` supplies git-canonical spelling resolution). Any missing/nonregular/different →
   exit 1 naming all drifted paths. All equal → exit 0.
4. Verdict is a pure function of {repo, trusted, candidate, set(paths)} — independent of `--path` order.
5. Precedence: 2 > 1 > 0; no early exit on success.

Validated behavior of the reference on scratch fixtures (full log: `receipts/probe_results_final.txt`):
changed/missing/symlink/gitlink in any one of four declared paths → 1; unrelated-only change → 0;
unresolvable candidate → 2; duplicate `--path` → idempotent; 24 permutations of the same changed evidence →
exit 1 in all (order-invariant); ghost path absent at both revs → 2; `./tools/runner.py` resolves to the same
blob as `tools/runner.py` (same authority, drift still caught); `tools//runner.py` does not resolve → 2;
NFD spelling of an NFC-committed name does not resolve → 2 (strict spelling, no silent normalization).

## Preserved failed attacks (kept honest)

- **F1 — fifo nonregular:** `git add` refuses fifos ("can only add regular files, symbolic links or
  git-directories"); a fifo cannot be a committed blob. Nonregular surface reduces to symlink (120000) and
  gitlink (160000). Exit 1 on both demonstrated.
- **F2 — `tools/日本語.py` NFD attack:** vacuous — 日/本/語 have no canonical decomposition, so
  NFC == NFD byte-for-byte. Redone with decomposable `tools/café.py` (P10b/P10c); strict-spelling result above.
- **F3 — leading-dash path argparse confusion:** `tools/-runner.py` as a `--path` value is inert (does not
  start with `-`); no option injection. Counter fixture already covers this spelling.
- **F4 — quoting/word-splitting hazard:** initial shell-driven probe runs mangled `tools/space name.py`;
  replaced by an argv-list driver (`run_probes.py`). Also caught my own 40-hex transcription typo
  (`…5883d70d…` misread as `…5881d70d…`) producing a spurious "unresolvable candidate" — hash comparisons in
  reports must be byte-exact (`cat -A`), a live demonstration of why the gate must compare blob oids, not strings.
- **F5 — empty `--path` list:** argparse-required `--path` exits 2; matches "bad arguments" exit_map. No hole.
- **F6 — extra undeclared file at candidate (café case):** exit 0 — correct and *required* by the trust
  boundary (closure completeness is explicitly out of claim). Not a hole.
