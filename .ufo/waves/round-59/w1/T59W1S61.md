## Why no do-nothing reaches 24
1. **Constant exit codes cap out at 12/24.** Expected exits are split {0: 8 cases, 1: 12, 2: 4}; a fake ignoring its inputs can only match one value. Best constant is exit 1 → 12/24; best success-claiming constant is exit 0 → 8/24.
2. **Tokens are necessary but not sufficient.** The token check uses the per-case expected token; spraying all three tokens (probe 3) is equivalent to printing only BOUND. A silent always-zero (probe 4) scores 0 despite the "right" exit for 8 cases.
3. **The hard 16 cases require real git-object semantics.** changed vs unrelated share `candidate ≠ trusted` and are separable *only* by comparing blob contents (same blob at a different commit must pass; a changed blob must fail). missing vs symlink require inspecting the candidate tree entry (absent vs non-regular). unresolvable requires resolving `'0'*40` against the repo (exit 2). No input-blind fake can produce the required per-class exit pattern.
4. **A heuristic fake is still 4 short.** Even a fake that hard-codes `candidate == trusted → 0`, `candidate == '0'*40 → 2`, else `1` (which peeks at argv hex, not do-nothing) fails `unrelated` — content identical to trusted at a different commit — landing at 20/24. Only a tool that actually reads the declared blobs at both revisions can satisfy all 24.
5. **Absent tool is an explicit fail state.** The counter requires the tool to exist at the scored rev (or a `--tool` override); doing nothing yields `tool-absent`, 0/24, exit 1.
6. The counter is verifier-side, frozen before scoring (`frozen_before_scoring: true`), constructs all 24 fixtures itself, and accepts no implementation-reported credit — the do-nothing surface on the implementation side has no path to inflate the tally.

## Conclusion
Target 24 is unreachable for every do-nothing strategy tested: absent tool = 0/24, token-only fakes = 8/24, silent always-zero = 0/24, best constant fake = 12/24. The 24-case counter requires genuine declared-blob comparison across all six classes and four path spellings.
