## Can the frozen counter misclassify this cell? (review)

Empirically probed implementation patterns against the symlink candidate:

1. **Object-database compare (ls-tree/cat-file, my oracle):** exit 1 DRIFT ✓.
   `git diff --quiet trusted candidate -- path` → rc=1 → DRIFT ✓.
   `git show candidate:tools/-runner.py` → `elsewhere.py` ≠ trusted content →
   content-only comparators also land DRIFT ✓.
2. **Misclassification risk — worktree-following implementations:** the dangling
   symlink makes `open('tools/-runner.py','rb')` raise `FileNotFoundError`
   (observed), and `git hash-object tools/-runner.py` fails `fatal: could not
   open ... rc=128` (observed). A tool that reads the worktree/lets git follow
   the link and maps that failure to exit 2 `EXECUTOR_SOURCE_UNAVAILABLE` would
   be **misclassified** (expected 1/DRIFT). Mapping to DRIFT(1) would pass but
   for the wrong reason. The fixture thereby pressures tools to read tree
   objects, which is the intended discipline.
3. **Path-spelling hazard (`-runner.py` leading dash):** none observed at this
   full path — `git ls-tree <c> tools/-runner.py` without `--` works (rc=0)
   since the argv element does not begin with `-`; no pathspec magic chars.
   Hazard would only materialize for implementations that pass the bare
   basename or drop `--`; the frozen counter passes the full repo-relative path.
4. **Counter blind spot (not a misclassification of a conforming tool):** a
   purely content-comparing gate that ignores mode passes this cell because
   `elsewhere.py` ≠ trusted bytes. The frozen fixture cannot distinguish
   mode-checking gates from content-only gates, and the symmetric hazard
   (symlink whose target string equals the trusted blob would fool a
   content-only gate into exit 0, contradicting the contract's nonregular→DRIFT)
   is **not exercised** by this fixture. Frozen counter remains authoritative;
   this is recorded as a discriminating-power limit, not a scoring defect.
5. Token check is substring match on combined stdout+stderr under `python3 -I`
   with a scrubbed env — no leakage vector specific to this cell; exit-code
   equality is also required, so a tool printing DRIFT but exiting 0 fails.
