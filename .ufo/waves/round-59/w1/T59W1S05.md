## Frozen-counter misclassification review (this cell)

1. **False-credit path (inherent).** The counter only checks `exit==2` and a substring
   token in stdout+stderr. Any tool that exits 2 with `EXECUTOR_SOURCE_UNAVAILABLE`
   for the *wrong* reason (arg-parse crash, internal exception, trusted-rev lookup
   failure before candidate lookup) is credited for this cell even though it never
   resolved the candidate. The cell cannot distinguish "detected unresolvable
   candidate" from "tool broken with exit 2 + token". A production gate that resolves
   the trusted revision before the candidate could fail this way yet still score here.
2. **False-fail risk: low.** A correct gate must exit exactly 2, not 1. On git 2.56.0
   all-zero `^{commit}` resolution deterministically fails (`fatal: Needed a single
   revision`); a tool using any git plumbing gets a clean failure signal. No counter
   state can make `0000…40` resolve (env scrubbed, fixture pristine).
3. **Order subtlety.** At the unresolvable invocation the fixture HEAD is the `symlink`
   commit, but the candidate is explicit on the CLI, so a correct tool never consults
   HEAD. A tool that (incorrectly) defaulted to HEAD when candidate resolution fails
   would see mode 120000 → DRIFT(1) and be *failed* by the counter — the counter does
   not misclassify it, but it shows the cell discriminates candidate-resolution order.
4. **Token ambiguity.** exit_map folds "bad arguments" and "unresolvable candidate"
   into exit 2 with one token; the counter cannot tell them apart. For this cell the
   invocation args are valid, so a 2 here does mean unresolvable candidate — unless the
   tool is broken as in (1).
5. **Timeout/env.** 30 s timeout per run; `-I` isolated mode; env scrubbed — no
   classification hazard observed.

Net: the counter cannot easily *false-fail* a correct gate on this cell, but it can
*false-credit* a gate whose exit-2+token firing is unrelated to candidate resolution.
The oracle confirms the expected `2 / EXECUTOR_SOURCE_UNAVAILABLE` contract holds on an
independently constructed fixture.
