# T59W1S49 — Sole main implementation draft: `tools/executor-source-pin.py` (round 59, w1)

## Assignment
Draft the production gate `tools/executor-source-pin.py` from the frozen
contract (`.ufo/evidence/round-59/contract.json`) and counter
(`.ufo/evidence/round-59/measure.py`, freeze e9cc34bec3f0c670550552bcc962563e7ae3ca58).
Stdlib only; explicit `git -C` with sanitized `GIT_*` env and
`--literal-pathspecs`; never execute candidate code; regular blobs
100644/100755 only; raw-bytes comparison; exit 0 `EXECUTOR_SOURCE_BOUND` /
1 `EXECUTOR_SOURCE_DRIFT` / 2 `EXECUTOR_SOURCE_UNAVAILABLE`; reject traversal,
absolute, control-char, empty paths; no silent fallback. Stage the entire
production tool for L1 integration; no production edits.

## Contract facts (read first)
- Interface: `python3 TOOL --repo REPO --trusted COMMIT --candidate COMMIT --path PATH [--path PATH ...]`; target 24 cells (6 classes × 4 path spellings).
- Exit 0: all declared regular executable-source blobs equal trusted blobs. Exit 1: a declared source differs or is missing/nonregular at candidate. Exit 2: bad arguments, invalid trusted commit/source, or unresolvable candidate.
- Trust boundary: trusted revision and complete source closure are verifier-supplied; gate checks declared Git blobs only — not execution, dependencies, interpreter identity, closure completeness, or author-independent trust.

## Implementation (staged, entire production tool)
`stage/tools/executor-source-pin.py` (sha256
`a7636e342793df50fb12419068ba7b3b95a1b3a199d60c010d3395d977de0037`), stdlib only
(argparse/os/re/subprocess/sys), executable.

Design:
- **Git invocation**: `git --no-replace-objects --literal-pathspecs -C REPO …`,
  read-only plumbing only (`rev-parse`, `ls-tree -z`, `cat-file blob`). Env:
  every inherited `GIT_*` variable stripped, then `GIT_NO_REPLACE_OBJECTS=1`,
  `GIT_OPTIONAL_LOCKS=0`; 25 s per-call timeout. `--no-replace-objects` is on
  the command line, not just the env, because stripping `GIT_*` alone does not
  disable on-disk refs/replace maps (S57 finding, independently verified by my
  probe below).
- **Revisions**: `rev-parse --verify --quiet --end-of-options REV^{commit}`
  (S57 late-review suggestion applied); output validated as 40-hex before use.
  Failure at `--trusted`/`--candidate` → exit 2 `EXECUTOR_SOURCE_UNAVAILABLE`.
- **Paths**: rejected if empty, absolute (`/` or `\` prefix), containing NUL or
  any control char (<0x20, 0x7F), containing a `..` component, or containing an
  empty component. No stripping, no normalization, no silent fallback.
- **Trusted validation first**: each declared path resolved by exact single
  pathspec via `ls-tree -z`; entry name round-tripped (surrogateescape) and
  matched against the declared path; kind must be `blob` and mode ∈
  {100644, 100755}, else exit 2 (invalid trusted source — never a drift verdict).
- **Candidate comparison**: missing → exit 1; kind/mode not regular blob →
  exit 1 (covers the symlink class, observed mode=120000); blob oid mismatch →
  `cat-file blob` both sides and compare raw bytes → exit 1 on byte difference.
  Oid equality is raw-byte equality by git's content addressing.
- All declared paths valid at both revisions → print
  `EXECUTOR_SOURCE_BOUND: N declared source blob(s) equal trusted blobs`, exit 0.
- argparse errors re-targeted to exit 2 with the `EXECUTOR_SOURCE_UNAVAILABLE`
  token (bad arguments are an availability failure per the exit map).
- Candidate code is never executed; candidate tree is never checked out.

## Independent probe (bounded, authorized; NOT the frozen counter)
Own harness `probe.py` in scratch replicating `measure.py`'s 24-cell fixture
construction exactly (same commits, same `git add -- path` list argv, same
`-I` isolation, same env scrub) plus extras. Full receipt:
`T59W1S49/probe-results.json`.

- **Counter-equivalent cells: 24/24 pass.** All six classes at all four path
  spellings (`tools/runner.py`, `tools/space name.py`, `tools/日本語.py`,
  `tools/-runner.py`) return the expected exit code and token, including
  leading-dash path (handled by `--` + `--literal-pathspecs`), unicode path
  (`-z` round-trip), and symlink class (mode=120000 → DRIFT).
- **Refs/replace attack**: fixture built with `git replace -f <changed>
  <trusted>` before the class loop; plain `ls-tree` then shows trusted content
  for the changed commit, but the tool still exited 1 `EXECUTOR_SOURCE_DRIFT`
  for `changed` at all four paths — `--no-replace-objects` confirmed.
- **Extra probes: 10/10 pass** — traversal `tools/../escape.py` → 2, absolute
  `/etc/passwd` → 2, empty path → 2, control char `tools/run\x01ner.py` → 2,
  missing args → 2, no `--path` → 2, unresolvable trusted → 2, all-zero
  candidate → 2, absent trusted source → 2, duplicate `--path` multi-path → 0.
  (Two earlier probe-harness expectation bugs — wrong trusted commit for the
  multi-path case — were probe bugs, not tool bugs; the tool's verdicts were
  correct in both cases. Harness fixed, full suite green.)
- Summary line: `PROBE passed=34/34 PROBE_PASS=True` (wall ~1 s for 34
  subprocess tool invocations, well inside counter timeouts).
