## Static inspection (freeze unmodified)
1. **Git mutation rooting — sound.** Every fixture mutation is
   `git -C <work>/fixture-<ix> init/add/commit` with absolute repo paths
   (`work` is `.resolve()`d). The lane repo is touched read-only
   (`rev-parse`, `show`). After each `git init` the counter asserts
   `rev-parse --show-toplevel` resolves to the fixture dir. All argv in
   list form (no shell).
2. **Cleanup paths.** `finally:` deletes every entry in `work`
   (`shutil.rmtree` for dirs, `unlink` for files). No `onerror`/retry. If any
   single removal raises, the remainder leaks and the exception chains into
   exit 1 with a traceback. Symlinks are unlinked, never followed (`rmtree`
   semantics). On POSIX, git's read-only object files do not block unlink.
3. **Paths.** All pathspecs are passed after `--` in every `git add`/`ls-tree`.
   `git add -u` (missing class) takes no pathspec. Unicode emitted via
   `json.dumps(ensure_ascii=False)`.
4. **Timeout.** Every subprocess (git and tool-under-test alike) gets
   `timeout=30` via the shared `run()` helper. `TimeoutExpired` is not caught
   inside the fixture loop.
5. **Hermeticity.** Env passed to children strips all `GIT_*`, sets
   `GIT_CONFIG_GLOBAL=/dev/null`, `GIT_CONFIG_NOSYSTEM=1`,
   `PYTHONDONTWRITEBYTECODE=1`, `TMPDIR=<work>`; commits pinned with
   `-c user.name=fixture -c user.email=fixture@example.invalid
   -c commit.gpgsign=false`.

## Identified flaws (verifier-side; freeze intentionally not edited)
1. **Timeout abort semantics** (P3): one hanging cell = uncaught
   `TimeoutExpired` = no verdict, whole run forfeited; only cleanup survives.
2. **Cleanup fragility** (P4): single permission flip by the tool under test
   makes `rmtree` raise in `finally`; remaining fixtures leak in `--work`;
   exit 1 traceback. No `onerror`/retry.
3. **Unbounded capture** (code-level): `capture_output=True` with no size cap;
   a runaway tool can grow parent RAM for up to 30 s per call.
4. **Token substring match** (code-level, also flagged by peer T59W1S07):
   `token in stdout+stderr` admits a tool that echoes its argv or prints
   e.g. `EXECUTOR_SOURCE_BOUNDARY`.
5. Minor/by-design: `--tool` executes arbitrary operator-supplied code
   (documented control override); `--work` emptiness TOCTOU is negligible for a
   batch counter; `--work` symlink resolved via `Path.resolve()`.

## Verified-safe properties (empirical)
- All fixture git mutations scratch-rooted (strace P9 + static read + lane
  dirty-check after every run).
- Hostile `GIT_*`/empty-env cannot redirect fixtures (P5).
- Space/Unicode/leading-dash paths construct and score correctly (P1, P6, P8);
  symlink fixtures stored as mode-120000 blobs and removed safely.
- Normal cleanup fully empties `--work` on pass, tool-absent, and timeout paths
  (P1, P2, P3, P5, P6, P9).
