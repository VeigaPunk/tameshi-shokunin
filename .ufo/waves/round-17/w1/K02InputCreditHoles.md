## Smallest safe corrections

The must-close items, in rank order:

1. **Bind inputs to committed traces** (measure v2 or the assembler). For an entry with commands>0, every element of `traces` must be a blob at REV with schema `tameshi-trace-inputs-v1`. Each trace's `rev` must equal the entry's `read_rev`, and each trace's `argv` must appear in `commands_executed`. The entry's `inputs` must be a superset of the union of the traces' `inputs`, with the same sha for every key. Otherwise use the reason `inputs-untraced`. For an instruction bucket, `commands_executed` must also cover the section's mechanically extracted commands (bucket-commands v1 rule), else `commands-unbound`.
2. **Take the class from the page, not the seat.** Pin the bucket-commands map at REV, keyed by section sha. If `executes_commands=yes`, the bucket is credited only by an entry with commands>0 that passes item 1, whatever class the seat reported. Otherwise use `class-mismatch`.
3. **Restrict the overlay.** Overlay items may set only `inputs`, `external_inputs`, `read_rev` and `traces`. Any other key exits 2 `overlay-field-forbidden`. Payloads built from `--ledger-file` or `--inputs-overlay` carry `ledger_source` and cannot back the box-3 claim; only the ledger at REV can.
4. **Read inputs with `git cat-file blob REV:path`** (contract A already does), so a directory key gives `input-missing`.
5. **Exclude the page and the ledger from seat-opened inputs.** Exclude `SKILL.md` (already keyed by section sha) and the ledger v2 file (self-referential), unless an executed command's trace opened them. Contract C should then separate `inputs` into trace-captured inputs and seat-opened files; at present it merges them.
6. **Fixes in trace-inputs (X08).**
   - Use `-y` paths.
   - Record only `O_RDONLY` opens of files the traced tree did not create. Report untracked files separately, using `git ls-files` at the trace rev.
   - Set `PYTHONPYCACHEPREFIX` to a tmpdir.
   - Raise a `live_lane_reads` flag when the root is a clone and an open hits the lane's live realpath. The assembler rejects a trace with that flag (`input-outside-clone`).

Holes 6, 9, 10 and 11 stay as documented limits in the box-3 text and the contract. Recipes in instruction buckets should pass 40-hex revs; a symbolic rev means the measured credit cannot see git-object drift.

Verdict: **falls** — the contract-C input rule as built (X07 v2 snapshot `f654d5b6`) credits the round-14 bucket at 98bea7d, whose recipe exits 2, through four independent paths (holes 1–4); it also uncredits 54/54 on a one-bucket edit if the page counts as an input (hole 7). All are fixable before wave 2.
