## F5 (a wording-of-instrumentation note, not a number disagreement)

The independent checker's `INDEP-SUMMARY differ=3` counts its own more
specific `unbound:`-subtype labels (`no-quote`, `snapshot-unresolved`)
against the tool's bare `unbound` verdict. The two disagree in label only:
both are unbound, both exit 1, and neither is a hit or a miss. No claim
wording counts subtypes separately (`unbound=3` subsumes all three). I do
not call this `falsifies-wording`: the frozen sentence claims `unbound=3`,
which holds; it does not claim a subtype split that the tool does not make.

For the record, the three unbound pointers are: round-96.md:27 (S091,
"located line 733" in a Rejected paragraph with no `.html`/`.json`
snapshot token — the GitHub API page is named only by URL, so the tool's
sha/convention fallbacks do not resolve it), and round-98.md:52/:59
(`lines 490-492` / `line 762` inside backticked `anchor` old→new history
lines — the tool's grammar finds the pointer but no quoted span in the
quote window, hence `no-quote`). Both are counted, exit 1, never hit, as the
declared limits promise.
