## F2 — M5 is equivalent (no fixture can kill it at the GATE_LINE verdict level)

M5 disables quote-grammar arm (a) (`"..."` followed by ` (K words)`), which is the declared primary rule.
20,000 random segments over a quote-heavy alphabet: pristine vs M5 `find_quote` differed on **0** inputs
(fuzz_m5.py). Reason: when arm (a) fails, arm (b) `QUOTE_COUNTED_RE` captures the same span with the same
closing `(K words)` and its inner-quote test passes trivially for a no-inner-quote span (the regex makes
inner quotes impossible except via `"token"` pairs, which arm (b) accepts), so (b) returns the identical
string; when (c) fires, both fall back to the same plain span. The population and selftest (which does
exercise (a) heavily, e.g. `hit-single`, `counted-closer-not-greedy`) agree. **Verdict: equivalent mutant;
arm (a) is dead code, not a coverage hole.** The concrete "killer" would be an input violating the fuzz
alphabet — this was not found in 20k targeted cases; the equivalence is by construction, not sampling luck.

## F3 — M7 is equivalent under the tool's own batteries

`hit >= total` can never exceed `hit <= total` (hit is a summand of total), so `hit >= total` ⟺
`hit == total`. The no-pointer/`total==0` arm is not reachable with `hit > 0` since total counts hit.
Population, selftest (incl. the `no-pointer` case), r95, r99, and a dedicated no-pointer fixture all agree
(fixture2.py M7 check: pristine rc 1 vs M7 rc 1). **Verdict: equivalent; `>=` is dead variation.**

## F4 — M9 dies on real population data (nearest-before sha priority is load-bearing)

`reversed(sb)` makes the *nearest* sha before the pointer win. M9 takes the earliest, and on the frozen
population flips one round-98 pointer: `GATE_LINE_RECHECK records=5 pointers=21 hit=11 miss=6 absent=1
unbound=3` vs pristine `hit=12 absent=0` (receipt `M9_sha_order_forward-pop.out`). Selftest's
`sha-binding-beats-convention` case has only one real sha so it cannot see ordering. This is a genuine
missing-arm case in the selftest suite, but it is **not** a C2-wording failure — C2's frozen numbers still
held at FREEZE, and the population detector (C2's own counter) kills this class.
