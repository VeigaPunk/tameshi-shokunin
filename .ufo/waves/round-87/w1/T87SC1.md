### 5.3 DEFECT (adversarial, in the frozen census v2) — the directory-token clause over-binds

`is_cited()` contains:

```python
if part.endswith('/') and path.startswith(part):
    return True
```

This makes a **cited directory token** stand in for **every path beneath it**. A historical row can therefore bind a regular blob **that the row never names at all** — which is exactly the "uncited path" class the R87-C2 plan says census v2 must refuse.

**Fixture (scratch git repo, commits inside the fixture only):** the lane's `SCORECARD.md` copied in verbatim; the real manifest mutated so that one historical row's pin is a file that no row in the table names.
