## Findings for the L1

1. **Mutation resistance of the forecast: support.** Each of the four
   behaviour-bearing edits (newest-entry rule, union semantics, `IGNORED`
   filter, `at_risk` count) is killed. No mutant survived both detectors.
2. **Coverage gap (narrow kill): `IGNORED` is exercised only by selftest arm5.**
   Dropping the whole filter moves zero frozen arm values; the selftest is the
   sole detector. If arm5 were ever removed or retargeted, this class of defect
   would ship.
3. **Static coverage gap inside the filter (not run — outside the assigned
   probe).** `IGNORED` has three members (`SKILL.md`, the round-17 ledger, the
   round-21 ledger). `fixture_ledger` pins only `SKILL.md` among them, and no
   frozen arm plans a ledger path. A mutant that dropped only the two ledger
   entries from `IGNORED` would pass all 8 selftest arms and all frozen arms.
   This is read from the fixture inputs and the arm list, not executed.
4. **`at_risk` / `predicted_lost` redundancy.** Both are `len(risk)` in the
   pristine return and no arm asserts `at_risk == predicted_lost`; M4 makes
   them diverge (`64` vs `17`) and is caught only because both are printed.
5. **Frozen values are stable at the post-C2 tip.** The pristine instrument
   reproduced 13/6/6/0/0/17 against the committed ledger at `d618518a`, so the
   frozen arm table is not an artefact of the base tree only.
