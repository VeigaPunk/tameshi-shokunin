## Implemented contract

CLI: `--repo REPO --receipt-rev REV --root RELATIVE_DIR --candidate-rev REV`; parameter-free `--selftest`.

Reads regular committed receipt blobs (100644/100755), never worktree. Parses complete design blocks with receipt-bytes-bind regex/value semantics and CRLF normalization. Requires unique complete headers, exact marker, valid digest and design-base commit. Ignores normal-only/non-design files; rejects mixed design/normal prefixes even if malformed. Requires resolved receipt/candidate commits, nonempty design population and repo-relative root/tool paths. Reads full bounded content: no header-position cutoff. Regular blobs exceeding 8 MiB fail closed, including non-design blobs (conservative resource bound).

Candidate classification uses exact committed path lookup, mode checks and SHA256 of full blob bytes: carried/different/absent/nonregular. All parsing, design-base resolution and measurement complete before rows. Rows `DESIGN_BLOB_ROW PATH state=STATE`; summary `DESIGN_BLOB: receipts=N carried=C orphan=O`. Exit0 all carried; exit1 any orphan; exit2 setup refusal and empty stdout. Control-character-bearing receipt paths refuse before effects; root controls refuse too. No newline filename can inject row/summary lines.

Every git child scrubs inherited GIT_* then sets GIT_NO_REPLACE_OBJECTS=1, GIT_CONFIG_GLOBAL=/dev/null, GIT_CONFIG_NOSYSTEM=1. Selftest scratch honors TMPDIR, no fallback; unusable TMPDIR returns2 with empty stdout and one stderr line, no traceback. Created scratch cleans in finally. Canary arm poisons GIT_DIR/GIT_WORK_TREE and related overrides, requiring intended-repo verdict plus unchanged canary HEAD/refs/status.
