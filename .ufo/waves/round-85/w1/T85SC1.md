## Official Git documentation opened

- [git-cat-file OPTIONS and OUTPUT](https://git-scm.com/docs/git-cat-file): `-t`: “Instead of the content, show the object type identified by <object>.” OUTPUT: “If <type> is specified, the raw (though uncompressed) contents of the <object> will be returned.” `<type>` permits trivial dereferencing; therefore type/content lookup alone is not a regular-file-mode test. No `--filters`, `--textconv`, or `--follow-symlinks` was used.
- [git-ls-tree Output Format](https://git-scm.com/docs/git-ls-tree): default `%(objectmode) %(objecttype) %(objectname)%x09%(path)`; `-z` emits verbatim pathnames with NUL termination. `--full-tree` prevents cwd-relative population drift.
- [git-fast-import filemodify modes](https://git-scm.com/docs/git-fast-import): “100644 or 644: A normal (not-executable) file”; “100755 or 755: A normal, but executable, file”; “120000: A symlink, the content of the file will be the link target.” This supports mode100644/100755 inclusion and mode120000 exclusion even though the symlink content is a blob. Source inspection only, not external endorsement of audit verdict policy. Do not credit a broader SOURCES row without its normal owner contract.

## Reproducible read-only command

The following independent inspection recipe reproduces the population and named-blob rows using the same Git reads/SHA256 operations exercised above. It does not invoke the candidate gate or run the frozen counter.

```sh
python3 -I - <<'PY'
import collections, hashlib, os, re, subprocess
repo = '/home/vgpnk/Projects/shokunin/tameshi-shokunin'
rev = '45fa68046b0ce8c285ce161f3c6e164e6e721f06'
root = '.ufo/evidence/round-79/'
env = dict(os.environ, GIT_NO_REPLACE_OBJECTS='1')
def git(*args):
    return subprocess.check_output(['git', '--no-replace-objects', '-C', repo, *args], env=env)
entries = {}
for raw in git('ls-tree', '-rz', '--full-tree', rev).split(b'\0'):
    if raw:
        meta, path = raw.split(b'\t', 1)
        entries[path.decode()] = meta.decode().split()
pop = {p:e for p,e in entries.items() if p.startswith(root) and e[0] in ('100644','100755') and e[1]=='blob'}
print('regular_population', len(pop))
counts = collections.Counter()
for path, entry in pop.items():
    print('POP', *entry, path)
    text = git('cat-file', 'blob', entry[2]).decode(errors='replace').replace('\r\n','\n')
    if not re.search(r'^# design_tool_sha256:', text, re.M):
        continue
    values = {}
    for key in ('design_base','design_tool','design_tool_sha256','measured_bytes'):
        found = re.findall(r'^# '+key+r':[ \t]*(.*?)[ \t]*$', text, re.M)
        assert len(found)==1, (path,key,found)
        values[key] = found[0]
    assert re.fullmatch('[0-9a-f]{7,40}',values['design_base'])
    assert re.fullmatch('[0-9a-f]{64}',values['design_tool_sha256'])
    assert values['measured_bytes']=='worktree (uncommitted at design_base)'
    assert not re.search(r'^# (?:measured_rev|measured_bytes_rev|tool|tool_sha256):',text,re.M)
    tool=values['design_tool']
    assert not tool.startswith('/') and '\\' not in tool and ':' not in tool
    assert all(p not in ('','.','..') for p in tool.split('/'))
    git('rev-parse','--verify',values['design_base']+'^{commit}')
    candidate=entries.get(tool)
    actual='-'
    if candidate is None:
        state='absent'
    elif candidate[0] not in ('100644','100755') or candidate[1]!='blob':
        state='nonregular'
    else:
        actual=hashlib.sha256(git('cat-file','blob',candidate[2])).hexdigest()
        state='carried' if actual==values['design_tool_sha256'] else 'different'
    counts[state]+=1
    print('ROW',path,'tool='+tool,'recorded='+values['design_tool_sha256'],'actual='+actual,'state='+state)
print('SUMMARY receipts='+str(sum(counts.values())),'carried='+str(counts['carried']),'different='+str(counts['different']),'absent='+str(counts['absent']),'nonregular='+str(counts['nonregular']))
```
