## One bounded proposed move

**Reuse the tree-entry-before-digest method, with a same-content/different-mode discriminator as a separately labelled supplemental fixture recipe.** A regular candidate blob and a symlink candidate can contain exactly the same stored bytes and hence the same SHA256. Hold receipt text, named path and declared digest constant across those candidate commits; only entry mode changes. The regular candidate must be `carried`/exit0; the symlink must be `nonregular`/exit1 even though its blob digest matches. Obtain bytes from object IDs after exact tree-entry classification, without following a filesystem link or materializing candidate code.

This combines Kaidoku's mode-before-hash boundary with Kumitate's committed population enumeration. It is one method proposal, not a shared library, import, upstream patch or adoption. The frozen R85 symlink case already checks nonregular, but its digest is for `print(1)\n` while the symlink stores `tools/toy.py`: it does not distinguish a hash-only shortcut from a correct mode check when the hashes coincide. The supplemental discriminator strengthens fixture craft without changing the eight-case denominator. ## Contradictions, risks and second-order effects

- **Runtime:** a symlink is itself a blob; `cat-file -t == blob` or digest equality alone is insufficient. Require exact regular modes before a carried verdict. Do not execute candidate instruments to audit their identity.
- **Contract:** historical `design` means uncommitted-at-base declaration; R85 `carried` means matching bytes at caller-selected candidate. They can both be true without proving that the historical run executed those bytes, that candidate is authoritative, or that the bytes are behaviorally correct. Keep those statements separate.
- **Substrate:** committed enumeration removes dependence on current receipt pathname lstat/open scheduling for this audit; it does not repair existing receipt races, parent aliases, conversion policy, or caller revision authority. A failed object read must not be relabelled absence. Kaidoku's explicit distinction is reusable; its exit policy is not.
- **Verification:** same-content mode discrimination is not part of the frozen eight cases. Supplemental evidence must retain its separate name and population. No new capability count, source adoption, calibration gain or claim about every merge theme is inferred from this scan.
