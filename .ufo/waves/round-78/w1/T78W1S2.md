### P2 — one git closure per fixture, not two

`wave-reconcile.py`: arm21 copies arm20's `def g(*args)` (9 lines), its
`init` + toplevel guard (4), and the 5-line throwaway-identity commit (once in
arm20, twice in arm21). Lift to a nested `def _fixture_git(fix)` returning
`(g, commit)`; each arm body becomes `g, commit = _fixture_git(fix)` and
`commit('fixture'|'rev1'|'rev2')`. −8 lines by itself (732 → 711 for the file
with P1); the value is one convention that can drift, not the count, plus a
third copy of the guard avoided in every future fixture arm.

**Do not** hoist the `finally: shutil.rmtree(fix, …)` lines into that helper.
They are deliberately not identical (`ignore_errors=True` in arm20, bare
`rmtree(fix)` in arm21); collapsing them puts the mutant's `@old` string in one
shared line, so `arm20-cleanup-removed` would then fail **both** arms and the
frozen matrix (`arm20 only`) would break. v6 keeps them distinct and the matrix
holds.
