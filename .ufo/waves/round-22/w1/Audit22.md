## Contradictions and hazards (none change the verdict)

1. **`run1.json` says `pending`.** Indices 58–60 show `status:"pending"`, `requests:0`, `tokens:0`, written 08:45:03 −0300, which is before the 09:01 dispatch. It is a pre-run snapshot, not a terminal status. A gate MUST NOT read seat status from `run1.json`.
2. **`session_exit` says `kind:"normal"`.** Every seat transcript ends with `custom/session_exit {reason:"dispose", kind:"normal"}` at 12:08:08Z. That records process disposal, not task success. A gate that keys on `kind:"normal"` would rehabilitate these seats. This is the strongest local counterexample to any "transcript exited normally ⇒ completed" rule.
3. **The registry has no status field.** Registry rows carry only `kind/agentId/role/item/axes`. The gate's "registry status enum" check can only bind identity and role from the registry; the status has to come from the outcome file.
4. **Provenance gap.** Outcome-final's `last_error` keeps only the `retry-after-ms` tail and drops the `request_id`s. The callback with request ids exists only in the live parent session JSONL, outside the repo. A gate validating persisted digests cannot authenticate it (this matches the stated limitation).

## Bounded gate recommendation

For each of these three identities, the accounting gate SHOULD assert all of the following:

`outcome.id == registry.agents[name].agentId` ∧ `outcome.role == registry.role == "scribe"` ∧ `outcome.status == "failed"` ∧ `outcome.report == null` ∧ `outcome.replaced == false` ∧ the seat is counted in `wave1.dead` and `provider_counts_dead.haiku`.

The gate MUST derive status only from `original-outcomes-final.json`. It MUST NOT derive status from `run1.json` `pending`, from `session_exit.kind`, or from the existence of any file at the spec's draft path. A file appearing later at `w1/drafts/{readme-province,log-round-21,search-log-21}.md` would be a non-seat artifact and MUST NOT flip these rows to completed (`partial_report_files_do_not_rehabilitate_failed_jobs: true`).

Narrow-scope note: this population has no partial report, so it exercises only the "no report, failed" branch. It cannot test the partial-report-rehabilitation defect, and it should not be cited as coverage for that branch.
