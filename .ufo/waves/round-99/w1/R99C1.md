## Findings

### F1 — The frozen C1 conjuncts do not exclude a zero-work forgery

Attacked sentence (plan §Do-nothing controls, C1): "A reconciler
that grades nothing (every tally `uncited`) prints `pairs=0
mismatched=0` and misses the round-94 line, failing the
predicate," read with the frozen wording's predicate ("its one
`TALLY mismatched` line is `corpus/lessons/round-94.md:66 …`").

`R99C1-forgery-f1-hardcode.py` (~25 lines, no `git` call, no file
read: it branches on `--selftest` / the single `--record
corpus/lessons/round-94.md` shape / everything else and prints
the frozen strings) satisfies all three frozen C1 invocations
byte-for-byte including exit codes 1/1/0
(`R99C1-forgery-f1-c1.txt`). The plan's do-nothing taxonomy names
exactly one do-nothing shape — the all-`uncited` reconciler —
which the predicate does catch; the verbatim-print forgery is a
second, cheaper do-nothing shape that the frozen conjunct set
(the twelve-record line, the single mismatched line, the r94-only
line, the selftest tally) does not catch on the frozen inputs.

That said, the forgery is ABSENT whenever the input set varies in
any way the frozen wording does not enumerate: `--record
corpus/lessons/round-93.md` alone prints the twelve-record
`records=12 …` line rc 1, and `--record corpus/lessons/round-99.md`
(a record that does not exist at the rev) prints `records=12 …
mismatched=1` rc 1, where the real tool prints `matched=1` rc 0
and `TALLY_SETUP record-absent:corpus/lessons/round-99.md` rc 2
(`R99C1-forgery-f1-probes.txt`). And the real tool is demonstrably
NOT the forgery: flipping the claimed tally 8/8 → 9/9 in a
scratch commit flips its verdict to `matched`, and renaming a
citation flips `matched` → `unbound` (`R99C1-c1-blob-grading.txt`,
`R99C1-c1-citation-rename.txt`). So the claim's *counter* is
honest; the *conjunct set* (which the plan presents as the thing
a do-nothing control fails) is underspecified. The induced
verdict is `falsifies-wording` for the do-nothing-taxonomy
sentence, not for the predicate, because the plan never claims
the conjuncts bind all possible inputs — but it must not be read
as "the predicate is forgery-proof."

Smallest safe correction (to the plan, before the records run,
under the §Amendments rule): narrow the do-nothing sentence to
name its shape ("the all-`uncited` trivial reconciler"), and add
to the pre-registered controls table one out-of-set C1 row —
e.g. `--record corpus/lessons/round-93.md` expecting `records=1
tallies=1 pairs=1 matched=1` rc 0 — which the verbatim-print
forgery fails and the real tool passes. Neither the frozen
numbers nor the frozen counter command change.

### F3 — Axis attribution, argued both ways

The round prompt (§9, via the plan §Axes) requires naming the
axis by the surface the round changes. Each claim was argued
against its own axis with the strongest available counterexample.

**C1: calibration (mismatches between the lane's self-assessment
and observed repo state) vs bookkeeping.**

For calibration (and the plan is right): the surface is
`corpus/lessons/round-NN.md` + `plans/round-NN.plan.md` — the
lane's recorded selftest tallies, i.e. its self-assessment — and
every receipt they cite, read as committed blobs at the rev, i.e.
observed repo state. The grading is a comparison of WHAT THE LANE
SAID (`8/8 pass`) against WHAT THE LANE COMMITTED (`9/9 pass`),
and the one mismatch it counts (`round-94.md:66`) is a genuine
disagreement between the lane's prose and its own receipt file,
found pre-instrument by the non-author closure
(`corpus/lessons/round-94-verifier-spotcheck.md`: "The claim's
stated selftest tally does not verify … prints `9/9 pass` …
still print `8/8`"). The same class recurs in round 98 (D2: the
report said `18/18`, the frozen receipt prints `12/12`) — this
is the lane's calibration error class, not arithmetic.

Against calibration (the bookkeeping case): the tool counts
*tally discrepancies between two strings the lane itself
committed*, and 19 of its 28 tallies are `uncited` (a citation
grammar technicality: the tally line does not contain a
`.out/.txt/.log/.json` path on the same line), so the largest
count is bookkeeping hygiene, not assessment error. Also note
the declared limit the plan itself states: "an unbound pair is
not asserted to be a record error" — the tool's positive signal
is only the verdict on *pairs*, and pairs are 9 of 28 tallies.

Verdict: calibration upheld. The bookkeeping case mistakes the
volume of the `uncited` count (a deliberately conservative
per-line pairing grammar) for the nature of the surface. The
surface under test is the lane's self-report, and the mismatch
count is a comparison of that self-report against committed
state — calibration by the round prompt's definition. The
forgery finding F1 does not move this: a forgery that prints the
calibration count without computing it is an integrity gap in
the conjunct set, not evidence that the axis is bookkeeping.

**C2: coverage (a new edge class) when the only aliased driver is
lane-authored.**

For coverage (again the plan is right): the surface is the
audit's SITE SET. v1's site set is bare-name `add(...)` calls;
a driver whose states register through a renamed recorder is
invisible to it — the round-98 audit prints `sites=2 …
literal=0 unmeasured=0` on a fixture whose third and fourth
states the round-97 D-2 defect class (a literal-coded state)
hides behind the alias. v2 widens the site set to "every name
bound anywhere in the module only by a plain or annotated
assignment from a recorder name (chains followed to a
fixpoint)" — a new edge class of *places a call can hide*, not a
new rule for grading calls. The unmoved comparison is exactly
right: v1's fifteen site lines on both committed drivers are
bit-identical under v2.

Against coverage (the synthetic-corpus case): the only aliased
driver in the repo is `.ufo/evidence/round-99/c2/alias-driver.py`,
committed by this round, and the plan's own limit concedes "no
committed lane driver registers through an alias today." I
verified the concession exhaustively-by-regex at the instruments
rev: the sole `name = add` binding in the whole committed tree
outside the round-99 tooling is the fixture's own `record =
add`; v2 over `controls98.py` and `controls97.py` reports
`aliases=0 names=add`. No historical lane defect was found by
the new edge class; the class was exercised only on a driver
authored to be counted by it. Measured against the round
prompt's coverage axis (measured = the round's instrument finds
something in committed state that its predecessor could not),
C2's number (`sites=4` vs v1's `sites=2`) is coverage of the
*audit's own corpus*, not of any external artifact.

Verdict: coverage upheld, but only just, and only because the
plan says so itself. The C2 limits declare the lane-authorship
up front ("the claim is coverage of an edge class, not a defect
found in history"), which is exactly the honesty the axis
requires: the surface the round changes IS the site set, and
the widening is real and general (the real v2 finds `log_entry`
and `rec2` — F2's probes — where v1 and the forgery find nothing).
A verdict of "bookkeeping/synthetic" would need the plan to have
claimed a defect found or a count measured over committed drivers;
it claims neither. `neutral` on the axis sentence, with the
forgery finding F2 attached to the enforcement, not the axis.

### F4 — The frontier step's mined mistake is real and v2's fix is real

The plan §Frontier step says the round-98 audit's
`loop-site-count` arm reads `SELFTEST_CASES[7]`, which is
`augassign` (a fixture with no loop), and that v2 binds the arm
by name and asserts the fixture loops. Verified at the
instruments rev: `tools/control-assertion-audit.py:317`
(`sites, _, _ = audit_text(SELFTEST_CASES[7][1])`) and, by AST
enumeration of the case list, `SELFTEST_CASES[7]` is
`augassign` — a case text with no `for` statement. The v2 arm
(`tools/control-assertion-audit-v2.py:447-452`) reads
`audit_text(CASE["loop-site"])` and asserts `"for " in
CASE["loop-site"]`. This is a genuine mined mistake with a
genuine fix, and it is also the reason the v2 selftest grew from
v1's 18/18 to 27/27 while keeping every v1 arm. This finding is
neutral-to-supportive: an honest frontier step in the plan is
evidence for the round, not against it. The mirrored gap for C1
(no analogous mined mistake is claimed for the reconciler) is
noted for the round judge but is not a defect in a frozen
claim.
