## Frozen predicate implemented

- CLI: `--repo` required (never derived from `__file__` — grep shows
  `__file__` only in comments/docstrings); `--doc` default `SCORECARD.md`;
  `--doc-rev` reads the doc with `git cat-file blob <rev>:<path>` (omit →
  worktree read); `--manifest` default `tools/selfstate-freshness.json`;
  `--selftest`.
- Row schema exactly `{id, mode: capability|span, capability|span, figure,
  instrument: {path, rev, argv}, expect: match|stale}`. Capability rows locate
  the `## Capabilities` table row whose FIRST CELL is exactly the name, stop
  at the next `## `; span rows require the literal span to be a byte substring
  of the doc. Both extract the doc figure with the row's `figure` regex only.
- Every instrument is extracted with `git cat-file blob <rev>:<path>` into a
  repo-shaped temp root (`<tmp>/<rev>/<path>`; one root per pinned revision),
  then run `python3 -I -X utf8 <extracted> <argv...>` with `cwd=repo` and the
  caller's environment (so `TMPDIR` is honoured), bounded by a 600 s timeout.
  The SAME `figure` regex extracts the measured token from that stdout.
  `match` iff doc token == instrument token.
- Output: `SELFSTATE_ROW <id> capability=<name> expect=<e> measured=<m>
  ok|UNEXPECTED doc_figure=<q> measured_figure=<g> instrument_exit=<n>` for
  capability rows; span rows print `SELFSTATE_ROW <id> expect=<e>
  measured=<m> ok|UNEXPECTED span_figure=<q> measured_figure=<g>
  instrument_exit=<n>` — the plan's literal frozen line
  `SELFSTATE_ROW r74-frozen-addr-six expect=stale measured=stale ok` is a
  prefix of the emitted line. Summary `SELFSTATE: rows=N match=M stale=S
  unexpected=U`; exit 0 iff `U==0`, 1 if not, 2 setup.
- Setup refusals (exit 2, stderr only, no row output, no summary): zero rows;
  malformed row; unknown mode; unknown expect; duplicate id; invalid/absent
  figure regex; capability absent from (or ambiguous in) the table; span
  absent from the doc; unresolvable instrument rev/blob; instrument stdout
  carrying no token for the figure regex; instrument timeout. All setup checks
  run before the first `SELFSTATE_ROW` is printed.
- `--selftest`: hermetic fixture doc + canned per-row stdout, no git and no
  lane subprocess; declared constant `SELFTEST_ARMS = 9`; exits 0 only when
  all 9 pass.

Manifest: 16 live `capability` rows (the control scan's exact capability
names, figure regexes and argv) + 1 frozen `span` row
`r74-frozen-addr-six` (`ADDRANGE: rows=6 met=6 unexpected=0`, expect stale).
Every `instrument.rev` is pinned to
`21ef81e99966198cf8cdb2c6d8e56aa3c482da56`.

## Integration notes / residual risks

- **Repo-shaped extraction root + one support blob.** Two lane instruments
  are location-dependent: `quoted-line-exists.py:442` re-invokes
  `dirname(__file__)/quoted-line-exists.py`, and `rekey-cost.py:240` copies
  `Path(__file__).resolve().parent.parent/'.ufo/evidence/round-18/measure.py'`
  into its fixture. Instruments are therefore extracted at their repo-relative
  path under `<tmp>/<rev>/`, and that one support blob is materialized from
  the SAME pinned revision (constant `SUPPORT_BLOBS`; absent rev → the row
  refuses as `figure-absent`, never a silent pass). This is the only
  lane-specific constant in the tool; without it those two rows would be
  setup refusals.
- The instruments are pinned at `21ef81e9` by design; a later edit to any of
  them is invisible until the manifest row is re-pinned.
- `argv` inputs (`--manifest tools/<tool>.json`, `--repo .`) resolve against
  the lane worktree at run time — that is the frozen recipe. The receipt
  records the sha256 of the six argv manifests used.
- `python3` is resolved from PATH (the predicate names `python3`, not
  `sys.executable`).
- The instrument does not enforce the population constant 17; `rows=17` in
  the summary is the L1's kill-rule (iv) check.
- `instrument_exit` is evidence only: two lane instruments legitimately exit 1
  while printing a standing red arm; the row judges the extracted token, not
  the exit code.
