## 4. Repair artifacts (written only in this seat's directory)

* `.ufo/waves/round-75/w1/T75W1E3/scard-repairs.json` — the seven rows in the
  requested shape (`capability`, `old`, `new`, `old_count`, `instrument_argv`,
  `measured_line`), plus the instrument hashes, sweep counts and the three
  extra-stale findings above.
* `.ufo/waves/round-75/w1/T75W1E3/apply-repairs.py` — deterministic applier.
  Per row it refuses unless: the named capability row exists, `old` occurs
  exactly once inside that row, `old` occurs exactly once in the whole
  document, and `new` occurs nowhere yet. `--check` prints
  `CHECK cap=… line=… row_old=1 doc_old=1 new_pre=0` per row and writes
  nothing. Apply mode is atomic (`mkstemp` + `os.replace`) and re-reads the
  written file to verify each old is absent and each new present exactly once.
* Supporting receipts: `sweep-capabilities.py`, `sweep.txt`,
  `sweep-patched.txt`, `control-scan-base.txt`, `control-scan-patched.txt`,
  `measure-receipt.txt`, `probe-uniqueness.txt`.
