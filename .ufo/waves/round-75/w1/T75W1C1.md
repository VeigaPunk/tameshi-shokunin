## 3. Do-nothing reachability — DEFECT (C2)

C1's controls hold: I reproduced the base state and the mutant survival (below).
C2's stated controls (do-nothing `stale=7`; row-deletion refused by setup exit 2;
echo-stub caught by the frozen red row) are real but **incomplete**: the §9
pre-freeze control that skips the claimed work — a manifest that satisfies the
counter without repairing the seven cells — was not built. Two concrete routes:

**(a) The figure regex is not constrained to a figure.** The plan says "each row
carries the figure regex"; nothing requires it to capture the number. With the
same 16 spans and a loose regex, a stale cell and its instrument produce the same
token:

```sh
$ python3 - <<'EOF'
import re
d='RECEIPT_COMMIT_BIND_SELFTEST: 4/4 pass'; i='RECEIPT_COMMIT_BIND_SELFTEST: 7/7 pass'
for p in [r'pass', r'\S+', r'\d+/\d+ pass']:
    print(p, '->', re.search(p,d).group(0), '==', re.search(p,i).group(0), ':',
          re.search(p,d).group(0)==re.search(p,i).group(0))
EOF
pass -> pass == pass : True
\S+ -> RECEIPT_COMMIT_BIND_SELFTEST: == RECEIPT_COMMIT_BIND_SELFTEST: : True
\d+/\d+ pass -> 4/4 pass == 7/7 pass : False
```

With `pass` or `\S+`, all seven stale rows read `match` at base; `unexpected=0`
lands with zero SCORECARD edits. C2 kill rule (ii) only refuses a regex that
"matches nothing"; kill rule (v) only requires the token to be the instrument's
own stdout token — `pass` is.

**(b) The instrument is not required to be the cell's named tool.** A row's
`instrument` is a path/rev/argv of the claim-writer's choosing; a committed script
that already prints the doc's figure (or a stub) satisfies reply (v) while
measuring nothing about the state the cell claims.

Smallest safe correction: freeze the 16 `(capability, regex, instrument path,
instrument rev, argv)` tuples **to the committed prototype's SPECS and the cells'
own evidence commands**, e.g. "the 16 live rows are exactly the pairs listed in
`.ufo/evidence/round-75/selfstate-control-scan.py` SPECS, regex byte-identical,
instrument path equal to the cell's named tool". That forces the seven repairs and
closes (a) and (b) without touching the 17-row count.

Also note: kill rule (iv) "population is not exactly 17" pins the **count**, not
the membership; the seven stale rows are named in prose but not in any
machine-checked artifact. The same freeze fixes that.
