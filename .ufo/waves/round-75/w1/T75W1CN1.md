### 1.1 kagi — the closest standing instance

`kagi-shokunin/corpus/self-counts.py` + `corpus/self-counts.tsv` (standing;
`PROVINCE.md:74`, `SKILL.md:46-47`, `SCORECARD.md:1161` reads `self-counts
CLEAN60`; `corpus/QUALITY.md:118` QM21 is the rule).

- Binds a **current-tense document number** to its live source. Locator is a
  regex with exactly one capture group (the claimed integer); **exactly one**
  doc line must match.
- `ledger:<ID>` executes *that row's command, not its pinned expected number*,
  and applies the extract to the command's **last nonempty combined output
  line**. A changed live count stays measurable even when the ledger's old
  expect regex is stale.
- Exit `0 CLEAN` / `1 STALE` (incl. `UNLOCATED`/`AMBIGUOUS`) / `2 POLICY/SETUP`.
- Explicit anti-cheat list at `SKILL.md:47`: hand-editing a number "to match";
  binding to a second definition of the quantity; dropping a binding to go
  green; treating an explicitly round-dated history line as current.

Differences from R75-C2: kagi locates by doc+line regex, not by exact
first-cell name in `## Capabilities`; its commands run at `cwd=root` (worktree),
not extracted from git objects at a pinned revision; a frozen host number uses
`expect:<ID>` which **runs nothing**, so it cannot measure drift — C2 instead
keeps the frozen row in the measured population with `expect: stale`.

## 4. Two-lane bar — may the method be called general?

**The method: yes.** Before this round, the same method (record figure →
executed command → normalized instrument stdout → match/stale verdict →
fail-closed setup exit) is evidenced in **three independent lanes** — kagi
(standing, closest vocabulary), souji (r30 met, r31 honest miss), kumitate
(self-only recompute) — and in tameshi's own r31 evidence script. Tameshi's
`PROVINCE.md:14-16` bar is therefore met for the *method*, and
`corpus/knowledge/executable-self-assessment.md` is already an admitted,
source-headed entry with mined sources (S055/S095/S096), so no new Core
admission is required for C2 to be honest.

**The exact predicate: no.** The 17-row declared manifest, `mode:
capability|span`, location by exact first-cell name in `## Capabilities`, a
per-row `measured=` token, instrument extraction from git objects at its own
pinned rev, setup refusal (exit 2) for an absent row or figure, and a frozen
row kept **inside** the population with `expect: stale` — that combination has
no sibling instance. Calling that shape general would be lane-only evidence
presented as a fleet pattern.
