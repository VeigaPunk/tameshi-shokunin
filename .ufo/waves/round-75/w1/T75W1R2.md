## 5. Adversarial checks on the candidate design

The candidate was absent (no `T75W1E2/` dir at check time); these are fixture
measurements against the pre-freeze prototype
(`.ufo/evidence/round-75/selfstate-control-scan.py`, explicitly "NOT the
instrument") plus acceptance probes for the L1. Fixtures: `fx-b1.md`
(capability name misspelled `anchor-drift sweepX`), `fx-b2.md`
(`RECEIPT_COMMIT_BIND_SELFTEST: 4/4 pass` token deleted from its row),
`fx-c.md` (second `ADDRANGE: rows=99 met=99 unexpected=0` planted in the
additivity cell). Transcripts: `fixture-responses.txt`.

**(a) Echo cheat.** A counter that copies the doc's figure as its measurement
reads `stale=0` (`echo-stub.py`, this dir):

```

```

so the summary count is not self-authenticating (plan control 2 verified). The
discriminator is the base-state run itself: an honest instrument must read
`stale=8 unexpected=7` at `--doc-rev 21ef81e9` — an echo reads 0. The measured
token must come from the extracted instrument's stdout (E2 frozen design; plan
kill rule v requires per-row `measured=` and raw stdout in the receipt).
**Probe for L1:** base-state run must show 7 live rows with `measured` ≠
`quoted`; my `mine-base.txt` is the reference output.

**(b) Row deletion / absent figure must refuse exit 2.** Prototype responses:

occurrence, or state "first match in the row is the bound figure" in the
instrument docstring. Silent first-match is the "wrong occurrence" hazard the
plan's kill rule (v) otherwise guards against.
