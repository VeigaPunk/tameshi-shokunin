## 3. TMPDIR contract

The lane's frozen text (`SKILL.md:32-40`) binds tools that allocate scratch
through `strict_scratch_root()`: unset → platform default; **empty → unset**;
set-but-unusable → **exit 2, could-not-evaluate, naming the value, never a
silent `/tmp` fallback, never a traceback, never exit 1**. Seven tools implement
it (`grep -ln ScratchRootUnusable tools/*.py` →
`bash-witness-study.py`, `context-capture.py`, `env-diff.py`,
`evidence-disposition.py`, `pin-disposition.py`, `registry-check.py`,
`repeat-control.py`).
`wave-reconcile.py` does **not** use the helper; it allocates with
`tempfile.mkdtemp(prefix='wave-reconcile-selftest-', dir=os.environ.get('TMPDIR') or None)`
(`tools/wave-reconcile.py:386-387`), so it is outside the helper's letter — the
arms below record what it actually does.

### 3.3 TMPDIR_VIOLATIONS=1 — the C2 control prototype swallows refusal

`.ufo/waves/round-75/w1/T75W1E3/sweep-capabilities.py` (15 KB scratch candidate;
it drives 19 instruments with `env['TMPDIR'] = tmpdir`, line 136):

```sh

  .ufo/waves/round-75/w1/T75W1E3/sweep-capabilities.py
# exit=1
# SWEEP_ROW cap=mutation sweep runner  kind=selftest quoted=MUTATE_SELFTEST: 80/80 pass  measured=MUTATE_SELFTEST: 0/1 pass  rc=1 stale
# …
# SWEEP_SUMMARY specs=19 match=8 stale=11 uncovered=0
```

and `grep -oE 'rc=[0-9]+' | sort | uniq -c` over that run → **3 rows with
`rc=2`**, the instruments' own setup refusals, each of them scored `stale` and
folded into an exit-1 verdict. A set-but-unusable `TMPDIR` therefore produces a
*measurement* ("11 stale") where the frozen contract demands a refusal
(`could-not-evaluate`, exit 2). It is the CR47 class at the harness level: the
substrate tools refuse correctly (all three `rc=2` lines come from
`strict_scratch_root()` consumers), and the wrapper converts the refusal into
evidence. The same defect is visible in the prototype's own normal run
(`T75W1E3/sweep.txt` `SWEEP_SUMMARY specs=19 match=10 stale=9 uncovered=6`).

This matters for C2 because the plan's kill rule (ii) makes a setup refusal "a
failure to measure, not a pass" and rule (v) requires each `measured` to be the
instrument's stdout token. **Recommendation (L1):** `tools/selfstate-freshness.py`
must treat any non-zero instrument exit as a row-level/whole-run **setup refusal
(exit 2)**, never as `stale`/`unexpected`, and the manifest sweep should assert
that with a `TMPDIR=/nonexistent` arm in its selftest. I could not measure the
delivered instrument (§6).
