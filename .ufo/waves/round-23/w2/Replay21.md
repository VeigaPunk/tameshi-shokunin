## Field-level false acceptance (one)

**ARGV/CWD/REVISION are producer echoes, not child observations.** `replay.py` builds `requirements` and each receipt from the same `row` (`'argv': list(row['argv'])`; `'cwd'`, `'revision'` and the bundle's identical values from one local variable), and `run_row` returns only `{name, kind, status, expect, tags, got, held, elapsed_s, stdout, stderr, *_tail}` — no argv/cwd/revision readback. So for this artifact `ARGV_MISMATCH`, `CWD_MISMATCH`, `REVISION_MISMATCH` are structurally unreachable; the gate compares the runner's input to its own echo. Only EXIT and STDOUT are independently observed. A clean `finding_ids: []` therefore certifies the declaration surface, not that the executed process carried that argv — consistent with the contract's no-authenticity claim, but not with reading "full revision matched" as a cross-artifact pin: requirements pin 28cae179, the receipt declares 496d212, and `command-binding.py` never receives `source_revision`. (Latent, not realized: `stdout_contains` is inclusion-only, no `stdout_excludes`/anchoring; the `stdout-surround-clean` extra case blesses arbitrary surrounding text.)
