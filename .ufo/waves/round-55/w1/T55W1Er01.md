## 5. The honest cause, with the arithmetic

`control/controls.sh:145` is `d=$(clone_at "$LANE" "$REV" pos)` — phase B clones the
revision it is handed. It was handed the FREEZE commit.

Evidence chain (all commands in §2 / receipts):

1. `077d431e` is an ancestor of `7fa9a5e`, which is an ancestor of the round-55 base
   `0a2010ac`. The freeze is 9 minutes older: `12:12:06` vs `12:21:35`.
2. `git diff --name-status 077d431e 7fa9a5e -- .ufo/evidence/round-21/coldread/` adds
   `A …/rekey-r54-99c3bc88d704/traces/section-08.json`, `…/17`, `…/18`, `…/23`
   (25 files touched in that tree); `ledger.json` entries go **587 -> 591**; the re-key
   directory holds 202 files at the freeze and 206 at the re-key.
3. Of the seven frozen headings (`round-54/c1/lost-headings-at-base.json`), at
   `077d431e`: **3 credit** (`## Standing rules`, `### The operator's runbook …`,
   `### Round-14 historical registry …`); **1 has an entry that fails** (`## Mutation-sweep
   recipe …` — its trace pins `.ufo/evidence/round-21/coldread/ledger.json`, whose sha256
   differs at that revision); **3 have no bound entry at all** (`### The boundaries — what a
   service run is not`, `### Using the ledger`, `### Round-26 gate/probe registry — report
   interop`). 7 − 3 − 1 = 3 → `rekeyed=3/7`.
4. Replaying the frozen counter bytes over a clone at each revision reproduces the receipt
   line exactly at the freeze:

   ```
   ### counter at 077d431e (clone HEAD 077d431e6996)
   exit=1
   C1_R54: rev=077d431e6996 c0=99c3bc88d704 credited=60 lost=4 rekeyed=3/7 readers=6/7 monitor=6/60 unstable=0 total=4 C1_R54_PASS=false
   ### counter at c2108100 (clone HEAD c21081008adb)
   exit=0
   C1_R54: rev=c21081008adb c0=99c3bc88d704 credited=64 lost=0 rekeyed=7/7 readers=7/7 monitor=8/64 unstable=0 total=0 C1_R54_PASS=true
   ```

   So the mismatch is **forced by the revision**, not by a counter fault: phase B scored the
   control on a tree that could not carry the re-key.

Wording to prefer everywhere: *phase B cloned the freeze `077d431e`, which predates the
re-key `7fa9a5e`; the pre-registered `true` was unreachable on that tree.* Not "the counter
was broken", and not "the control was re-scored and passed".
