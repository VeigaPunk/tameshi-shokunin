### F2 — the documented `'<value>'` shape is `%r`; a quote in the value breaks it

Quote (section bytes):

> root: TMPDIR is not a usable directory: '<value>' (could-not-evaluate)`

```
$ cd <clone-at-C0> && TMPDIR="/nonexistent-r55'q" python3 tools/repeat-control.py --selftest
exit=2
repeat-control: could-not-evaluate: cannot create clone scratch under the scratch root: TMPDIR is not a usable directory: "/nonexistent-r55'q" (could-not-evaluate)

$ python3 - (counter GRAMMAR, measure.py:47-50, requires "directory: '.+' ")
actual line: ... directory: "/nonexistent-r55'q" (could-not-evaluate)
GRAMMAR.match -> False
quote char actually used: '"'
```

The three tools format with `%r` (`"… %r (could-not-evaluate)" % t`), so any
value containing a single quote is double-quoted. The counter's own grammar would
score such a legitimate refusal as a failed arm. Values without a quote render
exactly as documented, which is why the nine-mode sweep passes. Receipt
`04-quote-value.txt`.
