   481	## No-permissiveness audit recipe
   482	
   483	Goal: prove a change did not make anything pass by absence — no finding went
   484	quiet, no arm stopped firing, no claim passed on a warning line. In order:
   485	
   486	1. **Fix the revision under audit.** Line refs pin to a sha; a reader on a
   487	   differing revision re-resolves. Stamps are recomputed (`ok=56 stale=0`),
   488	   never re-typed (gates-survey-kagi.md:246-254, 420-438).
   489	2. **Capture the before-set; compare against it.** Prior rows/ledgers are the
   490	   regression fence — "prior rows 0-mismatch", "all 102 prior ledger rows +
   491	   receipts byte-stable" (verification-patterns-fleet.md:37-39).
   492	3. **Compare by byte-identity; scrub volatility only by an explicit list**
   493	   (pids, timing, paths, ASLR, decimal wobble), and keep residual line drift in
   494	   a named field (`provenance_only_line_diff`)
   495	   (verification-patterns-fleet.md:32-35).
   496	4. **Match verdicts fail-closed:** a claim passes only when the exit code equals
   497	   the expected one AND the expected ERE matches the last non-empty output line;
   498	   a verdict-shaped string followed by failure fails (`reason=verdict-not-final`)
   499	   (gates-survey-kagi.md:161-168).
   500	5. **Abstention is declared, counted, exit-neutral — and proven both ways.**
   501	   `[substrate]` rows `DEFER … reason=substrate-absent`; the guard is the
   502	   both-paths selftest; only-ABSENT/SKIP output may exit 0
   503	   (gates-survey-kagi.md:187-197).
   504	6. **Zero-work is a defect, not a green** (gates-survey-kagi.md:139-143).
   505	7. **Falsifications and defects are findings, never softened;** the verifier
   506	   catches what the author missed; post-verification changes carry their own
   507	   proof (verification-patterns-fleet.md:46-57).
   508	8. **Leave holes named as unknowns, not as green:** live verdicts unmeasured for
   509	   five of six kagi gates; the kumitate integration group not executed
   510	   (gates-survey-kagi.md:442-465; gates-survey-kumitate.md:320-331).

   512	## Fail-closed arm taxonomy
   513	
   514	Exit 2 is not one class. A red run means different things — read the arm:
   515	
   516	| Arm | Fires when | Shape | Source |
   517	|---|---|---|---|
   518	| **SETUP** — cannot measure | input missing/unusable (`--src` gone, `op` absent, fixture dir not a dir) | exit 2, a named line before any effect (`ADJACENCY_SCOPE: SETUP (…)`), never a bare death | gates-survey-kagi.md:93-99 |
   519	| **Malformed committed data** | a census row / declaration is malformed | census `die`s exit 2 ("not a verdict"); scope-gate accumulates `BAD-ROW` → `DEFECT` exit 1 — opposite calls, both deliberate | gates-survey-kagi.md:100-106 |
   520	| **POLICY** — refused before the effect | the act would leak/overstep: non-regular or `op://`-carrying op-side paths; claim rows outside a 5-verb allowlist (quote-stripped before matching; 23 denied verbs); nested self-audit; stamp-set shrink without `--prune`; checklist rows naming `op.env`; hashing a no-hash path | refused before exec: exit 2 structural, except `drift-pins.sh`, which prints the POLICY line and returns its DRIFT verdict, exit 1 (`drift-pins.sh:142-148`, `:252-258`; round 17) | gates-survey-kagi.md:107-138 |
   521	| **Zero-work** | the gate would report over nothing | refused; a gate that measures nothing must not exit 0 | gates-survey-kagi.md:139-143 |
   522	| **Deferral** | substrate absent for a `[substrate]`-tagged row | `DEFER … reason=substrate-absent`, counted, not executed, never FAIL; guards: tag lives in the data file, both-paths selftest | gates-survey-kagi.md:187-197 |
