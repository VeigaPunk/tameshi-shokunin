## 4. UFO-FSD Connector Synthesis & Bounded Proposal

### Title
**GFM Delimiter Width & Fenced-Coverage Hermeticity Binding**

### Evidence & Synthesis Across Round Seats
1. **Delimiter Width Blindness (Reviewer R93R1 Finding 1):**  
   In `measure-v93.py:203-230`, `tables(text)` identifies the delimiter row at `vis[i+1]` via `DELIM_RE.match(vis[i+1][1])`, but populates `drows` starting at `j = i + 2`. Consequently, in `parse_note()` at line 269:
   ```python
   delim = drows[0][1] if drows else []
   if delim and len(delim) != len(header):
       bad.append("width:%d:header=%d,delimiter=%d" % (oi + 1, len(header), len(delim)))
   ```
   `drows[0]` is the **first data row**, not the delimiter row. Line 270 erroneously checks `len(first_data_row) != len(header)` (which is already checked per-row at line 275). The actual delimiter row's cell count is never verified against the header width. A table with 5 header columns and a 3-column delimiter `|---|---|---|` is accepted clean (`bad=[]`), violating S321 GFM table syntax.
2. **Fence-Blindness in Coverage Last-Row Grading (Reviewer R93R1 Finding 2):**  
   In `measure-v93.py:481-489`, the `coverage` scan parses `corpus/README.md` using raw `splitlines()` and `lstrip().startswith("|")` without filtering through `block_lines()`. A fenced code block containing an illustrative markdown row naming the note is evaluated as a table row, allowing a fenced example to defeat an honest denial or forge coverage.
3. **Receipt Cryptographic Traceability Gap (Reviewer R93R2 Finding F1):**  
   `controls-v93.py:343` prints `CONTROL_INSTRUMENT sha256=...` to battery stdout, but individual receipt files in `.ufo/evidence/round-93/pre-freeze/controls/*.out` omit this hash. While textual conformance holds, individual receipts cannot independently prove which driver revision created them.

### Affected Axes
- **Coverage (Axis: Verification-Fixture Craft - R93-C1):** Closes the GFM delimiter column count check (S321) and eliminates fence-blindness in `corpus/README.md` coverage checks (S322), ensuring that table grammar and presentation defenses are strictly certified without false-greens.
