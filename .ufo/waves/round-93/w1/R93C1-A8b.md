# A8 (rule-a, seat-not-named but plan-required): honest states beyond the named seven
Plan kill rule (a) is broad: "the committed note, the committed note with an id-keyed table
that asserts no verdict, or the committed note with a data cell equal to verdict — is refused
by a rule stated in this plan". The seat names seven shapes; also probe offline:
- a prose line containing a verdict token with >=2 pipes NOT in any table (edge1): REFUSED
  stray-verdict. A reader of the plan could call "The table for | C01 | KILLED | is given
  above" honest prose (no table asserts it, it points at the real table). Plan limit says
  "a verdict word in prose with fewer than two pipes on the line is not a table row" — TWO
  pipes here, and the stray rule is the named mechanism. Under the plan's own wording this is
  a presented verdict row (the reader's rule is content, not shape, and the plan says so:
  "a pseudo-table paragraph is a presented verdict row even when it has no delimiter row").
  So NOT an honest refusal: the reader's stated rule covers it. But it is a kill candidate
  under a READER-of-the-plan standard narrower than the instrument's stated rule. Record as
  the strongest A-side argument, judged WEAK because the plan/reader define this as a
  presented verdict, not prose.
- escaped pipe inside a stray line (edge3): NOT refused (escaped pipe stays in cell, token
  cell becomes "a | KILLED b" != KILLED). Consistent with declared limit. No kill.
- indented (3sp) SECOND verdict table (edge7): vt=2 + dup, refused. Table indented 3sp IS a
  table under GFM (<=3sp), so keying it is correct. The seat's A7 (non-verdict 3sp) passes.
