## D1 — adjacent asymmetry found (reported, not a kill of C1)

**Observation.** The reader normalises the **header** cell through `norm_cell` (strips `*` and
backticks, lowercases), so `verdict`, `Verdict`, `VERDICT`, `**verdict**` and `` `verdict` `` all
name the verdict column. But it compares the **token** cell **byte-exactly** against
`VERDICTS = ("KILLED","SURVIVED")` — no emphasis stripping, no case folding, no trailing-dot
tolerance. The header side is presentation-tolerant; the token side is not.

Both directions are reproduced **end-to-end through the frozen counter** on scratch fixtures
(`R93S2-emphasis-fixture.sh` / `.out`), each a `git clone --shared` of the lane at `855f0c1c`
with one edit committed under `ctl <ctl@fixture.invalid>`:

- **Honest direction (D1a).** The note's twelve verdict cells written as `**KILLED**` /
  `**SURVIVED**` — the same rendered words, markdown emphasis — are **refused**:
  `badrows=12` (`no-verdict:70:C01` … `no-verdict:81:C12`), `ids=false`, `mismatched0=false`,
  `C1_R93_PASS=false`, exit 1.
- **Hostile direction (D1b), as a minimal pair against the committed `renamed-result` control:**

| fixture | the appended table | `badrows` | verdict |
|---|---|---|---|
| **FX-B2** (plain tokens) | `\| C01 \| fixture arm \| SURVIVED \| differs \|` | **2** (`stray-verdict:299`, `:300`) | `ids=false`, `C1_R93_PASS=false`, **exit 1** |
| **FX-B** (same table, `**`) | `\| C01 \| fixture arm \| **SURVIVED** \| differs \|` | **0** | `ids=true`, `C1_R93_PASS=true`, **exit 0** |

The two fixtures differ **only** in the two `**` pairs — same header, same ids, same cell
positions, same witness column — and that alone flips the outcome from REFUSE to PASS. FX-B2
reproduces the committed `renamed-result` receipt exactly (`badrows=2`, `ids=false`), which is
what makes the pair legible: the `renamed-result` cheat the battery refuses is **one emphasis
byte away** from being accepted.

**Why this is not a kill of R93-C1 under the plan's four rules.** (a) The committed note and
the two named honest states are all accepted — `C1_R93_PASS=true`, exit 0, as are V4/V4a/V4b/V5;
the emphasis variant D1a is a *fourth* state, not one of the three the rule names. (b) All
twenty-three named hostile states reach `C1_R93_PASS=false`/exit 1 with their named conjunct
false — re-checked receipt by receipt, 23/23 `C1_R93_PASS=false`, 0 missing receipts — and the
committed `renamed-result` receipt shows `badrows=2`/`ids=false`; D1b is a *variant* of that
state, not the state itself. (c) the counter blob at `855f0c1c` is byte-identical to the stated
sha256 (re-read from `git cat-file`, not the worktree). (d) every pre-registered control name
has a receipt. The plan's claim wording is explicitly about the *committed* note and the *named*
states, and says "No other state is claimed"; D1a and D1b are outside both sets. QUALITY 156 is
also not violated: the reader's declared limits do not name emphasis-normalisation of the token
cell, and nothing is refused on a class the plan declares unkeyed. D1 is therefore a presentation
class the plan **neither kills nor declares** — an **undeclared limit**, not a contradiction of
the frozen claim.

**Materiality.** Low for the committed note (it writes bare `KILLED`/`SURVIVED`; **0** table
cells in the note and **0** in the README carry an emphasised verdict token — the emphasis class
is not live in either in-scope file today) but not zero, and it is the *shape* of defect that
killed round 92's counter: an honest note variant refused for a presentational reason (D1a), and
a hostile note variant accepted for the same reason (D1b). Emphasis inside table cells is
idiomatic in this lane's corpus (5 such rows in the README), so the class is reachable by
ordinary prose editing. Recorded so the L1 can route it; **no amendment is proposed here** —
the plan's claim is about the committed note and the named states, and the frozen counter must
not be edited.

**Note for any future note author.** Write the verdict cells as bare `KILLED` / `SURVIVED`
(exactly as the committed note does). `**KILLED**` in a verdict cell is refused; `**verdict**` in
the *header* is accepted.
