# A8 (offline edges, parse_note only — no committed fixture)
Cheap in-process probes; recorded for the frontier, each judged against the plan's own wording.
- Prose line "The table for | C01 | KILLED | is given above." (>=2 pipes, KILLED token cell,
  NOT in any table) → REFUSED (stray-verdict). Strongest honest-refusal argument — but the
  plan + reader define this as a presented verdict row ("a pseudo-table paragraph is a
  presented verdict row even when it has no delimiter row"), and the declared limit only
  exempts prose with <2 pipes. Judged: NOT a kill (the reader's stated rule covers it).
- Lowercase stray ("| C01 | killed |"): NOT refused — VERDICTS is caps-only. A reader of the
  plan would not key lowercase as a verdict token (the measured cells are uppercase). No kill.
- Escaped-pipe stray ("a \\| KILLED b"): NOT refused — the token is inside one cell; declared
  limit covers it. No kill.
- HTML with pipe tokens ("<p>| C01 | SURVIVED |</p>"): REFUSED (stray-verdict) — HTML evasion
  via pipes does NOT work; only databaseless HTML (no pipes) evades, see B5.
- HTML comment ("<!-- | C01 | SURVIVED | -->"): REFUSED (stray-verdict).
- Delimiter-row width (one extra or missing dash segment): ACCEPTED — the reader's "width"
  check compares header width to the first DATA row, not to the delimiter row (tables() never
  returns the delimiter); the DELIM_RE accepts any >=2-segment delimiter count. Under S321 the
  cells must match, so this over-accepts a non-GFM shape. Over-keying direction: it cannot
  hide verdicts, only see more. Observation, not a kill. Smallest safe correction: return the
  delimiter cells from tables() and check delimiter width against header width.
- Lowercase id in the verdict table ("c01"): REFUSED (out-of-set) — spec ids are uppercase;
  consistent with `ids` wording. No kill.
- Second verdict table with IDENTICAL true cells: REFUSED (dup) — the battery's hidden-c001/x
  class exactly. No kill.
- Relocated verdict table (real table removed, second table with true cells appended):
  ACCEPTED (vt=1, rows match). By design — the claim certifies cells, not position. A reader
  of the claim counts it. Not a kill (the battery does not claim position).
- Fenced inverted table: ignored (vt=1, no bad) — DECLARED LIMIT (S322), see B4.
