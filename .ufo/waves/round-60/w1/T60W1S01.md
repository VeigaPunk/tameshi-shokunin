## Why this happens (from the unfixed source)

`blob_bytes()` returns None on any `cat-file` failure. `main()` then takes the branch
`if trusted_bytes is None or candidate_bytes is None or trusted_bytes != candidate_bytes:`
and writes `EXECUTOR_SOURCE_DRIFT: ... differs at candidate revision`, returning `EXIT_DRIFT` (1). The
plumbing failure is folded into the drift verdict. The v2 amendment has to split that branch so a
None from `blob_bytes()` returns `EXIT_UNAVAILABLE` (2).
