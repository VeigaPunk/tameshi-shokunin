## Findings

### W1: wrong expectation, table row 5 (1877)

The row says: "A trace opened a file in the live lane while the root was a clone → No credit (`live-lane-read:`)". At REV that holds only for unbound reads.
- **What the code does.** measure.py:418-428 (via `live_read_bound`, :432-457) and assemble.py:464-472 accept a live-lane read that is under `.git/`, or whose bytes equal the regular blob at REV. The ruler's docstring states this exception (measure.py:61-62).
- **Real bytes.** Receipt 2 is this section's step 1, traced with `--root` a clone as step 2 instructs. It contains 2379 live-lane opens, all under `.git/`. The opens are a full local clone of the live object store, so the read is not limited to the recorded revision either. Assemble accepted the report that carries it (receipt 12: `rejected reports: none`). The strict measure credited an entry that carries it (T1).
- **Same for byte-identical reads.** A byte-identical live worktree read also credits (T15). Only the unbound read gets `live-lane-read:` (T14). The selftest `live-lane-read-bound {'credited': 4}` agrees (receipt 6).
- **Consequence.** A reader who trusts the table predicts no credit where the ruler gives credit.

### Minor gaps

- **M1.** The table omits the class-independent commands gate (measure.py:522, `commands-unrecorded`): a zero-command entry never credits, even a record with verified inputs (T9). The class gate is also unstated.
- **M2.** The table omits the trace-binding codes `trace-input-unrecorded:`, `trace-input-drift:` (measure.py:415-417) and `trace-invalid:` (:405-410). T16 shows the first.
- **M3.** Row 4 understates the veto. A failing entry with absent or empty inputs also vetoes (`entry_is_stale`, measure.py:528; T13).
- **M4.** Steps 3-4 name neither the default ledger path (measure.py:113) nor `<prior ledger>`. A ledger committed elsewhere measures as `no-ledger` with exit 0 (receipt 17), so the mistake is silent.
- **M5.** Row 1, "sibling and git-object reads are recorded as external", is loose. `.git` opens under the clone root are dropped (trace-inputs.py:296). Live `.git/` opens go to `live_lane_reads` (:303). Only sibling opens (:306) and seat-declared `repo@rev:path` keys are external.

"""history.py: content-minimal history probe for SKILL.md 1863-1869 record claims.

    return subprocess.run(["git", "-C", C] + list(a), capture_output=True, env=env, check=True).stdout

P2 = "line count of every edited section unchanged"
H15 = "### Round-15 gate/probe registry"

    if s15:
        body = lines[s15["start"] - 1:s15["end"]]; n_raw = len(body)
        while body and not body[-1].strip(): body.pop()
        r15 = "%d %d %s" % (n_raw, len(body), s15["sha256"][:12])
    else:
        r15 = "- - -"

    print("%s | %s | %s %s | %s %s | %s %s | %s | %s" % (r[:10], r15, p1, h1, p2, h2,
