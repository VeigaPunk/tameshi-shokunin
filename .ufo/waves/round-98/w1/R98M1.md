## Method

- **Pre-registered before any mutant ran**: `R98M1-prereg.json` (written 13:16, first mutant
  run 13:18). 10 mutants per instrument; each is **one exact `old`→`new` string replacement**
  on a fresh copy under `mut/<id>/`; the prereg records `old_occurrences` (all 20 = 1) and the
  pristine sha256. The runner re-asserts the occurrence count, and asserts that applying the
  reverse edit to the mutant reproduces the pristine bytes exactly (recorded per mutant in
  `R98M1-run.log` as `MUTATED <id> sha256=<mutant sha>`).
- **Same bounded detector on pristine, mutated and restored bytes.** Baseline runs precede
  the mutants; the full baseline is re-run after all mutants land ("POST-RESTORE"), and the
  pristine instrument sha256 is re-read at the end. A baseline failure would make every
  mutant `INCONCLUSIVE`; none failed.
- Every subprocess had a 300 s timeout. Slowest observed arm: battery positive/red on a
  contended 4-way pool, 36.2 s; no timeouts, no tracebacks.
- The detection repo is a scratch clone: `git clone -q --shared <lane> lane` (the lane
  worktree is never read or written by the instruments; they read blobs at `--rev`).
- `wtclone` is a second clone checked out at the freeze with **one worktree-only edit** to
  `.ufo/evidence/round-98/controls98.py` (`add("c2-nowork-absent", g.returncode,` →
  `add("c2-nowork-absent", 0,` — the exact D-2 regression), blob unchanged
  (`sha256 f1c1db0e…924b`, worktree `4acc745a…e302`). It is the fixture for C1 kill rule e.

## Detector findings (killed only by a supplementary arm)

1. **`b8` — the C2 red arm as specified does not observe the red substitution.** With the
   substitution replaced by `if False:`, the substituted class is refused under the red run,
   the battery prints `GUARD_REFUSALS_RED state-unbuildable refused-under-red-run`, and the
   summary + exit are byte-identical to the declared red line (`refused=5 wrong=1`, rc 1).
   The seat's red predicate (exit 1 + summary) cannot enforce C2 kill rule c; only the
   `missed-as-declared`/`refused-under-red-run` stdout line can. This is a detector gap in
   the pre-registered minimum suite, not an instrument defect (the pristine instrument emits
   `missed-as-declared rc=0`).
2. **`b11` — the `--tool-sha` refusal has no arm in the minimum suite.** C2's frozen wording
   claims a `--tool-sha` that is not 64 hex or not the blob's sha256 is refused (setup exit
   2). `b11` (dead pin check) passes selftest + positive + red; the supplementary `battery-pin`
   arm kills it. Without that arm the pin is dead code as far as the suite knows.
3. **`a8` — "naming the literal site at line 156" is not in the aggregate line.** Dropping
   site names leaves the r97 aggregate line and exit untouched; only the `CONTROL_ASSERT_SITE
   line=156 name=c2-nowork-absent …` assertion observes the frozen C1 sentence.

## Round-level note

The instruments themselves behave as declared on every arm: the pristine baseline passes all
eight predicates, and the two claims' cited lines/exits are exactly reproducible at the freeze
blob. The findings are about **what the instruments' own suites observe**, not about changed
pristine behaviour:

1. C2's red arm, as specified, cannot detect a dead red substitution (`b8`); the battery's
   red exit is unconditional and the summary is identical either way. A future kill suite
   should grade `GUARD_REFUSALS_RED <class> missed-as-declared rc=` on stdout.
2. The `--tool-sha` refusal in C2's frozen wording has no executed arm in the minimum suite
   (`b11`); a wrong-pin case (64-hex mismatch and non-64-hex) should be part of the suite.
3. C1's "naming the literal site at line 156" is not observed by the aggregate line (`a8`);
   the `CONTROL_ASSERT_SITE` line must be graded.
4. Three classification branches are unexercised by fixtures and survive single-edit
   mutants: 2-positional-arg `add` sites (`a5`), non-first tuple elements (`a9`), and
   name chains deeper than 8 (`a10`); on the battery side, exit-1-with-token (`b1`),
   stderr-only tokens (`b5`), and an embedded positive predicate (`b6`). Each is a named
   missing assertion above, not an equivalence.

No instrument was modified; no lane file was written; no claim wording was changed.
