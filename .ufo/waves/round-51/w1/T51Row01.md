## Defects of the tool seen (not fixed; only the runner is editable this round)

1. **Selftest hardcodes `/tmp`** — `private_root = Path(tempfile.mkdtemp(prefix="bash-witness-selftest-private.", dir="/tmp"))`
   (lines 1240-1241). `TMPDIR` is ignored: with `TMPDIR=<scratch>/tmp`, `<scratch>/tmp` stayed empty
   (`ls -A` → 0 entries) while the `/tmp` private root was created and removed by the cleanup
   (`bash-witness-study.py:1702-1709`). The row's write scope states it, but a caller on a host
   without `/tmp`, or with a noexec/`TMPDIR`-only sandbox, gets a failure instead of a verdict.
2. **Undeclared exit `1` for setup errors** — `evidence.mkdir(parents=True, exist_ok=True)` at
   line 848 runs outside the `Fail`/`Cannot` guards, so an unwritable parent aborts with a Python
   traceback and exit `1`, which reads as `failed` though it is a setup error:
   ```
   $ python3 tools/bash-witness-study.py --evidence /proc/t51row01-ev declare; echo $?
   FileNotFoundError: [Errno 2] No such file or directory: '/proc/t51row01-ev'
   1
   ```
   (receipt `T51Row01/declare_bad.err`; stdout empty). Same shape for `write_json` failures. The
   verdict map can only declare `1 failed`, so this leaks a could-not-evaluate into `failed`.
3. **The finding id on the last line is generic** — `VERDICT: PASS` / `VERDICT: FAIL` (lines
   1713, 1715) is not a tool-specific id; `WITNESS_SELFTEST: n/n pass` (line 1712) is. The frozen
   counter keys the *last* line, so the registry row must name `VERDICT:` (a marker other tools may
   also print) and can only mention the specific id as plain text. Recommend the tool print
   `WITNESS_SELFTEST:` last in a round that owns the tool; the row as drafted names both so it
   survives either spelling.
4. **`count` prints an absolute path** (`print(f"declared\t{declared_sha}\t{evidence / DECLARED_NAME}")`,
   line 1108) — cosmetic, makes receipts host-specific; the frozen rows themselves are
   host-independent.
5. Not a defect, recorded for the verdict map: `run`/`rerun` refuse when `the-janitor` is on PATH
   (`run_sweep`, lines 598-603) — that refusal is exit `2`, already mapped to could-not-evaluate.
