## Defects / caveats seen

1. **`TMPDIR` is ignored — `/tmp` is hardcoded** in both scratch creations (`:766`, `:916-917`, `dir="/tmp"`).
   The counter sets `TMPDIR=WORK/tmp` (`measure.py:167-170`) and that environment variable has no effect; the
   self-test still writes under the host `/tmp`, contrary to the round's scratch directive. The tool documents the
   choice (`:78` "fixtures only under /tmp"), so it is a policy mismatch, not a code bug; the row's Write-scope
   cell states it rather than claiming `TMPDIR`.
2. **`--help` exits 0** (`:1845`) — a caller that types `-h` gets `clean`; harmless but surprising for a gate and
   not distinguishable from a real pass. Not declared separately because the code is `0`.
3. **SIGTERM maps to 2** (`:1823-1824`, `_sigterm` raises `SystemExit(2)`): a killed run is reported as
   could-not-evaluate, which is the correct class but means `2` can arise from outside the tool.
4. **`--rev` needs the fleet layout** — it symlinks each sibling `*-shokunin` of the source lane (`:60-64`,
   `:769` onward). Running it from a bare clone (as the counter does) is fine, but a reader should expect
   sibling-lane resolution.
