## Findings and defects of the tool (reported, not fixed — outside this seat's write scope)

1. **`--help` returns 64.** `tools/wave-route-mix.py:100-103` catches *every* `SystemExit` from
   argparse, including the help exit 0, and returns 64: `python3 tools/wave-route-mix.py -h` →
   exit 64. Harmless for classification (64 is declared) but makes help indistinguishable from a
   usage error.
2. **A setup error can read as `failed`.** A spec whose JSON parses but is not an object (e.g. `[]`)
   dies with `AttributeError` at `:115` and exits 1 — the fleet-wide `failed` class — although the
   input, not the wave, is wrong. `{"items":{}}` is worse: iterating the mapping's keys yields
   `seats=0` and the tool reports `REFUSE seats=0` (exit 1) instead of an unreadable-input verdict.
   PROTOCOL would want `2`/could-not-evaluate here.
3. **Empty seat list is classified `failed`.** `{"items":[]}` → `REFUSE seats=0`, exit 1 (`:70`),
   which the row must therefore declare under `1`. Arguably a setup error; the row states the tool's
   behaviour, not the reviewer's preference.
4. **The default routing table is the operator's live file.** `:19` (`Path.home()/".omp/agent/
   config.yml"`) is used when `--config` is omitted, so a bare run's verdict is not reproducible
   across hosts or days, and no committed snapshot with a committed expected verdict exists for it —
   PROTOCOL §Gate "Two evidences" (`PROTOCOL.md:401-406`) is unmet for that mode. The row mitigates
   this by naming `--config CONFIG.yml` in the entry command; a real snapshot + `expected.json`
   would be a follow-up for the tool's owner, not something this seat may invent.
5. **Verdict text is stderr-only in normal mode.** `:121` prints `ROUTEMIX: OK|REFUSE …` to stderr;
   stdout is empty unless `--json`. A caller that captures only stdout sees no verdict (the selftest
   id *is* on stdout, `:89`, so the registry's marker rule is unaffected).
6. **Pinned values are genuinely `none`.** The only expected values are the eight literal case
   results inside `selftest()` (`:74-90`) and the `0.40` default (`:97`); there is no
   expected-value file in the lane for this tool. The round-21 mutation study
   (`.ufo/waves/round-21/w1/MT3RouteMix.md:9,322`) records the same source digest
   `1954c40…`, i.e. the bytes the row describes are the bytes that were mutated and credited.

No undeclared deterministic exit was found beyond item 1-3; a red gate is not the marker predicate
here, and no claim is made about C3 as a whole.
