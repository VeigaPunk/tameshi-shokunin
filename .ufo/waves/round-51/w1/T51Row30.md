## Tool defects and limits observed

1. **The green-line fields do not independently evidence the fixture.** `tools/write-path-census.py:107`
   computes `fixture_wrote = 0 if any('update flag' in item or 'no-flag' in item for item in failed) else 1`
   — i.e. from the *failure strings*, not from the observed write — and `:110` prints
   `noflag_unchanged` as `1 if fixture_wrote else 0`, so the two printed columns are one boolean. The
   fixture itself (`:93-105`) does read the file back and append on mismatch, so the assertions are real;
   only the emitted `fixture_wrote=`/`noflag_unchanged=` pair is a restatement.
2. **Flag detection is file-global, not site-local.** `tools/write-path-census.py:65`
   `flagged = FLAG_RE.search(text) is not None` — a single `--update` occurrence anywhere in a tool zeroes
   `unflagged` for that whole file. The lane result `live_unflagged=0` over 99 write sites
   (`T51Row30-probes.txt`, census-lane-clone) is therefore only as strong as that per-file rule; it cannot
   distinguish "no unflagged expected-value write" from "some tool mentions an update flag somewhere".
   The docstring discloses the line-scope limits (`:8-10`) but not this file-level suppression.
3. **No hardcoded `/tmp` write.** The only `/tmp` occurrence is the literal fixture string
   `'open("/tmp/census-scratch.txt", "w")\n'` at `:60`, never executed; the real temp dir is
   `TemporaryDirectory` (`:93`), TMPDIR-driven. Verified:
   `TMPDIR=$S/tmp python3 tools/write-path-census.py --selftest` left nothing under `$S/tmp` after the run.
4. **Frozen scope excludes the tool's own successors.** `GATES` (`:22-44`) names 21 of the 30 base tools;
   unclassified are `tools/pbt-staged-id.py`, `tools/round21-measure.py`, `tools/shrink-case.py`,
