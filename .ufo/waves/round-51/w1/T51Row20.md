## Findings (tool defects / operability limits observed)

1. **Hardcoded `/tmp` write outside `TMPDIR`** — `tools/tally-audit-v3.py:422`
   `cand = '/tmp/tameshi-r4-2-regression.' + …`, `os.makedirs(cand)` at `:426`. Every audit
   allocates a real directory under `/tmp` regardless of `TMPDIR` (deliberate: it witnesses the
   runner's own `$(mktemp -d /tmp/tameshi-r4-2-regression.XXXXXX)` shape, `:408-413`), so a
   sandboxed runner with a read-only `/tmp` would turn a clean runner into `SETUP`
   (`CannotAudit('cannot allocate a real auto root')`, `:430`) — exit 2, not a false FAIL.
   Three empty `/tmp/tameshi-r4-2-regression.*` dirs were present on the host at 21:24-21:28
   while several seats ran this tool concurrently (`ls -ld /tmp/tameshi-r4-2-regression.*`);
   attribution to this seat is **not** established, so this is reported as an observation only —
   the source-level fact in this finding is what the row declares.
2. **Undeclared exit code via an uncaught exception** — `main()` catches only
   `CannotAudit, OSError, UnicodeDecodeError, ValueError` (`:937`); any other exception escapes
   `sys.exit(main())` (`:946`) and exits **1**, which a reader maps to `failed` rather than
   `could-not-evaluate` (PROTOCOL: an undeclared nonzero code reads as could-not-evaluate).
   Same shape in the selftest path: `subprocess.run(..., timeout=900)` at `:895` raises
   `TimeoutExpired` past the `finally` and exits 1 without printing the finding id.
3. **`--then-regression` propagates the runner's code verbatim** — `:940-942` returns
   `p.returncode` (0/1/2 in practice, 124 mapped to 2 at `:794`); any other runner code would be
   undeclared. It also executes a full live regression (1200 s cap, `:96`), which exceeds a
   read-only gate's own write scope — the row's write-scope cell states that the workdir is the
   runner's choice.
4. **Cost** — the self-test is 35 sequential full audits: `WALL=375s` here (cap 900 s). A single
   audit is 13 s. Under parallel seats this is CPU-heavy but within the counter's limits.
