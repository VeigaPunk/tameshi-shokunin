## Defects seen in the tool

- **D1 — hardcoded `/tmp` in the self-test harness.** `tools/context-capture.py:1624-1625`
  calls `tempfile.mkdtemp(prefix="context-capture-selftest-", dir="/tmp")`, so fixtures land in
  `/tmp/context-capture-selftest-*` even when `TMPDIR` is set (the counter sets `TMPDIR`;
  the run above did too). Disclosed in the docstring (`:26-27`) and declared honestly in the
  row's Write scope, but it bypasses the caller's scratch root. Cleanup is in a `finally`
  (`:2206`), so no fixture dir survived.
- **D2 — `-h/--help` exits 0, the same code as `clean`.** `:2287-2289` returns 0 without running
  a check, so a consumer keying only on exit 0 reads a help invocation as clean. Only noted;
  the verdict map cannot distinguish it (`0 clean`).
- **D3 (non-defect, worth knowing) — frozen mode is clone-relative, not lane-absolute.**
  `DEFAULT_LANE_ROOT` is derived from the script path (`:137-138`), so the frozen pin reads the
  receipt in whichever tree the tool lives in; a clone missing the receipt exits 2
  (`receipt_missing`), not 1.

No undeclared exit code was found. The usage parser is hand-rolled rather than `argparse`, so 64
is intentional rather than argparse's 2.
