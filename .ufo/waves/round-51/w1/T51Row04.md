## Tool defects observed

1. **Hardcoded `/tmp` sandbox root.** `tools/env-diff.py:61`
   `tempfile.TemporaryDirectory(prefix="tameshi-r21-envdiff.", dir="/tmp")` ignores `TMPDIR`; the
   selftest and every production run write under `/tmp` regardless of the caller's scratch policy.
   The row's Write scope states this rather than hiding it.
2. **A missing prerequisite reads as `failed`, not `could-not-evaluate`.** With `bwrap` absent,
   `execute()` returns `BWRAP_UNAVAILABLE` (`:58-60`), `classify()` → `unavailable` (`:100`), main
   returns 1 (`:245`). Observed exit 1 above. A reader therefore cannot separate "environment
   missing" from "surface is env-sensitive-but-broken" by exit code alone; the row declares
   `1 failed` to match the tool's actual behaviour.
3. **Row-level `error` is dropped for profile-level failures.** `surface_result` sets
   `row["error"]` only in the exception branch (`:139`); the `BWRAP_UNAVAILABLE`/`TIMEOUT` markers
   live inside `profiles[*].error`, so `surfaces[0].error` is `null` in the receipt (observed) and a
   receipt reader sees `unavailable` with no cause.
4. **A tampered pin is graded `failed`.** `PIN_MISMATCH` (`:126`) → `unavailable` → exit 1; PROTOCOL
   §Gate standard asks that an edited snapshot be `snapshot_tampered` (could-not-evaluate), not a
   compared verdict. The selftest asserts the current behaviour
   (`pin-mismatch-public-cli`, `:186-192`, `child.returncode == 1`), so the lane owns the divergence,
   but it contradicts the fleet clause and should be routed.
5. **Receipt is written before the host-version probe.** `a.out.write_text(...)` at `:239` precedes
   the `node`/`bash --version` calls at `:234-238`; a missing `node` therefore returns 2 *with* a
   complete-looking receipt on disk. Source-derived, not executed. [INFERENCE]
6. **`--jobs` range errors are usage (64), not setup (2)** — observed; declared as such.
7. **The selftest cannot fail-in-isolation for a host without bwrap.** `missing-bwrap` passes a
   literal `bwrap="/nonexistent/tameshi-bwrap"` (`:161`), so the really-absent-bwrap path
   (`:58-60`) is never exercised; on such a host the other cases fail and the selftest exits 1.
   Source-derived. [INFERENCE]
