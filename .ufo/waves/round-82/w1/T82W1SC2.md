1. **The capability row must be inside `## Capabilities`** (scan stops at the next `## `). Adding

   tail-less regex over the **old** round-81 token the row certifies `match` against the bound
   instrument — measured `SELFSTATE: rows=24 match=22 stale=2 unexpected=0`, exit 0 — i.e. the
   binding would be unmeasured. With the tail, the same old token is
   `figure-absent` exit 2 until the cell is refreshed.
3. **The doc cell for `selftest-text pin` must gain `DEFECT_BIND_SELFTEST:`**; the round-81 cell
   carries only `SELFSTATE_SELFTEST`/`WAVE_RECONCILE_SELFTEST`, and a `DEFECT_BIND_SELFTEST:` figure
