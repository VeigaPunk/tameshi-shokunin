## 2. Disagreement between the seat brief and the landed manifest — the argv

The assignment's literal argv for `closure-defect-bind` is
`--repo . --manifest tools/defect-bind.json` (no `--manifest-rev`). Measured
against the landed doc row (`… manifest=bound`), that argv **cannot** produce
`match=24 stale=2`:

| Candidate argv | figure regex | Result |
|---|---|---|
| `--repo . --manifest tools/defect-bind.json` (brief) | landed `manifest=(?:bound\|unbound)` | `SELFSTATE: rows=26 match=23 stale=3 unexpected=1`, exit 1; row `closure-defect-bind … measured=stale UNEXPECTED`, `measured_figure=… manifest=unbound` |
| `--repo . --manifest tools/defect-bind.json` (brief) | strict `… manifest=bound` | `SELFSTATE error=setup figure-absent:closure-defect-bind`, exit **2** (whole sweep refused) |
| `--repo . --manifest tools/defect-bind.json --manifest-rev HEAD` (landed) | strict `… manifest=bound` | `SELFSTATE: rows=26 match=24 stale=2 unexpected=0`, exit 0 |

Without the flag the instrument prints `manifest=unbound`; the landed manifest
therefore correctly adds `--manifest-rev HEAD`. The brief's argv is the one
error to fix in any re-derivation that reuses it. (Landed regex choice
`manifest=(?:bound|unbound)` is equality-measuring, not state-asserting: if doc
and instrument ever both said `unbound` the freshness row would still match.
A strict `manifest=bound` regex — which I independently used — also measures
`match` at the landing, so tightening it is available at no cost.)
