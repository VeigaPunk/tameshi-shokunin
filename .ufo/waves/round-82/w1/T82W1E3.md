## 5. Disagreements and notes

1. **Plan wording vs measurement (L3).** §R82-C3's declared limit groups "a
   vacuous comment inside the function" with the edits that "stay outside the
   class". Measured: such a comment is *inside* the digest's sensitivity — it
   turns A14 red alone (`13/14`). The class is over-broad on comments (a false
   positive), not blind to them. The other two declared-limit items (module-level
   edits, two-edit rewrite) measure exactly as declared. This is a wording
   disagreement, **not** a failure of the claim: the claim's predicate only
   requires the `db-a1-assertion-weakened` FAIL set to be A14-only and the
   battery to kill 5/5, both measured.
2. **Scope of the 100 % kill rate.** Only defect 1 is a text-pinned mutant; the
   other four are code paths *outside* `selftest` killed behaviorally by A12/A13.
   The battery's `killed=5 survived=0` therefore must not be read as "A14 covers
   the C1 code paths" — it does not, by design.
3. **`A14` digest values cross-checked.** The lane's bare sha256 and this seat's
   labelled digest agree on pristine (both arms green) and disagree only through
   the label; the lane's measured mutant digest `728b97c70d94…` equals the value
   this seat independently recomputed for L4, so the two implementations digest
   the same object.
4. **No defect routed.** No row, arm, counter or receipt measured contrary to the
   frozen claim; nothing is opened against the L1.
5. Tooling: nothing installed or upgraded (python3 3.14.8, GNU bash 5.3.20, git
   2.56.0 were already sufficient). No pacman transaction was attempted.
