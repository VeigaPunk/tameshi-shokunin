## Findings

**F1 (medium, page text) — wrong count.** `SKILL.snapshot.md:505` says "22 denied verbs". The enumerated list on that line and the source regex `claim-ledger.sh:164` both contain **23** names (`op the-janitor git rm mv cp chmod chown curl wget sudo ssh scp systemctl tmux kill pkill dd truncate shred ln rsync tar`); counted programmatically from the alternation. Either the count is stale or `op`/`the-janitor` were excluded inconsistently. A reader using the number as a fixture invariant would be wrong.

**F2 (medium, page text) — coverage overstatement.** `:513-515` says surface-probe and cite-check "have no token enum, so their exit-2 paths are uncovered until a case asserts them". Both suites **do** assert a CLI exit-2 arm: surface-probe `:1340-1347` (bare-run `--src` missing, `status===2`, observed PASS) and cite-check `:2334-2343` (same, observed PASS). What is actually uncovered is *enum-level arm accounting*, plus cite-check's empty-scan `return 2` mapping (`:2527-2533`). The downstream survey states this correctly ("one CLI arm exercised"); the SKILL compression drops it.

**F3 (low, one hop away) — stale script line anchors in `gates-survey-kagi.md`.** At kagi `c2cab35`, `op-ref-probe.sh` refs are shifted ~12-14 lines: die is `:155` (cited `:141`); `guard_op_file` is `:228-241` with non-regular at `:231-233` and `op://` at `:235-237` (cited `:216-224`, `:218`, `:222`); `adir`/`absent.env` are `:216-222` (cited `:204`/`:207`); the three SETUP variants are `:480/:484/:486` (cited `:459-465`). `claim-ledger`, `scope-gate`, `surface-census`, `drift-pins`, `checklist-run` refs are exact at this rev. The page names the survey as Source, so a reader who follows the hop must search rather than jump.
