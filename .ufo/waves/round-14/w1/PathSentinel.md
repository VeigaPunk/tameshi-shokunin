- Lane precedent for safe reads is `tools/pin-disposition.py`:

## Findings

| ID | Sev | Exploit path | Impact | Smallest remediation |
|---|---|---|---|---|
| PS1 | High | Python's default exit codes collide with the contract. An uncaught exception (KeyError on `stdout.rows`, RecursionError from deep JSON, TypeError) exits **1**, which reads as "semantic failure". `argparse.error` exits **2**, which reads as "could-not-evaluate" instead of usage 64. | Tampered or malformed input can show up as an ordinary red result, and usage errors look like bad input. The before/after exit discrimination becomes untrustworthy. | Override `ArgumentParser.error` so it exits 64. Wrap `main` in a catch-all for `Exception`/`RecursionError` → structured `could_not_evaluate` exit 2. Only an explicit predicate-mismatch path may return 1. |
| PS2 | High | The superseded-row schema (`name/state/reason/superseded_by`) has no `receipt`/`check`. Yet the contract requires the gate to "retain observed raw receipt/check" for `producer_before`, and DispositionSpec makes before/after "identical aside state". So the after file will likely keep `receipt`/`check`. | Two outcomes: (a) strict extra-key rejection makes the real after file exit 2, or (b) a lax gate never locates or evaluates the raw failure. That would silently drop the initial crash, which round-13 routed item 1 forbids. | Superseded rows must **require** `receipt`/`check`, with the same selection rules as effective rows. Evaluate the raw original expectation and emit `raw_result: mismatch` with details. Messaged Gate and DispositionSpec. |
| PS3 | High | The pins in `inputs` are **authored by the dispositions file itself**. An attacker adds `forged.json` with its true sha256 and points an effective row's `receipt` at it, with stdout that satisfies every predicate. | The pins become self-attested, so a green result can be fabricated for any row. | Allow receipts only from the fixed set `{verification.json, producer-oracle-repair.json}` in `dirname(expected_file)`. Require `verification.json.expected_file == expected_file`. Hold the trust anchor outside the dispositions file, as described in L1 check C3. |
| PS4 | High | Supersession can launder results. The contract allows a superseded row whenever `superseded_by` names effective, passing rows. A file can supersede `source_census` or `pin_live` with `pin_selftest` and give some text as the reason. | Any failing expectation can be hidden behind unrelated green rows. This is a correctness defect, not merely a hardening gap. | Hard-code the only admissible supersession in code: `producer_before → {producer_before_oracle, producer_after_oracle}`, both required. Any other superseded name, or a different replacement set, is a finding (exit 1) or exit 2. Replacements must be distinct, must not include the row itself, and must have `state == effective`. That also rules out chains and cycles. |
| PS5 | High | TOCTOU between hash and parse: the gate hashes a file, then reopens it to `json.load`, or verifies `expected.inputs` digests through a separate open. A concurrent writer or symlink swap lands between the two opens. | A digest-verified file and the parsed file can differ. | Read each file **once** into bytes using the pin-disposition pattern: `lstat` → reject links and non-regular files → `os.open(O_RDONLY\|O_NOFOLLOW)` → `fstat` dev/ino equals lstat → bounded read. Hash and `json.loads` the **same** buffer. |
| PS6 | High | Path traversal and aliasing. `expected_file`, `inputs` keys, `receipt` values, and the `expected.json` inputs keys (including `tools/...`) can be crafted as `../x`, `/etc/x`, `./a`, `a//b`, `a/./b`, `a/`, `a\b`, a path containing NUL, an empty string, or a non-ASCII alias. Aliases like `./.ufo/…` vs `.ufo/…` defeat the textual "inputs pins expected file / every used receipt" check, or let two keys pin the same file with different digests. | The gate reads outside the lane, or the pin check is bypassed. | Validate every relative path before use. Reject when the path is not a non-empty `str`, `posixpath.isabs(p)`, `posixpath.normpath(p) != p`, any segment is in `{'', '.', '..'}`, `'\\' in p`, `'\0' in p`, or `not p.isascii()`. Compare pins on these canonical strings only. |
| PS7 | High | Symlinked parent directories. Turning `.ufo`, `.ufo/evidence` or `round-13` into a symlink to an attacker tree bypasses `O_NOFOLLOW`, which checks only the final component. | Every pinned read can be redirected. Digests can be made to match by copying the bytes, while the path claim becomes false provenance. | After `R = os.path.realpath(--root)`, require `os.path.realpath(R/p) == os.path.join(R, p)` (exact equality, not `startswith`). Better: walk components with `os.open(..., O_DIRECTORY\|O_NOFOLLOW, dir_fd=...)`. Record `root_real` in the output. |
| PS8 | Med | Non-regular targets: a FIFO hangs `open`/`read`; a symlink to `/dev/zero` or a huge file causes an unbounded read. | Denial of service, and the gate never reaches exit 2. | Check `S_ISREG` via lstat **before** open. Open with `O_NONBLOCK`, then clear it. Cap reads at a bound such as 8 MiB → exit 2 `input_too_large`. |
| PS9 | Med | JSON confusion: (a) duplicate keys, last one wins. (b) `NaN`/`Infinity`. (c) Python bool is int: `exit: true == 1`, `rows: 6.0 == 6`. (d) Non-object roots. (e) Deep nesting. All of this also applies to the **inner** `json.loads(check.stdout)` (duplicate `"id"` keys). | Predicates match on coerced values, or traceback → PS1. | Use `object_pairs_hook=reject_duplicate_keys` and `parse_constant` that raises, for outer **and** inner parses. Use `type(x) is int` / `type(x) is str` for every compared field. Catch `RecursionError` → 2. Require a dict root and schema `evidence-dispositions-v1`. |
| PS10 | Med | Unspecified predicate mapping for `pin_live`. `rows` and `statuses` don't exist as stdout keys, so a naive `stdout["rows"]` → KeyError (PS1). A lax mapping trusts `counts` only. | The row is unevaluable, or it relies on a self-reported tally. | Define rows = `len(legs)`. Define statuses = Counter of per-leg `content_status`, and require it to equal `counts` minus `legs`, with no extra status keys. Require `counts.legs == rows`. `result_reuse` must equal both the top-level field and **every** leg. Document the mapping in the output detail. |
| PS11 | Med | Self-attested receipt fields: `exit_matches` and `expected_exit` live inside the receipt. `producer_before` has `exit_matches=true` and still fails its expectation. | An exit-only or `exit_matches` gate passes the stale row. | The exit predicate uses only `type(check.exit) is int` against `expected.exit`. Ignore `exit_matches`/`expected_exit`, or emit a finding when they disagree. Where stdout JSON carries `"exit"`, cross-check it against the receipt exit. |
| PS12 | Med | Ambiguity in `contains`. Expected `contains` is not pinned to stdout vs stdout+stderr. An empty `""` would pass trivially. `producer_before`'s expected string is a prefix of the oracle's `… FAIL` line. | Silent, overly permissive matches. | Search `stdout` only (as `str`) and record the stream searched in the detail. Treat an empty `contains` in expected as exit 2. Keep the prefix weakness as a disclosed residual, not a repair. |
| PS13 | Med | No execution, plus selftest isolation. The risk is a gate or selftest that runs receipt `argv`, uses `shell=True`, `eval`/`exec`, imports receipt-named files, or a selftest that reads the real lane. | The gate executes target content or contaminates evidence. | The only subprocess allowed is the selftest calling `[sys.executable, os.path.realpath(__file__), ...]`. Use `shell=False`, a timeout, `cwd` = a `tempfile.mkdtemp` fixture root, and `--root` = that fixture. Clean up with `shutil.rmtree` in `finally`. Use a `grep` gate for `subprocess`, `os.system`, `eval`, `exec` and `import_module` (L1 check C6). |
| PS14 | Low | Findings may embed untrusted strings: row names, paths or stdout snippets in finding IDs, and ANSI escapes in non-JSON output. | Unstable IDs or terminal injection. | Validate row `name` against `^[a-z0-9_]{1,64}$` and require it to be in `expected_checks` before it is used in an ID. Keep IDs as fixed enum codes plus validated names. Emit detail only through `json.dumps`. |
| PS15 | Low | Pin padding and unknown keys: unused extra `inputs`, unknown row keys, unknown `state`, rows that are dropped or duplicated, or a check name repeated in a receipt. | Ambiguous coverage. | Make each of these an explicit finding or exit 2. Every `expected_checks` name must appear in exactly one row. Each selected `receipt.checks[*].name` must match exactly once. |
| PS16 | Low | Live-tool pins in `expected.inputs`: `tools/pin-disposition.py`, `witness-metadata.py`, `bash-witness-study.py` and `mutate-and-run.sh` are working-tree files. Any future legitimate edit makes the gate exit 2 permanently. | Freshness brittleness, which can be mistaken for tampering. | Use a distinct finding ID such as `expected_input_digest_mismatch` that carries the path. Optionally allow `--rev` blob reads later (out of scope now). |
