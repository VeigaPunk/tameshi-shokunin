## 1. Semantics read (authority: plan + code, not the control file)

- Plan `plans/round-81.plan.md` R81-C2 (lines 58–85): a row is `settled` when
  the instrument's blob at the row's pinned revision is byte-identical to its
  blob at `--pin-rev` (the tip). Byte-identity, not pin recency. Kill rule: the
  whole validated manifest is the population; one stale row fails; re-pinning
  to differing bytes still reads stale (ARM18); the standing sweep must stay
  green after re-pin.
- `tools/selfstate-freshness.py` (bytes at `1b115ba`, worktree verified clean
  against it): `pin_audit` (lines 1216–1246) resolves `pin_rev` via
  `rev-parse --verify <rev>^{commit}`, then per row: `exists(tip, path)` gate
  (`cat-file -e`, else `SetupError('pin-path-absent:…')`), compare
  `cat-file blob <pin>:<path>` vs `cat-file blob <tip>:<path>`; prints one
  `SELFSTATE_PINS_ROW … state=…` line per row, summary
  `SELFSTATE_PINS: rows=N settled=S stale=T`; exit 0 iff `stale==0` else 1;
  setup failures exit 2 via `main`'s catch. `validate_manifest` (lines
  231–274) runs first for both sweep and audit: refuses zero rows, non-hex
  revs (`_rev_ok`, shape-only), and paths with `''`/`.`/`..`/absolute/backslash
  parts. `GitReader.exists` treats tree objects as existing (`cat-file -e`
  succeeds on `rev:<dir>`), so directories pass the tip gate and fail later at
  the blob read as `blob-unreadable:<rev>:<path>`.

## 4. Adversarial edge probes (isolated fixture repo, lane tool bytes at 1b115ba)

Fixture timeline: C1 (tools/t.py v1, tools/stable.py, tools/old.py) + annotated
tag `v1`; C2 (README only); HEAD=C3b (t.py v2, old.py deleted, tools/adir/ dir
created, tools/new.py added, tools/shape file→dir at C3b). All runs:
`python3 -I -X utf8 $S/lane/tools/selfstate-freshness.py --repo $D --manifest <probe.json> --pin-audit --pin-rev <rev>`.

| probe | rc | behavior |
|---|---|---|
| pin at older rev, bytes equal tip (`stable.py` @C1) | 0 | `settled`. Byte-identity is the declared settled semantics — recency is not required (also settles @C2). Consistent with plan predicate + ARM18 do-nothing control. |
| pin at older rev, bytes differ (`t.py` @C1) | 1 | `rows=1 settled=0 stale=1` — non-vacuous single-row accounting. |
| instrument path is a directory at the pin (`tools/adir` @C3a) | 2 | `blob-unreadable:<pin>:tools/adir … bad file`. `exists()` gate passes (tree objects satisfy `cat-file -e`); the read fails. Note: labelled `blob-unreadable`, not `pin-path-absent` — the exists gate guards the tip only. |
| row pin rev = tag *name* (`v1`) | 2 | `instrument-rev-unresolvable:…:v1` — `validate_manifest._rev_ok` requires 6–40 lowercase hex; tag names never reach the audit. |
| row pin rev = tag *object* sha | 0 | `settled` — `git cat-file blob <tagsha>:<path>` peels the tag object to its commit. Loose: any hex object (commit/tag/blob sha) passes `_rev_ok`; comparison stays exact, so harmless here but worth knowing. |
| `--pin-rev` = annotated tag name | 0 | works: `_resolve_commit` peels via `rev^{commit}`. Tags usable for the tip argument, not for row pins. |
| instrument path `./tools/x` | 2 | `instrument-path-invalid:dot` — `_safe_relpath` rejects `.` path parts (also rejects `tools/`, `a//b`, `..`, absolute, backslash). |
| path exists at pin, absent at tip (`old.py` @C1) | 2 | `pin-path-absent:<tip>:tools/old.py` — the tip gate fires before any row output. |
| path absent at pin, present at tip (`new.py` @C1) | 2 | `blob-unreadable:<pinrev>:tools/new.py` — asymmetric label vs the row above; same exit-2 setup refusal before any row effect. |
| file at pin, directory at tip (`shape` @C3a→C3b) | 2 | `blob-unreadable:<tip>:tools/shape … bad file` — tip-side directory again survives the exists gate and dies at the blob read. |
| row pin = hex but nonexistent (`ffff…`) | 2 | validate passes (shape-only check), dies as `blob-unreadable:ffff…` at read time. |
| manifest with one row | 0/1 | measured, never vacuous: settled row → `rows=1 settled=1 stale=0` rc 0; stale row → rc 1 (matches ARM20). |
| manifest with zero rows | 2 | `zero-rows` refused by `validate_manifest`, same as the sweep path. |

Every exit-2 refusal prints only `SELFSTATE error=setup …` on stderr and emits
no row lines — setup failure precedes any row effect, as the docstring claims.

## 5. Disagreements and routed defects

- **No disagreement with the frozen plan.** All three frozen before/after
  numbers reproduce independently; the plan's disclosed stale-row set, pin
  shorts, and last-modifying-commit shorts (`4af6695f`, `01ca77cd`) all match
  my full-SHA derivations.
- **No new defect routed.** The three stale rows are exactly the declared
  R81-C2 before-state (round-80 closure defect D3 plus the one row the
  closure did not name); the re-pin repair reaches the frozen after-state
  `settled=23 stale=0` exit 0 at both the base tip and the declaration tip,
  with the standing sweep green and byte-identical before/after.
- Observations for the record (not defects): `exists()` treats directories as
  existing, so directory-shaped instruments fail as `blob-unreadable` rather
  than `pin-path-absent`; tag object SHAs are accepted as row pins while tag
  names are not; `_rev_ok` is shape-only so nonexistent hex pins die at blob
  read. All are exit-2 setup refusals and cannot mint a false `settled`.
