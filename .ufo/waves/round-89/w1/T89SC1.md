## Findings

1. **Check-set deviation, `env-steer`.** Pre-registered `W_ENV`
   (`ctl/expected.tsv:9`), observed `W_EXEC` (`dev/observed.tsv:2`). Cause recorded
   before the honest variants ran: `BASH_ENV` makes the suite's `bash -c` exit
   before any interpreter exec, so no mutant is exec'd and `W_EXEC` fires first
   (`ctl/expected.tsv:20-22`). The frozen predicate binds exit code + verdict
   label only (`ctl/expected.tsv:2`), so the refusal stands; the entry records the
   deviation rather than smoothing it.
2. **Check-set superset, `fake-interp`.** Pre-registered `W_EXEC`
   (`ctl/expected.tsv:12`), observed `W_EXEC,W_VERDICT,W_ENV`
   (`dev/observed.tsv:4`). Two extra checks fire because the shim execs change
   both the exit and the environment. Not a false positive: the runner is refused
   for the declared reason plus two true observations.
3. **`witnessed` is not the verdict.** `rlimit-steer` reaches `witnessed=11` and
   still FAILs on global `W_ENV` findings (`dev/observed.tsv:12`), because
   `report()` requires `not findings and witnessed == len(legs)`
   (`tools/ledger-witness.py:636-648`). Any counter that read only the
   `witnessed=` field would accept it; the frozen counter reads the whole line
   plus rc (`measure.sh:49-61`). The draft states this explicitly (§4.4).
4. **Seat brief vs counter code: run count.** The seat brief says the counter
   makes "13 traced regression runs"; `measure.sh:45-48` dispatches the real
   runner + 12 forgeries + 2 honest variants = 15 witness invocations through one
   `xargs -P 7`. Runtime estimate only; the predicate is unaffected. The draft
   avoids both counts and cites the dispatch lines instead.
5. **The landed SCORECARD row's receipt pointer is dangling.** `SCORECARD.md:272`
   says "landing receipt named in `## Round 89`", but `SCORECARD.md` has no
   `## Round 89` section — its last round section is `## Round 88` at line 5511
   (`grep -n '^## ' SCORECARD.md`). No committed file contains a measured
   `C1_R89_PASS=true`: `grep -rl 'C1_R89_PASS=true' .ufo/evidence/round-89/`
   matches only `measure.sh` itself (the predicate literal), and `lnd/` holds the
   five standing no-harm sweeps, not a counter run. The landed entry's `recheck:`
   line repeats the same pointer (`corpus/knowledge/kernel-witnessed-ledger.md:3`
   at `ff7a4b06`). Either the landing counter output is appended in the records
   commit, or the row and the recheck should name the pre-freeze receipt and say
   the landing run is pending. My draft does not print `C1_R89_PASS=true` as a
   measured value and states this gap in §7.
6. **The landed entry carries two uncited cost figures.** `ff7a4b06`'s entry §3
   says "about 11 minutes wall and leaves a 1.6 GB trace tree … an untraced run
   takes about 4.5" with no receipt path (`corpus/knowledge/kernel-witnessed-ledger.md:60-61`

   measurements. My draft omits them and says per-run wall time is not recorded
