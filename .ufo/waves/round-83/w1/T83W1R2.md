The real parser/open/check/measurement implementations then run unchanged. It demonstrates target bytes really can be consumed after the type check, contradicting an unconditional “never reads target bytes” interpretation. Suggested correction: bind type validation to the opened descriptor and refuse symlinks at open, rather than trust an earlier pathname stat.
