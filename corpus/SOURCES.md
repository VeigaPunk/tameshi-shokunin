## Paths

- **Mutation verdict semantics and validity** — S001 → S002 → S004 → S006 → S011 → S010 → S009 → S007: learn the vocabulary first (states, schema, outcomes), then the verdict grammar (witness), then what makes a verdict untrustworthy (flakiness, subsumption), and finish with equivalence from the cheapest filter to an LLM agent.
- **Golden and hermetic fixtures for CLI gates** — S015 → S016 → S017 → S028 → S013 → S014 → S018: start with shell-transcript golden tests, then txtar fixtures in a fresh $WORK, then bash runner isolation and the focus guard, then the normative hermetic spec, and end with how JS, Rust and Python tools refuse to write expected values in CI.
- **Reduction and generation of fixtures** — S024 → S022 → S023 → S019 → S020 → S021 → S012: do delta debugging by hand, then internal reduction and the validity problem, then a modern reducer whose LLM proposals still pass through the interestingness test, then PBT practice and its Python baseline, then agentic PBT, and end with why a generated oracle can still never fail.
