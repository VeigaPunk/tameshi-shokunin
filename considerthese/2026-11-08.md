## Self-improvement ideas (proposals only, not acted on)

1. **Frozen-tally reconciler.** At freeze, collect every `N/M` tally and `key=value` count in the plan, LOG, lesson and SCORECARD. Compare each one to the receipt line it cites and fail on any mismatch or missing pointer. QUALITY 169 states the rule, and this would make it mechanical. Round 94 would have been flagged before filing.
2. **Gate line-pointer checker.** Re-render each committed source snapshot with the Gate's stated renderer, then confirm that each cited `line N` holds the start of its quote. Report the drift. Round 95 D1 found three pointers off by 3–4 lines, which a reader would otherwise trust.
3. **Hardening lint for drivers and environment trust.** Extend the defense list beyond counters to battery drivers and fixture generators. The checks would cover `python3 -I`, a pinned or absolute `git`, a scrubbed `PATH`, existence-guarded `O_NOFOLLOW` receipt writes, non-empty `--lane`/`--rev`, and 40-hex revs. Sentinel F1–F8 in round 95 were almost all in this space.
4. **Predecessor-discrimination rule for new fixtures.** Make round 95's ad-hoc check standing. Each new hostile state runs against the previous round's instrument first. Unless it is declared otherwise, a state the predecessor already handles the same way is flagged as non-discriminating, before it can count toward a battery total.
5. **Survivor age ledger.** Track the 12 rule-level mutant survivors (26/38 killed in both round 94 and round 95) by id, with the round first seen and the rounds carried. Flag any that have been carried for three rounds or more as either "needs a state" or "declared invariant". Then the depth axis has a concrete queue instead of an unchanged count.
6. **Fleet `split_cells` conformance fixture (report-only).** R95CN1 found six sibling parsers that diverge on `\\|`. A small shared fixture file and a report showing which lanes pass it would surface the divergence without editing other lanes.
7. **Zero-reject nudge.** When a round's Gate records no source rejects (round 95 D5), either surface one plausible candidate the round could honestly refuse or ask for the sweep that found none, so the rejection judgment keeps getting exercised.
