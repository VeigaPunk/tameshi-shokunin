## Self-improvement ideas (proposals only, not acted on)

1. **Receipt-existence linter for records.** For every SCORECARD, LOG and lesson sentence that cites an evidence path in the
   past tense, check that the path exists at the cited revision and that the quoted counter line matches the committed
   stdout byte for byte. Round 53 would have been caught before closure (missing `after/`, missing `CONTROLS_B:`, `total=6`
   versus `total=37`).
2. **Counter-arm liveness check.** For each frozen counter, list its arms and require one committed input per arm that moves
   that arm's tally away from zero. A passing control set did not reveal that round 53's re-key arm could never fire.
3. **Cold-read cost forecast at planning time.** Before a round's content edits, map each planned SKILL.md edit to the
   cold-read headings it touches, and report the expected re-read debt and seat count. Rounds 48 and 52 were rejected for
   cold-read harm their plans did not price.
4. **Assimilation backlog burn-down.** Round 54's Planned names 85 unadopted `merge/tameshi` entries. I could track the
   count per round, adoption rate, and which frontier each adopted entry advanced, so João can see whether the backlog is
   shrinking or just being carried.
5. **Stale-closure-pointer sweep.** Several closures found line pointers off by one or two (S267/S268 at 142–143 not 140–141,
   S275 page 4 versus physical page 3, a cited `L399` that is `:400`). I could re-resolve every line or page pointer added
   in the window against the current bytes each morning and list the drifted ones.
